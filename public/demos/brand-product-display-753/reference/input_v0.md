# v7.5.3 品牌商品展现优化｜Input

> 2026-11-19 整理。本文汇总当前产品决定，供进入 Spec 前评审。产品版本为 v7.5.3「品牌商品展现优化」。Demo v0.18 使用虚构样例，生产接口与字段仍需核实。

本版优先让用户从频道里的一条视频看清它关联了哪些品牌和商品，再从品牌、商品反查对应内容，并比较不同商品在本频道的内容表现。优先扩充现有列表、视频卡和图表，复用已收录关系和已有指标。线上事实以 YouTube 频道与 Amazon 商品详情的核对样本为主，发布平台范围留待确认。见[调研事实](../../../../02_Research_Analysis/channel_brand_product_pending/线上事实与指标候选_v0.md)和[通用上下文](../../../../02_Research_Analysis/channel_brand_product_pending/channel_brand_product_common_context_v1.md)。

## 频道详情

- **P03 视频关联。** 内容数据沿用现有视频卡，通过轻标记进入关联抽屉。品牌合作详情采用强展示，卡下展示品牌列表和可逐项查看的商品轮播。覆盖多品牌、多商品、单关联、仅品牌及未提供关系。在某品牌的合作详情里，视频卡可以展示该视频的其他已收录品牌与商品，入口保留来源品牌上下文。商品所属品牌用显式资料，AD 标识继续沿原口径。卡高、列数、换行和轮播密度留给设计。见[关联现状核对](../../../../02_Research_Analysis/channel_brand_product_pending/内容与品牌商品关联核对_2026-11-16.md)。
- **B01 品牌总数。** 按当前品牌名搜索和推广类型筛选后的全部去重品牌计数，左下显示「共 N 个品牌」。分页不改变总数，筛后确无记录显示 0。
- **P01／P04 商品表与反查。** 原品牌表、商品 Top5 和商品分类继续展示，完整商品表暂按 Demo 纵向叠放。表内显示商品图／名、品牌、分类、原币种价格、本频道关联视频数及 P02 指标。商品品牌条件按明确所属品牌查完整集合，支持全部、指定品牌和未知品牌。合作详情「查看推广商品」带当前品牌定位商品表并回第 1 页，使用同一品牌 TAB 时间，不传视频形式或提及方式。该条件只筛完整商品表。商品标题默认进入商品详情的全部频道视图，其他商品行区域打开原样式右侧抽屉，固定来源频道、商品和所选时间。关联卡中的商品行沿用这套交互。抽屉总数对应同集合的本频道视频数，关闭后回到原位置。
- **P02 商品表现与商品 Top5。** 完整表两列按原始数值排序，首次点击或换列从降序开始，再次点击同列切换升降序。筛完整集合后排序、分页，切排序回第 1 页，销量和均播本轮未列入。互动率沿服务端现有口径，零观看分母保留未知。商品 Top5 使用同一总观看量，从同频道和同时间的全部商品中取前五。完整表品牌、排序和分页条件只作用该表。Top5 有效值不足五件时按实显示，真实 0 可参排，缺失值不补位。
- **S01 时间。** 品牌 TAB 内的时间值统一控制内容统计，包括广告均播／互动率及频道对照、发布数量和观看对比、品牌表／总数／合作视频、商品 Top5／分类／全量商品表及指标和频道商品视频抽屉。切换时间重新按完整集合统计、过滤和排序，商品表回第 1 页并保留品牌、排序和页容量。数据总览、内容数据、受众数据及独立商品详情沿各自范围，报价与合作效率沿其原业务口径。Demo 以近 6 月为默认，提供近 7 天、1 月、3 月、6 月、1 年，正式默认值和选项待核实。线上总览和内容各有局部选择器，品牌 TAB 新增选择器是本版改动。见[线上时间选择器核对](../../../../02_Research_Analysis/channel_brand_product_pending/频道统计选择器线上核对_2026-11-17.md)。
- **V01 发布数量。** 在原「非推广 vs 推广」图卡内切换。默认「观看表现」，保留逐视频观看量、三类颜色、均值参考线和视频入口。「发布数量」默认统计当前频道全部已收录品牌／商品关联视频，包含仅品牌的视频。品牌按视频提及关系筛选，商品按视频商品关系筛选，组合取交集。商品候选按明确所属品牌收窄，切品牌时清除不兼容的商品条件。品牌、商品和粒度控件仅作用发布数量及其视频查看。非零柱打开对应时间段的完整分页抽屉，总数与柱值相同。切换视图保留发布筛选和粒度，清除已选时间段。

## 商品详情

- **P05 完整视频清单。** 在「关联视频」TAB 提供一个频道筛选器和一份完整视频清单。搜索／选择／清除频道同时刷新四项总览、两张环图、发布趋势和清单。商品页自行提供统计范围，Demo 使用近 180 天。频道条件仅作用「关联视频」，关联网红群体分析和商品基础资料沿原范围。列表保留视频缩略图、标题、日期、频道身份、表现值和视频入口。见[商品详情与现有接口核对](../../../../02_Research_Analysis/channel_brand_product_pending/商品列表与详情关联视频核对_2026-11-16.md)。
- **V04 关联内容发布趋势。** 统计当前商品和频道整段范围内的已收录关联视频发布数。点非零柱只筛完整视频清单并回第 1 页。总览、两张环图和趋势保留整段范围。清除时间段后按当前排序恢复完整清单。
- **V06 总览与排序。** 总览沿用总播放量、总内容量、总评论数、总点赞量。两张环图沿用自然传播、付费推广、疑似付费推广分类，内容占比用完整集合的视频数作分母，播放量占比用该集合的总播放量。原播放量、点赞、评论三组视频榜单合并到清单，默认发布时间最新优先，三个表现指标均从高到低，所有记录可继续翻页。先按商品、频道、页面范围和趋势所选时间段筛集合，再排序，最后分页。改排序回第 1 页并保留频道和时间段；改频道、清频道或改粒度会清时间段并回第 1 页，保留排序和页容量。视频 TAB 往返保留筛选状态。见[原总览与三榜截图](../../../../02_Research_Analysis/channel_brand_product_pending/evidence/visual-metrics-2026-11-17/product-overview-ranks-live.png)。

两处发布趋势共用按视频发布时间计数的口径，支持日／周／月，Demo 默认月，周从周一开始，首尾时间桶按所选范围裁切。每个查询集合内按视频身份去重，同视频关联多个对象只计一次。已知没有发布的时间桶为 0。播放、点赞、评论按所选视频的累计值汇总。排序使用原始值，同值顺序稳定，缺失排最后，真实 0 可参与。空记录、未提供、缺字段和权限受限应能区分。观看量为零或分类不全时，占比按相应状态呈现。

## 进入 Spec 后优先核实

| 主题 | 需要定清楚的口径 |
|---|---|
| 平台与权限 | 明确首发平台、内容类型和相应入口的权限。核实关联返回覆盖，区分无关联、未采集、无权限。品牌公开接口的 Scope 和上限须按频道／商品入口重新核验 |
| 时间与集合 | 核实品牌 TAB 正式默认档位、区间边界、时区和商品页范围。确认 `launch_time` 与 `pub_date`／`pub_time` 在各查询中的职责，以及有效状态和去重键。列表数字、柱值和对应明细须能按同集合对上 |
| 指标与分类 | 核实总观看量、互动率的聚合字段、分母和单位，以及推广类型的映射、缺失状态。确认累计观看和发布数量的展示口径 |
| 筛选、排序与分页 | 核实商品品牌和网红频道候选来源、过滤后总数、稳定排序键、商品 Top5 及商品视频的完整分页。验收用例应覆盖跨页高值、同值、真实 0、缺失和空结果 |
| 交互与交付 | 收口 P03 多关联呈现、各入口条件传递及状态恢复。确定完整商品表与合作详情等最终布局的设计输入。排期待核定 |

Spec 建议按「频道视频关联」「品牌 TAB 查询与表现」「商品详情关联视频」「共用口径」组织。对应 P03、B01／P01／P02／P04／S01／V01、P05／V04／V06 及跨入口的一致性规则。
