# v7.6.4 内容监控标签分组与管理 · Demo

从浏览器直接打开 `index.html` 可运行。也可在 drafts 工作区启动发布目录的静态预览。

```bash
python3 -m http.server 8768 --bind 127.0.0.1 --directory publish
```

启动服务后访问 `http://127.0.0.1:8768/demos/monitor-764/index.html`，默认打开示例项目及视频标签筛选器。[项目内容](./index.html?view=content) 直接进入内容列表，[标签管理](./index.html?view=manage) 直接进入配置。

| 想验证 | 操作 |
|---|---|
| 选择与分组 | 在「内容类型」选「开箱测评」「教程指南」，再选「表现跟进」的「重点跟进」。默认每组至少命中一个标签。点击底部「组内任一 · 组间全部」，可以分别修改两个关系再应用 |
| 分组快捷下拉 | 打开「视频标签」，在「额外标签」等组的名称旁点空心图钉，打开该组的独立下拉。点独立下拉组名旁的实心图钉，主下拉会展开并定位该组，已选草稿和已应用筛选保留 |
| 全局无标签 | 先用主下拉或快捷下拉筛选，再在主下拉选「无标签」并应用。所有快捷下拉清除已选标签并显示全局状态。选择任一快捷组标签并应用可切回普通标签筛选 |
| 个人置顶 | 在选择器目录行点图钉即可置顶或解除。悬停「我的置顶」中的标签，点右上角「×」可直接解除。切换右上角身份，可以看到每个账号各自的置顶 |
| 整理定义 | 分组按单列排列。悬停标签行或组标题后，拖动最左侧手柄排序或移动。拖到另一组时先确认项目影响，按组排序时临时收起标签，结束后恢复原展开状态。也可点击手柄或按 Enter 用表单定位 |
| 原行编辑 | 悬停标签行后，从「更多」选择「编辑标签」。名称与颜色共用一个控件，取消／保存紧随其后。同一菜单也可删除标签 |
| 组内新建 | 悬停组头后点「＋」，折叠组会展开，组尾出现相同样式的单行编辑器。按 Enter 或点「创建」即可保存到该组。「未分组」也可直接创建 |
| 管理并返回 | 在选择器勾选标签，点「管理标签」进入统一标签目录。配置后选「返回选择标签」，继续原来的选择 |
| 单条／批量 | 通过某一行的「编辑标签」同时编辑普通标签和原额外标签。选中多行后体验「添加标签」与「移除标签」 |
| 新增监控 | 选择「新增监控」，填样例标题并暂存视频标签，确认创建后检查对应的内容及标签 |

只使用合成项目与内容。顶栏的身份切换演示管理员和没有共享定义维护权限的项目成员，两个身份都具有样例项目的内容写权限。原两类额外标签归入同一个「额外标签」组。浏览器本地存储记录本机样例、折叠状态、个人置顶与快捷入口，清除该页面站点数据可恢复初始状态。配置弹窗中的影响数量来自本 Demo 内容样本。产品接入通过 [Spec 验收矩阵](../../documents/02-project-documents/monitor_764/spec_v1.md#61-验收矩阵) 核对服务端和灰度表现。

## 浏览器验收

2026-11-24 使用 Playwright 驱动 Chrome，验证了分组搜索和折叠恢复、管理往返保留草稿、建组和标签移组、角色的个人置顶隔离、单条及批量关系修改和创建监控。

390、768 和 1440 px 视口的页面及弹层通过边界检查，验证了搜索初始焦点、Tab 循环、Esc 返回和直接打开 HTML。浏览器主流程检查未出现本地资源错误或 JavaScript 异常。

本轮补验了组内和组间的四种组合及新增默认值、无标签的独立筛选、标签跨组确认与取消、组内排序、拖动组时临时折叠和恢复、顺序刷新持久化、触摸及键盘操作，以及标签颜色在管理、选择器和内容列表中的同步。

原行编辑版本另验证了折叠组和「未分组」新建、重名和取消保留原值、键盘打开和关闭色板。布局验收覆盖 320、390、768、1440 px，检查原行等高、色板打开时列表无位移，以及切换编辑行时保留未保存修改。

统一目录版本验证了两类旧额外标签在本地样例中的迁移幂等、原有 ID／绑定／个人置顶保留，以及统一目录在筛选、单条、批量和手动新增中的可用性。快捷入口回归覆盖 3 项上限、主次视觉、按账号隔离、刷新保留、组改名与删除、取消入口后筛选保留、组内清空、无标签互斥及移组后的筛选快照。生产历史条件、权限及迁移回退走独立的联调验收。

主下拉与快捷下拉联动回归覆盖目录、搜索、置顶、已选项和计数去重，取消快捷后回到主下拉，主下拉清空保留快捷组条件，页面清除移除全部条件，以及打标入口仍能选用快捷组标签。

组标题行的空心图钉和独立下拉的实心图钉已通过鼠标、键盘和触屏验证，覆盖 320–1440 px、3 项上限、焦点定位、草稿保留和账号隔离。
