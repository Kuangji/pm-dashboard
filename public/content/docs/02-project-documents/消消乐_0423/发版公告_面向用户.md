# 发版公告｜XXL0423 多模块体验优化上线

尊敬的用户：

在 **XXL0423** 热更新版本中，我们对搜索、频道详情页、内容监控、TTS、跨境支付和竞品监控等多个模块进行了细节优化，重点围绕 **筛选更好用、列表更好看、数据更稳定、操作更顺手** 进行升级。

本次更新后，您在搜索和详情页中可以使用更多筛选条件与排序方式，更快找到目标频道和商品；在内容监控与支付管理中，也能减少重复操作、提升处理效率；同时，部分统计图表和参考值更新机制也做了优化，帮助您获得更稳定、更准确的数据体验。

## 本次更新内容

### 1. 搜索与频道详情页支持更多筛选、排序和判断方式

- 频道搜索筛选项新增 `30天基准的预估曝光量`，方便更快按近期表现筛选频道
- `品牌账号相关` 筛选升级为三档：`全部`、`只看品牌账号`、`不看品牌账号`
- 频道详情页新增 `不感兴趣` 按钮，和搜索结果页保持一致，方便统一处理不想继续查看的频道
- YouTube 频道详情页的 `内容数据` Tab 新增 `平均观看量` 指标，帮助更快判断内容表现
- TikTok 网红详情页的 `带货商品` 列表新增搜索框与商品类别筛选，支持按产品名、产品 ID 查找商品
- TikTok 网红详情页的 `带货商品` 表格新增销量、销售额、关联视频数排序能力

### 2. 多个列表与详情页的数据展示更清晰

- TTS 商品榜、店铺榜列表中的销量表头去掉 `（估）` 字样，展示更简洁
- TTS 店铺详情页中，带货视频列表的 `发布时间` 列新增排序能力，且默认按发布时间倒序展示
- 频道国家相关数据优化了多字段取值的搜索和展示策略，减少国家信息不一致带来的理解成本
- 频道详情页的参考值增加定期更新机制，并优化了参考值取值范围，帮助您看到更合理的对比结果
- 竞品监控的 `合作网红列表` 新增 `合作视频播放量` 筛选项，同时表格中新增对应字段列

### 3. 内容监控和图表数据体验优化

- 在 `新建监控 > 自动追踪规则` 中，追踪频道下拉列表里的每个网红支持直接打开详情页，方便边看边选
- 在 `添加监控` 时，系统会记住您上一次选择的监控时长，下次打开时自动选中，减少重复设置
- 视频监控统计图表在遇到个别日期数据缺失时，会进行平滑处理，减少图表断点对阅读的影响

### 4. 跨境支付操作更灵活

- 支付单新增 `复制为草稿` 功能，方便基于已有单据快速复用并继续编辑
- 预约发送的支付单新增 `手动放行` 功能，便于在需要时更灵活地控制后续处理节奏

### 5. 全站日期筛选补充快捷选项

- 所有日期选择器新增 `本年度` 快捷选项，范围为 `今年 1 月 1 日至今天`
- 在需要查看年度累计数据或进行年内复盘时，操作会更方便

## 如何使用

### 使用新增筛选和排序能力

1. 进入频道搜索、频道详情页、TikTok 网红详情页或竞品监控相关页面
2. 在筛选区查看新增条件，例如 `30天基准预估曝光量`、`品牌账号相关`、`合作视频播放量`
3. 在列表表头中按需使用新增排序能力，快速调整结果顺序

### 使用内容监控与支付管理的新操作

1. 在内容监控中创建自动追踪规则或添加监控时，直接使用新增的快捷交互
2. 在支付管理中打开已有支付单，按需选择 `复制为草稿`
3. 对预约发送中的支付单，如需提前处理，可使用 `手动放行`

## 温馨提示

- 本次为 `XXL0423` 热更新，更新内容分布在多个模块，不同账号看到的入口会因权限或套餐范围有所不同
- 部分新增能力属于现有页面内的筛选、排序和交互优化，不会改变您原有的主流程
- 图表平滑处理仅用于改善缺失日期下的展示连续性，不代表原始数据被修改
- 频道详情页参考值和国家字段展示策略优化后，您在不同页面看到的数据口径会比之前更统一
