# 发版公告｜v7.4.1 其他社媒搜索支持 Twitter (X) 搜索与详情页

尊敬的用户：

在 **v7.4.1** 版本中，我们对「其他社媒搜索」中的 **Twitter (X)** 能力进行了升级，正式支持 **站内搜索真实 Twitter 账号**，并新增 **Twitter 频道详情页**。本次更新希望帮助您在 NoxInfluencer 内更顺畅地完成 Twitter 创作者的发现、初步判断与进一步查看，减少反复跳转站外带来的操作成本。

本次更新后，您可以在「其他社媒搜索」中直接搜索 Twitter 账号，结合类别、地区、粉丝量等条件快速缩小范围；在结果列表中，也可以直接查看账号核心数据与近期内容预览，并进入新的 Twitter 频道详情页，继续查看数据总览和内容表现。

## 本次更新内容

### 1. 其他社媒搜索支持真实 Twitter 账号搜索

- 在「其他社媒搜索」中切换到 `Twitter` 后，系统会直接返回真实 Twitter 账号结果
- 搜索结果对象从原来的关联展示升级为可直接识别与判断的 Twitter 账号
- 支持结合 `频道类别`、`频道地区`、`粉丝量` 等条件进行筛选，帮助您更快找到目标账号
- 当您没有输入搜索条件时，页面会展示默认推荐/热门账号列表，方便直接开始浏览

### 2. 搜索结果页新增更完整的账号信息与内容预览

- 结果卡会展示头像、频道名、`@handle`、频道地区、频道类别等基础识别信息
- 同时展示粉丝数、内容总数、平均互动率、预估曝光量等核心判断指标，帮助您快速评估账号价值
- 支持查看近期 Tweet 预览：有媒体内容时优先展示缩略图，无媒体内容时展示文本卡片
- 点击 `头像`、`频道名` 或 `@handle`，即可进入对应的 Twitter 频道详情页

### 3. 新增 Twitter 频道详情页

- 新增站内 Twitter 频道详情页，承接从搜索结果进入后的进一步查看需求
- 在详情页中，您可以查看账号的核心摘要信息，例如粉丝量、最近发布时间、平均曝光量、平均互动率等
- `数据总览` 分区支持查看账号整体表现与增长趋势，帮助您快速完成基础判断
- `内容数据` 分区支持查看内容标签、发布时间频率，以及全量内容列表，方便继续了解账号近期发文方向与表现

## 如何使用

### 搜索 Twitter 账号

1. 进入 `搜索`
2. 选择 `其他社媒`
3. 切换到 `Twitter`
4. 输入关键词，并按需结合 `频道类别`、`频道地区`、`粉丝量` 等筛选条件进行搜索

### 查看 Twitter 频道详情页

1. 在搜索结果中找到感兴趣的账号
2. 点击账号的 `头像`、`频道名` 或 `@handle`
3. 进入详情页后，查看 `数据总览` 与 `内容数据` 分区
4. 如需进一步查看具体内容，可在内容列表中按发布日期或互动表现继续筛选与排序

## 温馨提示

- 本次更新重点为 `Twitter` 链路升级，`Facebook` 的现有能力保持不变
- 若当前搜索条件下暂无符合结果，页面会展示“暂无搜索结果”空态
- `受众组筛选` 入口目前已预留，但暂未正式开放，后续版本将逐步补齐
- Twitter 详情页中的 `受众数据` 与 `品牌数据` 分区当前为预留展示位，后续会继续完善
- 若部分账号的数据尚未采集完整，个别聚合指标可能显示为 `暂无数据`
