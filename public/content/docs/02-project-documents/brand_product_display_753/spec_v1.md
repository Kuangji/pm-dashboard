## 1. 频道视频关联 · P03

适用页面为 YouTube 频道详情。

| 入口 | 展示与查询 | 边界 |
|---|---|---|
| 「内容数据」视频卡 | 沿用原视频卡，显示品牌／商品关联数量。点击标记查看同一视频的品牌列表和商品列表 | 关系按当前视频身份获取。卡片数量与展开后的对应集合一致。内容 TAB 保有原有日期、内容类型等筛选 |
| 「品牌数据」→ 品牌合作详情 → 视频卡 | 沿用现有合作视频和组内筛选，在卡下展示品牌与商品。多商品可逐项查看 | 来源品牌限定进入合作详情的视频集合。卡下关系指该视频全部可见的已收录关系，可包含其他品牌或商品 |
| 视频的关联商品行 | 商品标题进入商品详情，其余可交互区域打开当前频道与该商品的视频明细 | 复用 P04，来源若在品牌 TAB 则继承品牌 TAB 时间。普通内容来源如何映射列表范围见 §5 |

- 品牌、商品关系各自去重并独立展示。支持多品牌多商品、单关联、只关联品牌或只关联商品。商品所属品牌使用明确的商品资料，经同视频提及的品牌保持独立。视频的推广类型和 AD 标识沿用已有分类。
- 视频关系应随列表批量返回或批量查取。若只返回来源品牌子集或部分商品，明确展示覆盖状态，合计及展开内容使用同一可见集合，避免显示为完整关联。
- 已确认没有关联时省去空标记，只有一类有记录时展示可用的那类。关系未提供、资料缺字段、权限受限分别处理。名称或详情标识缺失时展示可用资料，链接只对有有效目标及权限的实体启用。
- 数量标记文案、换行方式、轮播密度、卡高与列数由设计评审。应支持键盘打开和关闭后恢复到来源位置。

## 2. 频道品牌数据 TAB

### 2.1 时间上下文 · S01

适用页面为 YouTube 频道详情。品牌 TAB 顶部提供一个时间选择值。品牌提及表与总数、合作视频、广告内容统计和对照、原观看表现图、发布数量视图、完整商品表、商品分类图、频道商品视频抽屉均使用该时间上下文。报价和合作效率按各自业务口径计算。频道总览、内容、受众及独立商品详情继续使用各自的范围。

品牌 TAB 选项暂按 Demo 的近 7 天、1 月、3 月、6 月、1 年编写，默认近 6 月，作为待核配置。按日历月计算的近 6 月和滚动 180 天分别保留定义。换时间后按新范围重取相关数据，分页表回到第 1 页，保留仍适用的筛选、排序和每页容量，清除旧发布选段。源范围切换期间只展示与当前条件匹配的结果，迟到的旧响应不得覆盖新条件。

### 2.2 品牌提及与频道商品 · B01、P01、P02、P04

| 区域 | 适用页面 | 查询与展示规则 |
|---|---|---|
| 品牌提及表 · B01 | YouTube 频道详情 | 品牌总数取当前时间、品牌名搜索及推广类型过滤后的去重品牌数，表底左侧显示「共 N 个品牌」，与右侧分页同行。翻页及改每页数量保持总数。合作详情维持来源品牌和频道上下文 |
| 品牌提及表 · B01 | Instagram 频道详情 | 表底左侧显示「共 N 个品牌」，与右侧分页同行。直接读取现有 `channelBrandList.totalSize`，沿用现有查询范围、品牌名搜索、推广类型筛选、分页和权限。以当前表格可分页的结果总数为准，翻页及改每页数量保持总数。成功查询为空时显示 0，加载失败或受限沿用既有状态 |

- YouTube 品牌合作详情的「查看推广商品」携带来源品牌、本频道和品牌 TAB 时间，定位完整商品表并回第 1 页。视频形式、提及方式和品牌表条件仍作用原入口。保留目标商品表的排序及每页容量。

## 3. 商品详情「关联视频」· P05、V04、V06

适用页面为通用商品详情（当前为 Amazon）。以该商品已收录且有权限查看的关联内容为基础，各模块共用相同的资格范围。

### 3.1 条件作用域

| 条件 | 总览和两张占比图 | 发布趋势 | 完整视频清单 |
|---|---|---|---|
| 商品、商品页时间 | 生效 | 生效 | 生效 |
| 网红频道 | 生效 | 生效 | 生效 |
| 趋势选中时间段 | 保留整段 | 保留整段，标出选中柱 | 筛至对应时间段 |
| 趋势粒度 | 保留 | 重分桶 | 清除旧选段并恢复范围 |
| 清单排序、分页 | 保留 | 保留 | 生效 |

- 每次从商品标题打开默认全部频道。可搜索、选择或清除一个频道，显示当前频道和商品页时间范围。候选来自当前商品范围内可查的关联网红，须能检索前几名之外的频道。是否保留历史已选但当前无记录的频道见 §5。
- 沿用 Amazon 商品页已有的时间选择器。代码中的档位为近 7／14／30／90／180 天，默认 180 天，时间值由「关联视频」与「关联网红」共用。新增的频道筛选仅作用于「关联视频」。商品基础资料保持原口径，切换 TAB 往返保留视频侧频道和清单状态。
- 切换／清除频道或改变商品页时间后回第 1 页，保留排序、粒度与每页容量，清除旧选段。点非零柱和清选段同样回第 1 页。排序仅影响完整清单，排序切换回第 1 页并保留当前频道、时间段、粒度和页容量。

### 3.2 统计和完整视频清单

| 区域 | 规格 |
|---|---|
| 总览 · V06 | 总播放量、总内容量、总评论数、总点赞量按当前商品、频道、商品页时间内的有效去重视频集合取值。内容量取视频数，其余取对应当前累计值的合计 |
| 占比 · V06 | 复用自然传播、付费推广、疑似付费推广分类。内容占比用同集合视频数为分母，播放量占比用同集合总播放量为分母。缺分类或分母时呈现对应状态，避免把已知子集当成全部视频 |
| 发布趋势 · V04 | 对同一集合按发布时间统计发布视频数，支持日／周／月。非零柱选段后，完整清单总数与柱值一致，清除后恢复当前频道整段范围 |
| 完整清单 · P05、V06 | 一份列表承接原播放量、点赞、评论三组榜单。字段保留缩略图、标题、日期、频道身份、播放、点赞、评论和视频入口。默认发布时间最新优先，另可按播放量、点赞量、评论数降序 |

先按当前条件取完整集合并去重，再排序和分页。趋势选段仅叠加在清单的查询条件中。完整清单总数与当前位置的筛选一致，能遍历全部符合条件的记录。

## 4. 共用数据与验收规则

### 4.1 关系、数值与状态

以下数据规则适用于 YouTube 频道详情和通用商品详情的新增能力。Instagram B01 使用 §2.2 的现有品牌提及表口径。

- 后端应以业务实体 ID 及平台标识匹配关系，明确频道、商品和视频归属。单个查询集合内同一视频只计一次。跨商品行或品牌行相加会重复计入共享视频，频道合计应直接在去重集合上计算。
- 同一入口的数量、指标、排序、图表和对应明细使用相同资格、去重和时间条件。发布趋势只统计视频发布时间内的发布量，观看、点赞和评论是所选视频的累计值。每个时间桶与其明细用同一时区和时间边界。
- 总观看量对合格视频的观看量汇总。总体互动率复用平台现有聚合，YouTube 现有总体互动率为（累计点赞之和＋累计评论之和）÷累计观看之和，返回小数比例。P02 按该口径复用，以百分比展示，目标字段映射与缺值传播需核实。分母为 0 时无有效互动率，展示时区分零值与未提供。
- 排序以原始数值为准，已知 0 正常参与，缺失始终在后。同值用稳定的后端次序，跨页保持一致。表格、明细、趋势及候选查询均在完整符合条件的集合上运行。
- 权限由当前访问入口及资源范围决定，关系明细和汇总使用兼容的资格。沿现有权限策略处理受限、错误和重试。上游接口截断或只返回 TopN 时，不将该结果作为全量。

| 数据状态 | 指标/图表 | 明细与入口 |
|---|---|---|
| 已知空集合 | 完整查询确认空时，件数、条数和已提供的累计总量为 0。发布空桶为 0，占比无有效分母 | 展示当前条件无已收录记录 |
| 有记录且指标确为 0 | 展示 0，排序正常参与。零分母的比率无值 | 记录仍可查 |
| 关系、字段或分类缺失 | 缺失单独呈现。完整总量中有任何必需值缺失时，显示总量未提供。若另行展示已知部分，明确标示覆盖范围 | 已知记录可以显示，缺失部分按对应状态标示 |
| 受限或请求失败 | 使用现有权限／错误状态。示例数据或上一次成功结果仅可明确标成示例或旧数据 | 明细访问也须通过入口与资源权限 |
