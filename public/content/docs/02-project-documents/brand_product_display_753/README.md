## 研发评审清单

先看能否从一条视频找到关联品牌和商品，再看能否从频道或商品查回对应视频、比较内容表现。各项章节号对应 [第二轮 Spec](spec_v1.md)。

本期完整覆盖 YouTube 频道和通用商品详情（当前为 Amazon）。Instagram 频道仅做 B01。TikTok 频道与 TikTok Shop 商品详情纳入回归检查。

### 频道详情 · 视频关联

- [ ] **P03 从视频查看关联品牌与商品（§1）**
  - **适用平台** YouTube 频道详情。
  - **功能意图** 看到一条视频时，能直接查到它提到哪些品牌、关联哪些商品。浏览普通内容时保持卡片简洁，查看品牌合作时则能在卡片上直接看到关联。
  - **评审重点** 用同一条包含多个品牌和商品的视频，对比「内容数据」的数量标记与抽屉，以及「品牌数据」合作详情的卡下展示。两处都应能查看完整关联，重点看标记和多商品入口是否容易找到。[双 TAB 视频卡](../../../demos/brand-product-display-753/index.html#point=P03)

### 频道详情 · 品牌数据

- [ ] **S01 统一品牌数据的统计时间（§2.1）**
  - **适用平台** YouTube 频道详情。
  - **功能意图** 选定一段时间后，用户可以用同一时间范围比较这个频道提及的品牌、推广的商品及相关视频，也能从汇总数字查回对应明细。
  - **评审重点** 切换「品牌数据」的时间范围，看统计、图表、列表和视频抽屉是否都按该范围展示。独立商品详情使用自己的时间选择器。[品牌 TAB 时间](../../../demos/brand-product-display-753/index.html#point=S01)

- [ ] **B01 显示筛选后的品牌总数（§2.2）**
  - **适用平台** YouTube / Instagram 频道详情。
  - **功能意图** 用户筛选品牌名或推广类型后，能一眼看到有多少品牌符合条件。YouTube 另外按品牌 TAB 所选时间统计。
  - **评审重点** 在表格左下角、分页同一行查看「共 N 个品牌」。翻页或调整每页数量时沿用同一总数。YouTube 的总数随品牌 TAB 时间更新。Instagram 直接使用现有品牌表的分页总数，沿用原有统计范围。[品牌提及表](../../../demos/brand-product-display-753/index.html#point=B01)

- [ ] **P01 查看频道推广过的全部商品（§2.2）**
  - **适用平台** YouTube 频道详情。
  - **功能意图** 打开「推广商品」即可先浏览观看量较高的商品，再用同一张表翻页或按品牌查完整记录。查看品牌合作详情时，可以直接查这个频道推广过该品牌旗下的哪些商品。
  - **评审重点** 原「推广商品」区首屏直接展示完整表，替代独立 TOP5 卡。品牌筛选和翻页只影响表格，商品分类图展示所选时间内的全量分类。从合作详情点「查看推广商品」，看是否定位到同一张表并带入当前品牌和时间。[全部推广商品](../../../demos/brand-product-display-753/index.html#point=P01) · [品牌合作详情入口](../../../demos/brand-product-display-753/index.html#brands)

- [ ] **P02 比较商品关联视频的表现（§2.2）**
  - **适用平台** YouTube 频道详情。
  - **功能意图** 用户可以在同一频道、同一时段比较不同商品的关联视频累计获得了多少观看，以及观众互动的相对表现。
  - **评审重点** 默认按本频道关联视频总观看量降序。点击当前列切换升降序，换到互动率时先按降序。筛选后先对全部匹配商品排序，再分页。真实 0 参与排序，缺失排在末尾。[商品表现与排序](../../../demos/brand-product-display-753/index.html#point=P02)

- [ ] **P04 从商品行查看本频道视频（§2.2）**
  - **适用平台** YouTube 频道详情。
  - **功能意图** 用户在商品行就能看出商品属于哪个品牌、这个频道有多少条相关视频。想查视频时可留在频道页，想进一步了解商品时可打开商品详情。
  - **评审重点** 在商品表分别点击商品标题、图片和视频数。标题进入商品详情，其他可交互区域打开本频道的视频抽屉。正式口径要求行内视频数与抽屉总数来自同一组视频。[商品行与视频抽屉](../../../demos/brand-product-display-753/index.html#point=P04)

- [ ] **V01 查看频道发布相关视频的节奏（§2.3）**
  - **适用平台** YouTube 频道详情。
  - **功能意图** 用户既能看频道视频的观看表现，也能看与品牌或商品有关的视频集中发布在哪些时段，并查到那段时间发布了哪些视频。
  - **评审重点** 在原「非推广 vs 推广」模块切换「观看表现」和「发布数量」。在发布数量视图按品牌、商品筛选并切换日／周／月，点有记录的柱子打开对应视频抽屉。[频道对比图](../../../demos/brand-product-display-753/index.html#point=V01)

### 商品详情 · 关联视频

- [ ] **P05 查看商品关联视频并筛选频道（§3）**
  - **适用平台** 通用商品详情（当前为 Amazon）。
  - **功能意图** 从商品出发查看所选时间内全部已收录的关联视频，也可以专门查某个频道围绕这件商品发过哪些视频。
  - **评审重点** 从商品标题进入时默认展示全部频道。搜索并选择一个频道，试清除条件、翻页和打开视频。[完整关联视频与频道筛选](../../../demos/brand-product-display-753/index.html#point=P05)

- [ ] **V04 查看商品关联视频的发布趋势（§3）**
  - **适用平台** 通用商品详情（当前为 Amazon）。
  - **功能意图** 用户能看出一件商品的关联视频在哪些时段发布得更集中，也能选定一个频道并下钻到具体时段的视频。
  - **评审重点** 趋势随频道筛选更新，支持日／周／月切换。点有记录的柱子只筛下方视频清单，总览和占比仍按整段统计。清除选段后，清单回到当前频道的整段范围。正式口径要求选段后的清单总数与柱值一致。[商品发布趋势](../../../demos/brand-product-display-753/index.html#point=V04)

- [ ] **V06 按频道查看商品内容表现并排序（§3）**
  - **适用平台** 通用商品详情（当前为 Amazon）。
  - **功能意图** 选定频道后，用户能同时了解它围绕这件商品的内容规模、观看和互动表现，再用同一份清单找出最新、播放最高或互动较多的视频。
  - **评审重点** 在「关联视频」内切换频道，观察四项总览（播放、内容量、评论、点赞）和两张占比图是否一同更新。原三组榜单合入清单，默认最新优先，可按播放、点赞或评论降序。选段和排序只影响清单。[商品总览联动与清单排序](../../../demos/brand-product-display-753/index.html#point=V06)

Demo 用虚构数据演示交互。商品详情时间固定为近 180 天样例，Spec 要求复用现有商品页时间选择器。P03 的多关联排布留到设计评审，生产时间口径、权限及全量查询见 [Spec 待确认项](spec_v1.md#5-现状证据与-spec-待确认)。
