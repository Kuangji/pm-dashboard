## 已确认的目标与范围

- 在网红频道详情页扩展品牌、商品相关指标，帮助用户查看频道的品牌商品推广情况。
- **最高优先级：在详情页查看某条内容/视频时，能明确它关联了哪些品牌和商品（2026-11-16 用户补充）。** 先解决内容与品牌、商品之间的关联可见性，商品完整清单和表现指标随后讨论。
- 尽量复用品牌报告与频道现有数据指标或简单变种，不引入新的复杂计算方式。
- 优先改扩现有功能；新数据模块必须先确认它能帮助用户作出的具体判断，再决定是否纳入。
- 渐进讨论、逐点实现。每次讨论结果先写入本 Input，再同步对应 Demo；未讨论的候选保持待讨论，不一次冻结全部指标、平台或布局。
- 使用独立审阅 Demo：参考账号权限 Demo 的左导航、中示意、右说明结构，每点可填意见和导出，仅内存会话；不连接真实页面或生产数据。
- 功能示意须尽量与线上对应功能保持相似，便于评审对号入座（2026-11-16 用户补充）。外层保留评审工具；中间沿用线上模块名称、层级、布局、控件、列序、入口与展开方向。模拟数据明确标注，不把“示意”解释为可自由改写已有交互。
- 本轮保留品牌提及表、合作详情抽屉和商品 Top5 / 分类参照，并增量实现P03双TAB视频关联方案；不补整站导航、完整频道页或完整品牌报告；本轮追加商品详情中的关联视频模块示意。候选说明及审阅工具控件不算候选业务功能已实现；按改动点审阅，不编写用户故事。
- 后续各点的已确认增量直接落在对应的线上模块结构内，便于对照现状与修改；不因评审工具形式另造抽象业务界面。

## B01｜品牌数量（2026-11-16 已确认，低优先级）

- 在现有品牌表格底部，与分页同一行显示“共 N 个品牌”。总数左对齐，分页右对齐；不在标题旁增加数量，不新增统计卡片。
- 复用当前筛选条件下去重品牌的列表总数，不按当前页行数计数。切换分页或每页数量不改变总数；搜索、推广类型筛选后更新对应总数，无结果显示“共 0 个品牌”。
- Demo 初始三个品牌显示“共 3 个品牌”；这是虚构样例中的示意，不将样例数量当作线上规模。
- 用户判断：改动很小、优先级不高。完成此点不提升其他品牌候选的优先级。
