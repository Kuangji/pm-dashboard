## 线上功能对应要求（2026-11-16 历史参照）

- 品牌区外层为「品牌提及」，卡内为「提及品牌」。沿线上保留「选择推广类型」和「按品牌名搜索」；表头顺序为品牌 / 推广 / 互动率 / 总观看量 / 上次视频时间 / 预算 / 提及视频。排序、品牌 Logo/域名、视频缩略图、页码与每页条数按既有组织方式示意。
- 点击品牌行对应右侧 654px「合作详情」抽屉；已有总观看量、平均观看量、互动率及「内容形式」「提及方式」筛选。品牌名/Logo保留品牌报告占位；频道商品标题进入本地商品详情示意，商品图片、视频数及其余行区域打开本频道商品视频抽屉。不连接真实报告或生产接口。
- **已有抽屉均播是现状能力。B02 仅指是否前置到品牌列表**，恢复该抽屉不算 B02 实装，也不重新提出均播计算模型。
- 商品区保留「推广商品」标题，下方两张等宽白卡：左侧「TOP5视频观看量最多」，右侧「商品分类」环形图与图例。商品图、标题、分类、橙色价格、播放图标和缺失观看值沿线上层级；缺失保持“--”。两块空态各自保留卡片。
- 原 Top5 标题与缺少观看值/排序不一致继续放在模块外的评审说明，具体改名或排序等待讨论，不提前决定 P02。
- 审阅导航、候选状态、意见与导出放在业务模块外；不补完整频道或整站导航。窄屏允许模块内横向滚动或必要单列适配，不宣称复现线上固定桌面最小宽度。

## 2026-11-17｜品牌商品联动验收

- 全部推广商品表有独立商品品牌选择器，默认全部品牌，具体品牌、未知品牌及清除可操作；先完整集合筛选再分页，total随结果更新，切换/清除回第1页，每页容量保留。
- 合作详情“查看推广商品”关闭原抽屉，跨Demo子页进入推广商品，定位完整商品表并预选该品牌，焦点到筛选控件；带入当前品牌/频道；范围随S01方案收口，不带视频形式和提及方式条件，商品窗口随S01待确认范围方案收口。
- 依据商品明确所属品牌ID，不能用视频提及品牌集合归属商品；未知不猜。品牌表搜索不隐式影响商品，Top5/分类也不跟随商品表筛选。
- 商品标题仍跳详情，其余行区域仍开当前频道/商品的视频抽屉，关闭后品牌条件保留。空结果、缺失字段、清除/分页及窄屏可达；file协议下可操作。
- Demo为全量12件内存集合；生产品牌筛选参数、过滤后totalSize与同窗分页接口仍须核验，不宣称前端筛当前页即可完整查询。

## 2026-11-17｜P02 两项商品表现列验收

- 完整商品表追加“本频道关联视频总观看量”“互动率”，两列各支持表头首次降序/再次升序、可访问aria-sort；不新增均播。
- 先品牌筛完整集合、按原始数值稳定排序、再分页；排序切换回首页，保留品牌/页容量，品牌切换/清除/合作详情定位保留排序。两种方向都把null放最后，缺失显示“--”，0观看量可显示0，0互动率仅用于有观看而无互动；零观看分母的互动率仍为空。
- Demo读取固定模拟聚合，汇总对应当前频道该商品完整关联集合，不从当前视频页聚合；真实总体互动率沿现有(点赞+评论)/观看及比例单位，不取逐视频比率平均。
- 标题/行视频抽屉双行为、其他既有模块不变；完整表允许内部横向滚动。Top5内部排序按文末最新确认收口。
- 所有验收直接打开file URL，runner不创建HTTP服务器；检查原功能回归和运行文件哈希后才更新发布包。

## 数据与设计边界

- 提及不等于实际付费合作，预估预算不是实际付款；品牌报告跨频道指标不得直接当作单频道数据。
- 不新增评分、预测或成交归因模型；Amazon 资料没有本频道成交归因，TikTok 沿已有带货返回及校准口径。
- 价格保留原币种，缺失不解释为免费；多商品视频的频道汇总须按视频去重。
- 11 月 13 日历史事实、11 月 16 日补充复查、静态代码能力、模拟示意与候选分别标明；Demo 可打开不代表候选批准或上线。
- 遵循同级设计规范：[入口](../../../../../kol2.0-design-specification/README.md)、[语义 Token](../../../../../kol2.0-design-specification/playbook/semantic-tokens.md)、[原始 Token](../../../../../kol2.0-design-specification/playbook/tokens.md)、[表格](../../../../../kol2.0-design-specification/playbook/components/table.md)、[Tabs](../../../../../kol2.0-design-specification/playbook/components/tabs.md)、[Element UI 对齐](../../../../../kol2.0-design-specification/playbook/element-ui-alignment.md)。审阅壳与产品示意层级可辨识，沿已有组件状态，桌面优先、窄屏可达，不臆造既定规范。
