# 内容监控标签｜一致性与视觉评审

2026-11-24 · 本地 Demo 评审通过 · 发布版本待排期

对照当前 [需求输入](../input_v1.md)、[实施规格](../spec_v1.md)、[交互设计](../design_v1.md) 及 [独立 Demo](../../../../demos/monitor-tag-organization/index.html)。本轮结果用于正式研发评审文档。生产 ACL、存量查询回放、迁移、联调和回退按实施规格单独验收。

## 1. 一致性评审

| 级别 |对照发现 | 处理 |
|---|---|---|
| High | 删除活动条件或单条移除后，已经离开筛选结果的内容仍可能留在批量选择中 | 结果变动后重验选中内容，批量提交仅处理仍可见的目标。主动删除命中当前筛选时在删除确认中说明条件及结果变化 |
| High | 迁移保留标签 ID，但旧同名标签缺少来源提示 | 保留旧来源，冲突时补显示来源，同一来源重名再补 ID。回归同名标签独立选择及绑定 |
| Medium | 切换主下拉和快捷下拉后，部分草稿变更会随当前应用一起提交 | 延续共享草稿，在底部提示其他待应用条件 |
| Medium | 有原行修改时从标签管理返回，草稿会被直接清空 | 离开管理、切换身份或进入分组编辑前，请先处理当前原行草稿 |
| Medium | 规格里对无标签可见范围、旧入口写入、个人置顶来源及搜索规范化的表述需要统一 | 更新规格并纳入正式 PRD 的迁移及上线验收 |

实际走过 14 组 Chrome 浏览器回归。覆盖统一目录及本地迁移、布尔关系四种组合、无标签全局联动、快捷上限与账号隔离、组内和跨组拖动、管理往返、选用入口、紧凑置顶区、已应用条件的主动删除、历史同名及批量目标复核。关键退出路径使用了键盘和触屏。

| 验收项 | 已验证 | 研发还需验证 |
|---|---|---|
| A01、A04 统一目录与重名 | 模拟旧两类额外标签合并，迁移幂等，ID、绑定、置顶保留。同名显示来源，必要时补 ID | 逐字典映射、真实存量冲突、旧写入路径、前后数据对账 |
| A02、A03、A09 管理、置顶与可访问性 | 组和标签拖动、临时收起、手柄不推挤名称、个人置顶及键盘和 320–1440 px 视口 | 真实大字典、客户端与网络性能、语言及浏览器兼容 |
| A05、A10 共享筛选与快捷 | 四种关系、无标签、入口去重、同一草稿、应用和清除范围、顺序、改名和删除 | 服务端与看板、导出、结果全选一致，真实账号和字典 ACL，旧条件回放 |
| A06、A07、A08 写入、权限及回退 | 单条、批量、手动新增，筛选变化后剔除不可见目标。角色切换及原行草稿保护 | 真实不可编辑和隐藏关联、批量部分失败、导入导出和回退演练 |

## 2. 视觉评审

基线使用聚星的标签、按钮和下拉规范，以及本轮前已复查的主筛选、管理单列和原行色板截图。用 Chrome 在 320、390、768、1024、1440 px 核查边界、信息层级和交互后的几何稳定性，并人工查看关键截图。评分 96／100，通过。

| 画面 | 检查结果 | 截图 |
|---|---|---|
| 主下拉 | 搜索与管理同行，组标题、图钉和计数对齐。置顶区紧凑，已选和主操作留在固定底部 | [桌面 1440](assets/主筛选-1440.png) · [窄屏 390](assets/主筛选-390.png) |
| 快捷下拉 | 共用标签图标，主次由浅底与线框区分。一次显示 3 个组时工具栏可换行。全局无标签状态在工具栏和快捷下拉底部均可辨认 | [桌面工具栏](assets/快捷工具栏与全局无标签-1440.png) · [窄屏快捷下拉](assets/快捷筛选与全局无标签-320.png) |
| 共享管理 | 单列保持稳定，悬停时左右控件出现，名称起点不移动。原行名称、颜色及操作在同一行，色板不超出窄屏 | [管理单列](assets/管理单列-1440.png) · [320 px 原行改色](assets/原行改色-320.png) |
| 跨组确认 | 原组、目标组和影响条目数各自有明确位置，取消优先聚焦 | [影响确认](assets/标签换组确认-1440.png) |

第一轮发现窄屏 Toast 过早折行，已调整为按内容宽度居中，再受视口宽度限制。复测覆盖短提示单行和视口边界。320 px 表格按设计独立横向滚动，选择器和管理外层无横向溢出。长列表底部内容通过目录区滚动访问。
