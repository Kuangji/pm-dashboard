## 1. 项目内容与标签管理

项目工具栏固定提供主入口「视频标签」。筛选、详情、批量和手动新增共用该目录，原「额外标签 1」「额外标签 2」归入同一个「额外标签」组。用户可以额外配置分组快捷下拉。从项目工具栏或选择器进入「标签管理」，管理完成后可回到发起入口继续。

| 区域 | 标签选择器 | 标签管理 |
|---|---|---|
| 头部 | 筛选时顶部仅显示搜索与同一行的「管理标签」。编辑、批量等入口显示相应动作标题、管理入口和关闭按钮 | 视频标签目录、搜索和新建分组。选择器发起的进入方式额外显示「返回选择标签」 |
| 标签访问 | 「我的置顶」使用与目录相同的标签 ID。任一入口勾选会同步目录、置顶区和已选区 | 直接展示有效字典的共享分组和标签，可按名称搜索 |
| 分组目录 | 标题、折叠箭头、标签数；标签行含复选框、名称和个人置顶。搜索匹配项临时展开 | 分组单列从上到下，组和标签的拖动手柄均位于最左。组名后显示标签数、组头「＋」及分组菜单。标签名称后是「更多」 |
| 固定操作 | 当前下拉的已选数量及可移除标签、清空、取消、场景主操作。仅主筛选弹层显示匹配规则摘要，默认「组内任一 · 组间全部」 | 新建或编辑标签在该行保存、取消。删除确认显示组内标签数或可授权提供的影响范围 |

### 1.1 选择器布局

- 桌面弹层优先在触发器下方 8 px，空间受限时上翻或贴边。建议宽 512 px，可用高度上限 680 px。目录滚动，标题、搜索和操作区固定。以项目页面现有信息层次为准，表格可以在弹层后保持上下文。
- 搜索同时匹配标签与分组。命中组名时显示该组标签，命中标签名时保留组名定位；隐藏顶部快捷区，搜索结果按原分组出现。清空后还原折叠和已选状态。搜索中文输入法组合结束后查询。
- 标签名旁的浅色「N 条」表示使用该标签的可见监控内容数量。置顶、已选和新增表单的标签内使用紧凑计数样式，管理页原行编辑将计数留在名称字段旁，着色与提交仍为单行。长名称优先截断或换行，计数完整展示。组头的「N 个」用于显示标签数。监控内容列表的标签保留名称和颜色。
- 首次打开选用入口时默认展开一个分组，其余组默认折叠。目录提供「全部展开／全部折叠」，行勾选与组折叠分别操作。组标题显示该组已选数量。「无标签」位于标签目录之外，下方用分隔线、灰底和「尚未打视频标签」说明表达其筛选条件属性。名称旁显示未打标内容的「N 条」。选择「无标签」清除包括快捷组在内的所有普通标签草稿。应用后只显示整个可见视频标签目录中未打标的内容。
- 目录标签行使用单独的图钉设置和解除个人置顶。已置顶图钉常显；未置顶时，鼠标悬停标签行或键盘焦点进入该行才显示。触屏直接显示图钉。图钉有「置顶〈标签名〉」或「取消置顶〈标签名〉」的可访问名称，悬停提示「仅自己可见」。
- 「我的置顶」使用紧凑标签，点击标签进行选择。选中勾占固定空间，勾选前后尺寸一致。标签悬停或聚焦时，右上角显示用于解除置顶的「×」；触屏可直接点按。「×」仅更新置顶，已选草稿保留。没有置顶时从目录开始浏览。
- 已选行可跨组保留。已选较多时摘要允许在固定区域内滚动，同时保持主操作可见。批量入口明确显示动作和目标数量。批量无已选时主按钮禁用。
- 点击规则摘要展开两个控件。「组内关系」可选「匹配任一标签」或「匹配全部标签」。「组间关系」可选「满足所有组」或「满足任一组」。每个参与组共用组内关系。设置修改进入筛选草稿，应用有普通标签的选集时一同生效。主入口清空全部条件时恢复默认关系，快捷入口清空本组时沿用当前关系。选择「无标签」时隐藏设置区并停用摘要。只有一个参与组时，组间关系对当前结果无影响。
- 在 620 px 及以下使用贴边弹层，外距 8 px。快捷入口可随工具栏自然换行。内容表格独立横向滚动，外层无需横向滚动。

### 1.2 分组快捷下拉

- 分组置顶（快捷筛选）是个人设置，仅当前账号在有效标签字典下可见和修改。是否通过服务端保存并跨设备恢复，列入研发评审。 [分组置顶持久化](spec_v1.md#71-分组置顶持久化)
- 主入口始终在前，使用品牌浅底。可选的组入口按添加顺序紧随其后，以中性细描边呈现。主入口和组入口的名称左侧使用同一个标签图标，右侧显示下拉箭头。每个入口只显示自己下拉里的已选数，工具栏下方的已应用摘要显示所有视频标签条件的合计。全局「无标签」生效时，主入口、所有快捷入口和已应用摘要均回显「无标签」与条数。
- 主下拉的普通分组在组名旁提供带描边底座的空心图钉，组的标签数量靠右对齐。单标签的图钉位于标签行最右侧，使用无底座样式。悬停提示「设为快捷筛选（仅自己可见）」。点击后立即创建并打开该组的独立下拉，焦点进入组内搜索。独立下拉在组名旁显示带描边底座的实心图钉，悬停提示取消快捷并移回「视频标签」。点击后打开主下拉并展开、定位回迁组。两个图钉按钮均有 32 × 32 px 热区，可通过键盘操作并读出分组名称与当前状态。
- 最多设 3 个个人快捷组。达到上限时，主下拉显示「快捷已满 · 3/3」，暂时收起组内添加操作。取消任一快捷后恢复添加。组改名后入口同步更新，删除或无权访问后隐藏。「未分组」和「无标签」留在主入口。
- 设置后，分组及其标签从主下拉的目录、搜索结果、置顶和已选区移出，在对应组下拉中展示。主下拉目录标题改为「其他标签」。配置管理、单条编辑、批量和手动新增使用完整授权目录。
- 各下拉的「清空」仅清除当前入口的已选项，应用时更新同一份视频标签筛选。工具栏下方的「清除标签筛选」可清除所有入口的条件。主入口设置两种全局匹配关系和「无标签」。快捷下拉的已选区显示「全局无标签」与条数，提示选组内标签会替换此条件。在任一下拉选中普通标签即替换草稿中的「无标签」，应用后同步到所有入口。取消编辑保留原筛选。
- 设置或取消快捷即时更新个人入口。切换下拉时重置搜索，保留选择草稿、已生效的筛选、置顶和归组快照。已选区在当前入口之外还有改动时提示「另有筛选变更待应用」，应用时一并提交。底部「取消」放弃选择草稿，入口设置即时生效。取消后，该组的候选、置顶和已选回到主下拉。标签已移组时，当前所属组的下拉可取消该标签，并从原快照中移除。

### 1.3 管理页面

1. 进入后直达「视频标签」目录。组标题显示当前可见标签数，原「额外标签」可按普通组整理。
2. 管理页维护有效字典中共享的标签定义、分组和顺序。无定义权限可浏览和搜索共享标签，维护入口按权限展示。
3. 「新建分组」填写名称。每个组头，包括「未分组」，都提供「＋」。点击后展开该组，在组尾显示新建行并聚焦名称。搜索中发起新建时清空查询，展开完整组。提交即归入发起组。
4. 在标签行「更多」中选择「编辑标签」，名称和颜色共用一个控件，取消／保存紧跟其后。组内新建复用同一布局，按钮为取消／创建。常态编辑、新建与普通标签行等高，窄屏均可在一行完成。重名在当前行提示并保留输入。
   - 色板锚定颜色按钮，空间不足时上翻，列表位置保持。橙、蓝、绿、紫、红五色显示名称和当前选中状态。点选即收起，方向键可在色板内移动焦点，Esc 关闭并返回颜色按钮。
   - 同一时间编辑一行。名称、颜色仍是原值时可直接切换到另一行；有未保存修改时保留当前草稿。离开管理、切换身份或打开分组编辑前提示先保存或取消当前行。名称框按 Enter 提交，Esc 取消编辑。
   - 鼠标悬停或行内获得键盘焦点时，手柄在列表现有左侧留边浮现，组名和标签名的起点保持固定。名称旁的操作入口随悬停或焦点展开，隐藏时收为零宽。标签行按 44 px 基线排列。编辑行失去悬停及焦点时保留名称输入，重新聚焦可见颜色及提交操作。触屏直接显示操作入口。
5. 有维护权限时，标签「更多」提供编辑和删除。编辑进入原行，删除经过确认。删除当前筛选使用的标签时，同时说明对当前筛选和结果的影响。删除分组也经过确认，说明移到「未分组」及关联影响。可返回影响数字时显示数字，也可说明内容回显、筛选和个人置顶的变化范围。
6. 管理由选择器发起时，保存来源入口、快捷组（如有）、查询、勾选及匹配方式。返回后先复核候选权限及删除状态，再恢复可用草稿，焦点放回选择器。

### 1.4 拖动排序与移组

- 从标签行最左边的手柄拖动。拖到某行的上／下半部时显示插入线，松手后放在该行之前／之后。拖到组标题或空组时高亮接收组，松手后追加到该组末尾，折叠组也可接收。
- 组内排序松手即保存。跨组落点弹出「确认移动标签」，显示标签、原组、目标组及「当前可见项目中有 N 条监控内容使用此标签」。同时提示「换组后，所有使用此标签的项目都会显示新的标签分组」。确认后展开目标组并定位标签，取消保留原归属与排序。删除分组时，在删除确认中一并提示其中标签换组的影响。
- 从自定义组头最左边的手柄拖动。开始拖动后，组内标签临时收起，只留单列组标题行。落在目标组标题上／下半部时插入前／后。拖动结束后恢复各组原来的展开状态。分组排序松手即保存，「未分组」固定在末尾。
- 点击或按 Enter 激活手柄，打开「移动标签」表单，选择目标组和放置位置，支持纯键盘排序和移组。换组由位置操作发起，标签原行的编辑只承接名称与颜色。无定义维护权时，仍可浏览共享顺序。
- 点击或按 Enter 激活分组手柄，可以用位置表单排序。拖动中按 Esc 或放开在目录之外时取消。跨组确认默认聚焦取消，返回表单时保留待提交的内容。
- 提交完成后选用目录同步读取新顺序。已有筛选按应用时的分组和标签 ID 快照执行。主入口变更选集后按新归组应用其范围内的标签，保留快捷入口已选标签的快照。快捷入口只更新本次改动的标签。

## 2. 动作、按钮与提交

| 场景 | 主按钮 | 取消与清空 |
|---|---|---|
| 项目主筛选 | 应用筛选 | 取消或点外部关闭保留此前筛选。清空后应用只取消主下拉的已选标签或「无标签」。工具栏可清除全部视频标签条件 |
| 分组快捷筛选 | 应用筛选 | 取消保留此前条件。清空后应用移除该组当前可见的所选标签，保留其他组和匹配规则 |
| 单条编辑 | 保存标签 | 打开回显现有标签。取消后沿用原关系，清空后保存移除本次有权编辑的关系 |
| 批量添加 | 添加标签 | 空草稿起步。取消时保留表格的对象选择。成功后刷新相关内容，部分失败显示受影响数量和可重试项。筛选结果变化时取消选中已离开范围的内容 |
| 批量移除 | 移除标签 | 只处理预览目标中的选中标签，成功后按回执刷新。入口与删除定义的文案区分 |
| 手动新增监控 | 确定 | 写回监控表单草稿，提交外层「创建监控」后应用到创建的内容 |
| 个人置顶 | 图钉按钮 | 独立即时写入。选择取消不会撤销置顶 |

## 3. 状态和异常

| 状态 | 界面及返回 |
|---|---|
| 首次加载 | 保持弹层框架；目录区域显示加载反馈，禁止提交未知候选。置顶请求状态不影响列表主体 |
| 字典为空 | 「这里还没有标签」。有维护权用户可去管理页创建。筛选仍可显示「无标签」 |
| 搜索无匹配 | 「没有匹配的标签」「试试其他标签或分组名称」。可继续输入或一键清空，显示此前已选 |
| 请求失败或数据过期 | 显示失败原因和重试入口，保留上次成功结果与本次草稿。候选已失效时展示移除反馈后允许继续 |
| 达到上限 | 筛选建议最多 50 项，个人置顶最多 12 项，分组快捷入口最多 3 个。达到上限时保留现有项，允许先取消再添加 |
| 无权限或范围变化 | 管理入口展示可执行操作，越权写以服务端结果为准。字典范围切换时重新读取并校验旧草稿 |
| 视口紧张及长标签 | 行名称允许换行，快捷和选中摘要省略时可查看全名，数量和图钉留固定区域 |
| 应用成功 | 固定操作区尽快回到原入口，并播报「已应用筛选」「已保存内容标签」或批量成功数 |

## 4. 可访问性与视觉

| 要素 | 实现 |
|---|---|
| 语义 | 分组和匹配规则摘要用具备 `aria-expanded` 和 `aria-controls` 的按钮。选择行是原生复选框，关系设置用带名称的原生选择框。搜索结果数、拖动和其他操作结果用状态区域播报 |
| 键盘 | 打开后焦点进搜索。Tab／Shift+Tab 经过可操作控件，Space 切换勾选，Enter／Space 展开分组。弹层内保持焦点范围，Esc 返回触发点。关闭表单和提交成功时将焦点归还来源 |
| 视觉 | 主色 `#FA6300`、画布 `#F7F8FA`、白色面板、文字 `#101C32`、分割线 `#E5E7EB`。标签浅色可区分且有文本，选择同时通过勾选表达。橙色上的按钮文字采用深色以提高对比度。面板圆角 16 px、确认弹窗 20 px、主要交互热区接近 40 px |
| 响应 | 采用聚星现有中文系统字体与产品图标。投影仅用于浮层。减少动态效果偏好下关闭过渡。生产使用本地样式令牌与国际化键，不额外引入组件库 |

聚星规范用于颜色、表格密度、按钮和状态。国家地区选择器用于分组、滚动与选中反馈。操作条、个人快捷和确认规则按本案业务状态设计。 [布局](../../../../../kol2.0-design-specification/playbook/components/layout.md) · [表格](../../../../../kol2.0-design-specification/playbook/components/table.md) · [弹窗](../../../../../kol2.0-design-specification/playbook/components/modal.md) · [可访问性](../../../../../kol2.0-design-specification/playbook/accessibility.md)
