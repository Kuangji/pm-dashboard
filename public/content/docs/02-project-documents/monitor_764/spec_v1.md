## 1. 范围与对象

| 对象 | 规则 |
|---|---|
| 视频标签 | 工作台筛选、单条编辑、批量操作、手动添加监控及管理页共用一套视频标签目录。工作台始终提供一个主筛选入口，用户可为普通分组添加最多 3 个次级快捷入口 |
| 有效字典范围 | 字典共享边界由服务端解析。旧链路以父账号为范围。业务组权限落地后以有权进入的目标业务组为范围，默认组承接存量，新建组从空字典开始。两种口径的上线情况在迁移前核实 |
| 自定义分组 | 每个有效字典包含一层目录。标签归一个分组，或归系统区「未分组」。旧额外标签 1 和 2 全部映射到同一个「额外标签」组。组是组织和筛选的匹配单元 |
| 内容标签关系 | 迁移和目录编辑以存量标签 ID 为准，保留关联与原始来源。兼容期继续使用旧 `groupId=1/2/3` 及原有资格校验，供权限、历史查询及原接口回放。目录归组使用独立字段 |
| 个人偏好 | 各选用入口共用当前用户在有效字典内的标签置顶。分组置顶（快捷筛选）同样按账号和有效字典隔离，由本人维护，仅本人可见 |

纳入监控工作台筛选、单条详情编辑、批量添加或移除标签、添加监控的标签选用，以及内容监控的标签配置。自动追踪、报表、导出、既有导入模板与其他模块标签属于兼容回归范围。内容监控体验通过评审并完成上线验收后，再评估其他标签迁移。

## 2. 标签配置 · C01–C06

在内容监控开放「管理标签」入口。在有效字典内按授权展示同一套共享目录和顺序。有维护权时，可编辑对应标签与分组。从选择器进入时带入有效字典和来源上下文，可定位发起操作的标签。返回时刷新目录，恢复有权使用的选择草稿与来源焦点。

| ID | 配置能力 | 产品规则 |
|---|---|---|
| C01 | 创建、改名和排序分组 | 自定义分组可拖动排序，直接保存。管理和选用共用分组顺序。「未分组」固定在末尾，新组追加到自定义分组末尾。字典内分组名规范化后须唯一，校验空名称和保留名「未分组」 |
| C02 | 删除分组 | 展示该组当前包含的标签数及处理结果。确认后同事务把成员标签移回「未分组」并删除分组定义。空组同样可删除。标签 ID、内容关联和标签置顶保留。已删除分组从个人快捷入口移除 |
| C03 | 新增、编辑标签 | 组头「＋」在组末打开新建行，保存即归入发起组，含「未分组」。在标签原行同时修改名称和颜色，一次只编辑一行。颜色为橙、蓝、绿、紫、红。新建或改名不得在字典内造成新重名。冲突提示保留输入。只改色、排序和移组允许保留历史重名 |
| C04 | 排序与移动标签 | 拖到标签行上／下半部时插入该行前／后，拖到组标题或空组时追加到组末。支持移入「未分组」。组内排序直接保存。跨组拖动和手柄的位置表单先展示来源和目标，以及当前可见项目中使用此标签的内容条目数。确认后写入，使用此标签的项目按权限显示新分组。取消保留原归属和顺序 |
| C05 | 删除一个标签定义 | 从标签行「更多操作」发起，展示标签名称及授权范围内的影响信息，确认后软删标签。刷新目录、内容回显、有效查询及置顶。若命中发起者的当前筛选，确认框说明移除后结果可能变化，唯一条件则说明会清除当前视频标签筛选。用户确认后更新当前条件。已保存条件按版本与失效规则处理 |
| C06 | 折叠、搜索和定位 | 管理页按共享目录浏览、展开和折叠分组，支持搜索标签或组名。折叠状态可在会话内保留，跨会话记忆属于可选的个人偏好 |

### 2.1 写入约束

- 分组和标签名称上限由服务端统一校验，接入前确认数据库容量和多语言计数方式。历史同名各自保留 ID，在管理、选择及已选摘要中提供来源标记，例如「原额外标签 1」和「原额外标签 2」。同来源仍有重名时增加可见的唯一识别信息。只在用户可见条目之间呈现冲突，名称搜索可以找到每个有权查看的同名标签。
- 成功前保留原列表状态。并发重名、目标组删除或目录版本冲突时保留表单并提示刷新，展示服务端最新目录和可用选项。修改请求只接收允许更新的字段。
- 跨组确认的影响数量按当前用户可读项目内引用标签 ID 的监控内容条目去重。查询返回零条时展示「0 条」，暂时无法获取数量时说明数量不可用，并保留换组影响范围的提示。
- 历史分组和未设置顺序的标签按名称自然排序，以 ID 兜底。分组排序和组内标签排序各有共享顺序键，管理和选用目录统一读取。新建标签、移入组标题以及解散组后归入「未分组」的标签追加到目标组末尾；解散组的多个标签保留原相对顺序。搜索结果中的拖动以实际目标行作定位。
- 删除标签需要校验共享定义权限，详情中移除标签需要校验对象写权限，两项操作分别提示。管理页影响数优先使用服务端按调用者可见项目统计的去重内容数。数值不可安全返回时说明影响范围，省略数量。
- 删除后通过有效字典读路径过滤软删定义，关系保留以供内部审计。客户端遇到外部删除时，应以最新候选移除失效 ID 并提示。旧存储及旧接口仍引用软删 ID 的情况纳入切换前回归。用户侧不提供恢复入口。

## 3. 搜索、个人置顶与标签计数 · P01–P05

| ID | 能力 | 产品规则 |
|---|---|---|
| P01 | 搜索 | 配置和选用都在当前授权目录中搜索标签名或分组名。匹配采用 NFKC 规范化、去首尾空白、合并连续空白、转成不依赖地区的 Unicode 小写后的子串语义，中文按原字匹配。空白输入清除查询，展示名称保留原始字符与大小写。分组快捷下拉只匹配组内标签名 |
| P02 | 搜索期间的目录 | 标签命中时展示标签和其分组，组名命中时展示该组及其标签。临时展开命中组，省略其余组。当前选择草稿继续保留，清空搜索后恢复搜索前折叠态。同一标签在搜索结果中只占一行；选择器在该行显示个人置顶状态 |
| P03 | 个人置顶 | 只在选择器中设置或解除。已置顶图钉常显，未置顶图钉随行悬停或聚焦显示，触屏直接显示。「我的置顶」可直接解除。每人每有效字典统一上限 12 个可用标签，最新置顶排在前。已成功的置顶即时更新，独立于勾选草稿与共享目录 |
| P04 | 存量及失效处理 | 如果实际部署已有个人置顶记录，按用户、有效字典和标签 ID 汇入统一视图，记录继续保留。合并后超过 12 个时完整显示可用记录，并允许解除，降到 12 个以下后才可增加。软删、资格撤销或退出业务组后过滤相应条目。无个人记录时从空置顶开始，既有共享置顶字段留给旧链路 |
| P05 | 标签条数 | 筛选及打标候选、置顶、已选、管理和手动新增表单中的标签显示「N 条」。监控内容列表的标签只显示名称。按标签 ID 统计，当前账号在有效字典下可读项目内，引用此标签的监控内容按内容 ID 去重。搜索、折叠及当前筛选不改变计数。关联变更后刷新。真实零值显示「0 条」，暂不可用时显示「—」及数量不可用提示 |

## 4. 选用入口与提交规则 · U01–U06

| ID | 场景 | 打开、选择与提交 |
|---|---|---|
| U01 | 工作台标签筛选 | 打开回显已生效视频标签条件。勾选进入草稿，点击「应用」后统一更新视频标签筛选。清除只作用于视频标签，其他类型的筛选保留。历史版本条件按 §4.3 回放 |
| U02 | 单条编辑 | 回显当前内容已关联且有权读取的标签。仅可选、可写标签纳入替换范围，可读但不可编辑的标签以只读状态呈现。清空后保存移除可编辑范围内的关系，隐藏及不可编辑关系由服务端原样保留 |
| U03 | 批量添加 | 打开批量模式，空草稿起步，显示目标范围与数量。确认时只新增选中关系，已有关系保持。无选择时禁用提交，操作失败时维持目标和草稿 |
| U04 | 批量移除 | 打开时明确移除模式和目标范围。确认只移除选中的可写关系，未关联的目标跳过。全选筛选结果按既有作用域处理，由服务端重验目标 ACL 并返回可安全展示的执行回执 |
| U05 | 添加监控 | 手动添加监控使用统一选择器。选择写回监控表单，并保持现有公共配置和单行覆盖规则。外层提交时重验标签授权，按成功创建任务回显结果 |
| U06 | 跨入口共用状态 | 各选用入口共用统一目录、搜索和个人置顶。关闭或取消放弃草稿，提交失败保留草稿和上次生效状态。有效字典变化时重新读取并校验，旧请求响应不得覆盖新范围。列表因筛选、搜索或标签写入产生变化时，取消选中已离开当前结果范围的内容。提交批量操作前根据明确展示的选择范围复核目标 |

### 4.1 筛选合同

- 统一筛选保存组内与组间两项关系。组内默认「匹配任一标签」(`OR`)，可改为「匹配全部标签」(`AND`)。组间默认「满足所有组」(`AND`)，可改为「满足任一组」(`OR`)。参与组至少包含一个有效的已选标签，「未分组」按一个组参与。只选择一个组时，组间关系对结果无影响。
- 只提供一个全局「无标签」，与主下拉及所有快捷下拉中的普通标签选择互斥。选择时清空所有普通标签草稿，应用后同步清除各入口的已选标签。后端在当前有效字典及调用者的可读权限内检查任务是否缺少任何有效标签。只有隐藏或已删除标签的内容符合该条件。「无标签」显示满足上述条件的可见监控内容数，按内容 ID 去重，与 P05 同步处理零值、不可用和关系变更。当前搜索词、项目筛选条件与快捷组设置均不改变该统计口径。空选择表示没有视频标签筛选。
- 应用时记录关系类型及参与分组的标签 ID 快照。折叠、改名、排序、移组或解散组都保留已应用和已保存条件的原快照。标签集合未变时，调整关系可复用快照。主入口调整选集后按当前目录重建其范围内标签的快照，保留快捷入口已选标签的原快照。
- 新版筛选建议统一最多选 50 个去重标签，超过上限时保留已有选择并允许取消。服务端验证数量、ID、字典范围与可读权限。写入对象的入口按各自业务限额。
- 外部删除或权限改变导致已选 ID 失效时给出明确反馈。刷新后保留已知可用草稿，重验后由用户确认变更。本会话主动删除已应用标签时，删除确认可以同时说明并确认其对当前筛选的影响。查询遇到不可执行的旧条件或新的权限变动时提示重新选择，避免静默扩大查询范围。筛选请求失败时保留上次成功结果和本次草稿供重试。

### 4.2 工作台分组快捷入口

- 主入口「视频标签」始终显示，浏览和搜索当前未设快捷的可见分组。用户在主下拉的普通组标题行点击空心图钉，即时添加并打开该组的独立下拉。在独立下拉的列表标题行点击实心图钉，即时移除入口并展开、定位主下拉中的对应组。分组快捷图钉贴着组名，使用描边底座。单标签置顶图钉位于标签行最右侧。按钮通过悬停提示和可访问名称及状态说明操作。切换时清空原搜索词并保留筛选草稿，偏好更新独立于筛选的应用或取消。设为快捷后，从主下拉的候选、搜索、置顶和已选区移出。取消快捷后恢复显示。「未分组」和「无标签」留在主入口。标签管理和打标入口继续使用完整的授权目录。
- 工具栏最多展示 3 个次级入口，标题跟随分组名，顺序按个人保存的分组 ID 列表。首次使用时为空，添加新的快捷入口默认排在末尾。达到上限时显示「快捷已满 · 3/3」，暂停添加，取消任一快捷后恢复。设置或取消快捷入口只改变当前账号的展示位置，已生效筛选及个人置顶继续保留，并随分组在对应下拉中回显。每个入口显示自身的已选数，页面的已应用摘要显示合计。已删除或无权访问的分组隐藏，组名修改后随目录更新。
- 快捷入口复用筛选选择器，仅编辑目标组当前可见的标签。应用时并回同一份筛选草稿及快照，保留其它组的条件和既有匹配规则。切换后如还有当前下拉未展示的变更，已选区提示「另有筛选变更待应用」。各下拉的「清空」只撤销本入口的已选项。页面的「清除标签筛选」清除全部视频标签条件。所有入口共用一个筛选请求。
- 主入口负责设置组内／组间关系及选择「无标签」。生效时，主入口、全部快捷按钮和页面筛选摘要均回显「无标签」及未打标的内容条数，快捷下拉已选区回显同样的全局条数。任一下拉选普通标签时从共享草稿移除「无标签」。应用后刷新所有入口，取消编辑保留此前已生效条件。
- 快捷入口按标签当前归组展示候选，并按全局所选 ID 回显。已选标签移动到当前组后，取消勾选即从原快照组删除该 ID。新勾选的标签写入当前快捷组的快照，未改动的标签保留其原快照位置。主入口改动选集后仅按最新目录重新分组本入口内的标签。旧版本筛选切到新版编辑时使用主入口的显式确认流程。

### 4.3 历史条件回放

- 已保存或可恢复的旧筛选保留原版本、旧维度、原先的组内 AND／OR、无标签条件及旧平铺 ID 语义。沿用原版本执行器进行精确计算，同时重验当前权限。两类旧额外标签即使在新版目录中归同一组，旧查询仍按原维度求值。
- 对旧条件提供可识别的回显和清除动作。用户主动改选时进入新版选择流程，明确确认后创建新版条件。在无法无损映射的情况下保留旧配置和结果，不自动生成近似的新条件。
- 实现按版本锁定条件结构，查询、看板、导出和批量全选使用同一已应用版本。新版独有的布尔或「无标签」条件经回滚后仍应能执行原表达式。旧界面若无法编辑新版条件，可提示在新版编辑，或暂停这类配置的可写入口至界面恢复。

## 5. 权限、数据与兼容 · E01–E04

| ID | 操作 | 校验与错误反馈 |
|---|---|---|
| E01 | 读取目录、筛选 | 后端解析字典范围，按存量资格过滤原额外标签的可见性，直至生产权限策略确认并切换。组内数量、搜索和快捷区均使用同一可见集合。对象查询与导出另验项目访问权 |
| E02 | 写共享定义或分组 | 校验维护权及源、目标归属。业务组模式校验目标组 ACTIVE 身份，再执行内容监控的独立定义策略。限制开启时仅该组有效组长和该组有效 Owner／Admin 有维护权。分组移除或排序可能影响隐藏成员时，先按权限校验整笔操作。权限变化时清理越权缓存 |
| E03 | 应用／移除内容关系 | 字典可读与对象可写分开校验。原额外标签保持原写权限，移组及统一目录不改变资格。服务端校验对象、项目、标签归属和标签写入资格。批量异常在回执中说明可安全披露的失败范围 |
| E04 | 个人置顶、折叠及分组快捷入口 | 用户仅可读写自己的个人偏好。维护标签置顶时校验字典及标签可见性。分组快捷入口按当前账号及有效字典隔离，设置和回显时校验分组可见性。采用服务端存储时，由服务端识别当前用户并校验权限 |

### 5.1 加法接口建议

| 数据或接口 | 合同建议 |
|---|---|
| 分组与目录 | 分组保存有效字典范围、规范名称和稳定分组 ID。标签增加可空分组关联，空值表示「未分组」。读取返回共享排序、分组与标签 ID、名称、颜色、目录版本及各项权限能力。保留兼容期能回溯原权限和字段的旧维度 |
| 目录修改 | 排序提交移动项 ID、锚点 ID、前／后位置和目录版本，移组另传目标组。服务端校验权限、范围和锚点。跨组归属与顺序、解散分组与成员迁回分别在同一事务内完成。锚点失效、并发重名或版本冲突返回可识别错误 |

| 查询 | 建议新增带版本的统一筛选请求，含 `withinMatch`、`betweenMatch`、`withoutLabel` 及带标签 ID 的分组快照。向后兼容旧 `labelGroups` 和平铺 `labelIds`，服务端按版本选择执行方式。列表、看板、批量全选及导出共用解析结果 |
| 关系与文件 | 新入口按标签 ID 查找和写入。单条替换按事务思路处理 `保留的关系 ∪ 本次选择且有权写入的关系`，提交时重验权限与当前版本。批量差量保持幂等。继续兼容旧导入模板、原导出字段和原接口；同名按原模板的维度及权限解析，无法唯一识别时返回可辨认的冲突，保留原关系 |

### 6.2 灰度、观测与发布门槛

1. **预发对照。** 先验证权限、往返映射、旧查询回放和目录迁移前后的 ID 与关联数量。批准同名目标组的逐字典映射，使用可复跑的差异报告记录存量和权限定界。
2. **分开灰度。** 先部署加法字段、版本执行器和兼容接口。再按有效字典逐步开放新界面和写路径，验证覆盖只有基础标签及各类额外标签资格的账户，并确认原导入、导出与其它入口。
3. **回退。** 关闭新入口和写路径后，旧界面继续读取原维度、标签 ID、已有关联及原权限。加法字段保留已迁移目录、排序、个人置顶和新版保存条件。通过保留的版本执行器回放新版条件。研发在灰度前验证旧写入和回滚后的新增标签仍可按原有字段读取，并演练恢复开关以及必要的数据级反向映射。新旧界面并行及回退窗口内，应收口可能因重名合并标签 ID 的旧定义写入、会按整旧维度覆盖的旧详情写入，以及旧导入创建权限。仍在执行的新旧查询均按自身版本回放。

推荐验证目标为预备好 1,000 标签测试字典后，目录首次打开到可操作的 P95 ≤ 800 ms，已加载后搜索到首批可操作结果的 P95 ≤ 150 ms。记录网络、服务端和渲染分段耗时以及测试条件，灰度前按真实字典分布复核目标。超过 1,000 项仍需全量可检索，可比较服务端分页／匹配与组件虚拟滚动方案。

观测标签选择器打开、成功应用、取消、搜索无结果、置顶及分组快捷入口上限、写入失败、目录冲突、失效 ID 及目录／偏好接口延迟。比较灰度前后「打开到应用时间」和「成功完成比例」，按入口区分统计，事件不上传标签名、分组名或搜索原文。发布门槛为 A01–A10 全部通过、范围隔离与回退演练通过、关键路径延迟达到复核目标，以及已有绑定和有效筛选结果对照无非预期差异。

### 7.1 分组置顶持久化

- **已确认。** 分组置顶（快捷筛选）是当前账号在有效标签字典下的个人偏好，仅本人可见和修改。设置或取消快捷只更新个人入口，共享标签分组与排序由标签管理维护。
- **评审讨论。** 优先评估复用现有个人偏好服务，持久化有序分组 ID，支持同一账号跨设备、跨浏览器恢复。评审确认能否复用已有读写接口，以及是否随首版交付。
- **首版验收。** 可使用按账号和有效标签字典隔离的浏览器存储。验收覆盖个人隔离、刷新后恢复、权限变化和快捷入口行为。服务端持久化属于可选方案。
