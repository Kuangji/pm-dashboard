## 研发功能点清单

本轮范围为内容监控视频标签。按下面的清单拆分开发任务，联调时逐项勾验。 [详细验收矩阵 A01–A10](spec_v1.md#61-验收矩阵)

### 标签选择器与个人设置

- [ ] **统一目录。** 项目筛选、单条编辑、批量打标和手动新增共用视频标签目录。支持折叠分组、按标签名或组名搜索，搜索时保留已选。
- [ ] **标签条数。** 选择器、标签管理和新增表单的标签名旁显示当前账号可见的内容条数，按内容 ID 去重。监控内容列表的标签只显示名称。标记为「0 条」的标签尚无可见内容使用。
- [ ] **个人标签置顶。** 在选择器内设为或取消置顶，最多 **12 个**。已置顶图钉常显，未置顶图钉在悬停、聚焦或触屏时显示。「我的置顶」用右上角 × 解除。
- [ ] **分组快捷下拉。** 点组名旁带描边底座的图钉将该组移出主下拉，最多 **3 个**。在独立下拉取消后，组及其选中状态回到主下拉。管理和打标仍读取完整授权目录。
- [ ] **个人偏好隔离。** 标签置顶、分组快捷均按账号和有效字典隔离。分组快捷的服务端持久化属于可选评审项。

### 项目筛选

- [ ] **两层匹配。** 主下拉设置组内与组间关系，默认 **组内 OR、组间 AND**。组排序和标签换组保留已应用的分组快照。
- [ ] **共享筛选草稿。** 主下拉和快捷下拉统一应用。入口内「清空」只作用于当前下拉，页面的「清除标签筛选」清除全部标签条件。
- [ ] **全局无标签。** 主下拉应用「无标签」后，所有普通标签条件清除，各快捷下拉同步回显未打标内容条数。仅含可读有效快捷组标签的内容也排除在结果之外。

### 内容打标

- [ ] **单条编辑。** 回显现有标签，仅替换可编辑关系，保留隐藏或不可编辑的关系。
- [ ] **批量添加与移除。** 各自按差量提交，展示目标数量。提交前复核选中范围，筛选变化后已离开当前结果的行不会被更新。
- [ ] **手动新增。** 标签先写入表单草稿，创建监控成功后建立关联。从选择器往返管理页时，恢复仍有效的选择与目标。

### 共享标签管理

- [ ] **分组维护。** 支持新建、改名、拖动排序和删除。拖动时临时收起组内容，结束后恢复展开状态。删除组时将标签移到末尾的「未分组」。
- [ ] **标签维护。** 在组头点「＋」新建。原行改名、选常见色，保存和取消紧邻控件。删除需确认，涉及当前筛选时同时说明影响。
- [ ] **组内排序与跨组移动。** 均从最左侧手柄操作，悬停时名称不跳动。组内排序直接保存，跨组需二次确认并展示有权可见的受影响内容数。

### 权限、迁移与回归

- [ ] **权限校验。** 分别校验字典可读、定义可维护、内容关联可写三类权限。统一入口继续沿用旧额外标签的访问资格。
- [ ] **存量迁移。** 原「额外标签 1／2」归入同一个「额外标签」组，保留标签 ID 和内容关联。历史同名保留独立条目并标明来源。
- [ ] **兼容与回退。** 按旧语义回放旧筛选，回归列表、看板、导入导出及自动追踪。灰度前对账并演练回退。

## 1. 目标与范围

高频用户需要能快速找回熟悉的标签，也要能在标签变多后按工作语境浏览。当前几个入口的搜索和置顶能力不一致，字典维护还与内容打标混在同一个面板里。此次统一内容监控的标签配置与选用，优先解决找标签、反复打标和整理存量三个动作。

| 使用者 | 主要任务 | 交付 |
|---|---|---|
| 项目运营、分析人员 | 在项目筛选中组合标签，快速找回自己置顶的选项 | 分组浏览、搜索、我的置顶、最多 3 个个人分组快捷下拉 |
| 内容维护人员 | 为一条内容编辑标签，或给一批内容添加、移除标签 | 同一选择组件，按入口保留单条替换和批量差量语义 |
| 标签字典维护人员 | 建组、归类、调整命名和删除废弃定义 | 内容监控内独立管理页，包含分组、搜索和受权限控制的定义管理 |

正式范围覆盖项目全局筛选、单条详情、批量添加／移除、手动新增监控和监控标签定义。原「额外标签 1」「额外标签 2」合并到统一视频标签目录的「额外标签」组。存量标签 ID、内容关联和原有访问资格继续沿用。看板、内容列表、导出、Excel 导入、自动追踪纳入回归验证。CRM、达人收藏、其他模块标签的迁移在本轮验收之后单独评估。

## 2. 方案取舍

1. **同一字典增加一层自定义分组。** 业务组决定谁能读写。自定义分组用于浏览和筛选，原基础视频标签默认留在「未分组」，两类原额外标签进入同一个「额外标签」组。管理页支持组头新建标签、原行改名和改色，以及拖动排序与换组。标签换组需确认对使用该标签的项目的影响。
2. **个人置顶留在选择器。** 有权限的账号共同使用同一套标签字典。标签管理负责共享定义、分组与排序。置顶按账号和有效字典独立保存，在选择器内设置与解除。
3. **选择和配置各有固定入口。** 轻量选择器保留当前业务操作，管理页负责共享字典。可以从选择器进入统一目录管理，完成后返回继续选择。
4. **首版采用带搜索的分组多选弹层。** 纯搜索列表适合已知名称，长列表的浏览和整理成本仍在。二级级联会增加跨组多选的切换。采用分组展开、快捷区、固定已选区三部分，同一标签从任意入口操作都同步。
5. **筛选只需设两种关系。** 整套视频标签共用一个组内关系和一个组间关系，默认组内 OR、组间 AND，即每个选中的组至少匹配一个所选标签。主面板显示规则摘要，展开即可调整。
6. **分组置顶（快捷筛选）是个人设置。** 同一标签字典下，每个账号可独立设置最多 3 个快捷组，仅本人可见。点组标题旁的空心图钉移作独立下拉，点实心图钉移回主下拉。各入口共同编辑同一个筛选，调整入口时保留现有条件。主下拉应用「无标签」时，所有快捷组同步清除已选标签并显示全局条件。

## 5. 交付顺序

| 阶段 | 产物与退出条件 |
|---|---|
| 交互评审 | 运行独立 Demo，复核组内／组间四种组合、无标签、拖动排序和移组、已应用条件在移组后的稳定性，以及选择器的个人置顶设置和隔离。置顶最多 12 项，个人分组快捷入口最多 3 个 |
| 研发基线确认 | 前端确认替换入口和地区选择器可复用样式，后端确认生产接口链、旧字典例外、当前权限范围、DDL 与批量回执，QA 冻结代表性回归字典 |
| 联调预发 | 先部署目录、个人标签置顶和兼容接口，再接入项目筛选和配置，随后覆盖详情、批量、手动新增及额外标签迁移。按 [A01–A10](spec_v1.md#61-验收矩阵) 完成跨入口验收 |
| 灰度与发布 | 分账套或业务组开关，验证授权范围、使用指标和旧界面回退。记录上线状态及偏好迁移结果后再评估其他模块 |

**评审讨论项**　分组置顶优先考虑服务端持久化，让同一账号换设备后仍能恢复快捷组。首版可先使用按账号和有效字典隔离的浏览器存储。是否纳入服务端持久化由评审决定。 [分组置顶持久化](spec_v1.md#71-分组置顶持久化)

其余研发待确认项包括生产部署、旧字典异常、名称与数量约束、批量结果明细、个人偏好缓存隔离和旧筛选回放。 [研发评审待核](spec_v1.md#7-研发评审待核)
