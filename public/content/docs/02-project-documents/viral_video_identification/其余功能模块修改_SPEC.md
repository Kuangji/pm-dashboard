# 其余功能模块修改 SPEC

更新：2026-10-27。本文规定榜单以外页面的增量改造；总体范围与交付 checklist 见 [README](README.md)，计算、状态与结果协议以 [计算规则 SPEC](计算规则_SPEC.md) 为唯一依据。新增榜单及共用依据抽屉的呈现见 [榜单页 SPEC](榜单页_SPEC.md)。

## 1. 范围与改动原则

目标是在用户现有的找作品、找作者、查看内容与监控链路中消费爆款识别结果。除新增榜单外，沿用原页面布局，只增加必要的筛选、视频标记、简短统计和依据入口；其他模块不再制作独立 Demo。

| 范围 | 模块 | 本期交付 |
| --- | --- | --- |
| 纳入 | 三平台视频搜索 | 只看爆款/识别状态筛选、行内标记与依据 |
| 可选，研发评估后启用 | 榜单单视频 AI 推荐关键词的搜索承接 | 复用现有推荐能力；确认搜索词后进入同平台视频搜索，不具备交付条件则隐藏榜单入口，不影响本模块筛选与标记交付 |
| 纳入，待研发排期 | 三平台频道搜索 | “近期有爆款视频”、计数及书签/恢复配套；关联视频保持原选取与排序，不新增命中作品入口 |
| 纳入 | 频道内容 | 内容 Tab 筛选、视频标记与依据 |
| 纳入 | 内容监控 | 原全局筛选、表格/卡片增加公共识别结果；原增长指标保留，不增加近期识别／增长爆发 |
| 纳入 | 品牌内容资产 | 内容主列表筛选、卡片/表格标记，保留原指标 |
| P1，组件复用，非阻塞 | YouTube 单视频分析 | 可复用视频标签与依据，无新增筛选，不为本入口单独扩建接口或页面 |
| 本期不单独开发 | 其他独立视频入口 | 第7节逐项列出；共享组件自然带出时复用统一结果，不新增独立任务或作为上线阻塞项 |

本期不包含监控近期识别／增长爆发或其他爆款判定类型，也不新增作者综合评分、频道榜、交易爆款、合作成功/履约判断、自动预警、AI 因果解释、开放 API 或独立视频收藏库。平台仍为 YouTube、TikTok、Instagram；不能把同一筛选自动开启到未接通契约的数据来源。

## 2. 所有模块共用的要求

### 2.1 查询与展示

- 服务端返回判定、证据、聚合与排序所需结果；前端不计算阈值、基线、倍数、预测或 fallback 标签。
- 本期采用同作者此前同形态作品的累计快照比较、暂定10×；不再声明同发布年龄。依据说明真实采集时点与限制，最低发布时长、快照质量和计算期限以计算 SPEC 为准；快照不设时间TTL，不由各模块自行规定过期天数。
- 同视频只有在**计算配置、观察范围、批次/版本和权限上下文相同**时要求一致；本期包括内容监控在内均消费公共结果，不另建近期识别用途，监控原增长字段保持独立。
- 查询先确定原业务范围，再关联结果、执行筛选、去重、计算总数和分页。禁止只在当前页补标后过滤、从可见几行计算全量命中数或覆盖率。
- 当前有效命中统一显示“爆款”标签，不展示内部判定类型名。接口、存储及查询继续使用 `account_breakout`，不删除类型维度。完成评估但未达标不叫“已入选”，不可判定不作为普通视频或未达标。
- 状态直接说明结果，例如“数据不足”；保留零值、缺失、受限、不适用、未覆盖、过期与撤销的差别。
- “只看爆款”与状态的组合、冲突禁用/拒绝规则见计算 SPEC；二者均只查询账号突破，不提供判断类型切换。
- 原关键词、地区、分类、形态、日期、业务指标及排序维持各自对象含义。新榜已确认使用频道国家/地区；作者频道国家与内容市场、受众地区分别定义，未知频道国家显示“—”，不拿其他字段补齐。其他模块原地区控件仍保持其原业务对象，不能借接入爆款标签静默改义。
- 切换筛选只查询已发布结果，不触发重算、采集提速、扣配额、创建监控或生成 AI 报告。公共结果以日更为产品目标，允许随公共视频数据更新触发增量计算；不承诺每条视频每天取得新数据或刷新页面即重算。采集、评估与发布/榜单更新时间分开说明，见计算SPEC第3.5节。
- 新榜按判定快照累计播放量降序、同播放量较新发布优先、再按稳定ID；该顺序不覆盖视频搜索、频道内容、监控或品牌资产原有业务排序，各模块保持其原排序。
- 新榜90天候选上限及默认30天是榜单查询条件；频道搜索“近期有爆款视频”也已确认提供30/90天，但默认不限、不启用该条件。其他模块保留原发布时间筛选范围，作者历史基线不裁成页面窗口。公共计算另统一遵守发布后90天期限，超过后停止自动首次判定和重算，见计算 SPEC 第3.4节。
- 计算结束不删除旧结果、不自动变为未达标/过期。其他模块继续消费仍可使用且授权的保留结果；依据展示原判定时点及已停止更新。新批次目录时间不能冒充旧视频重算时间。
- 超龄且从未有结果、最后是pending或数据不足时，依据明确已超过识别期及真实状态，不继续暗示自动观察中，也不补造未达标。计算结束信息由服务端提供，放入现有依据/限制说明，不另加类型、筛选或独立区域。

### 2.2 筛选、依据和操作

| 组件 | 增量要求 |
| --- | --- |
| 筛选区 | 放在原筛选面板；默认不限，复用原提交/重置行为，不增加独立全宽说明区 |
| 已选条件摘要 | 用“只看爆款”等用户文案回显生效条件、状态和窗口；支持单项移除与清空，不能回显已被服务端忽略的条件 |
| 视频卡片/表格行 | 标签靠近标题/内容身份区；原播放、赞评、发布日期与业务字段保持 |
| 识别依据 | 复用共用抽屉；先结论与关键解释，再按需展开口径，先说明“已入选爆款”等当前结论及同作者比较依据；数据不足不伪造对照；展开时与榜单读取同一历史中位数，其他模块不强制增加基准列 |
| 返回 | 刷新、分页与返回保留条件；从依据返回恢复原列表位置；可用上下文失效时显式提示重新查询 |
| 原平台、作者、监控 | 沿用原真实入口、权限、项目选择与配额；标签自身不触发写操作 |

### 2.3 统计、异常与权限

2026-10-27已确认：本模块范围内的爆款筛选、标签、中位数/倍数和依据不新增权限限制。用户可访问原模块及相应视频时，新增能力随原模块提供；不新增爆款专属权益、升级套餐提示、额外筛选权限开关或爆款次数额度。原模块/项目/数据的访问边界保持，不能由可见计数或命中作品泄漏不可访问内容。新榜单另按原榜单设定继承权限。

搜索、导出、加入监控及可选主动AI推荐继续各自既有权限与配额；本次不新增额外扣量，也不因爆款增强移除原操作限制。现有“受限”状态仅用于原有模块/数据限制，不作为本次新增付费墙。

覆盖统计必须由服务端按全量业务范围和权限计算，返回账号突破的适用、已评估和命中数量；不适用对象排除，待识别/不足保留在适用分母，未知或零分母显示“—”。爆款结果筛选不能把覆盖分母缩成已命中的集合。具体字段与去重口径见计算 SPEC。

| 情况 | 页面行为 |
| --- | --- |
| 列表加载 | 沿用原加载组件，不短暂显示“无爆款” |
| 业务列表成功、个别视频未覆盖 | 保留原内容，局部显示可用结果/限制；不能把缺失结果补成 pending 或未达标 |
| 请求失败 | 错误提示与重试；不得伪装成未覆盖或真实空结果 |
| 依据请求失败 | 保留原列表结果，抽屉提供失败与重试，不编造原因 |
| 批次延迟/不可用 | 显示真实截止时间与延迟；服务端明确不可用或显式stale/撤销时不贴当前爆款标签，单条快照不按时间自动失效 |
| 目标超过90天 | 不触发首次计算、重试或重算；已存在的可用结果和历史依据保留，说明停止更新；无可用结果不伪造判定 |
| 受限 | 服务端先裁剪再聚合/下发；不泄漏隐藏指标、样本、基线、内部原因码及证据 ID |

## 3. 视频搜索

真实入口：`/search/{youtube,tiktok,instagram}/video`。

| 项目 | 要求 |
| --- | --- |
| UI | 在原筛选区增加只看爆款与识别状态；结果项加标签和“识别依据”，保留原搜索框与结果形态 |
| 数据 | 原业务条件与新条件按已定义语义组合，服务端筛选后分页；保留原相关性及支持的指标排序 |
| 平台 | 三平台分别查询；未知/不适用的视频形态不得强行取得视频标签 |
| 来源承接（可选） | 榜单单视频“AI推荐关键词”启用时，按榜单 SPEC 第 7 节接收同平台与用户确认的搜索词；默认不复制全部榜单条件，不自动强制爆款结果 |
| 验收 | 同上下文的有效命中与榜单依据一致；账号突破命中与未达标正确；状态含义明确；空、未覆盖、失败和受限可区分 |

从榜单单条视频进入搜索，是基于已确认关键词查找相关主题内容，不保证同类创意、爆款属性或名次一致。沿用原搜索框、结果形态、排序与条件摘要，不增加另一套搜索 UI；按榜单 SPEC 保存来源和合法返回地址。只有实际生效的条件才在摘要回显；推荐词不能以隐藏条件附加，不能把所有候选词未经确认按 OR 提交。

该入口是否本期交付由研发评估。未启用时，榜单相关入口整体隐藏，视频搜索本身的爆款筛选、标签与依据仍按本 SPEC 交付；不保留无关键词的旧跳转作为替代。打开依据、进入作者再返回仍保留原搜索条件、页码和位置。

## 4. 频道搜索：近期有爆款视频

真实入口：`/search/{youtube,tiktok,instagram}/channel`。该条件找作者；频道内容筛选则找该作者的具体作品。

### 4.1 控件与唯一含义

2026-10-27已确认：在原高级筛选增加“近期有爆款视频”，仅提供以下三个选项。时间按作品发布时间，不是首次命中时间、算法观察年龄或实时刷新承诺。

| 选项文案 | 含义 |
| --- | --- |
| 不限（默认） | 不启用爆款存在性条件，保持原频道搜索，不表示查找所有历史中曾有爆款的作者 |
| 近30天 | 近30天发布的作品中，至少有一条可访问且当前有效的爆款 |
| 近90天 | 近90天发布的作品中，至少有一条可访问且当前有效的爆款 |

选项复用筛选项名称表达“有爆款视频”，避免在下拉菜单中重复整句。重置、清空或移除该条件均回到“不限”；这与榜单发布时间默认30天不同。已选摘要例如“近期有爆款视频：近30天”。不增加独立勾选开关、全历史爆款选项、次数阶梯、爆款率、“无爆款”反向筛选或类型切换。

说明文案：“按视频发布时间筛选，所选范围内至少有一条已识别爆款即符合条件；命中作品不限定与搜索词相关。”沿用现有筛选说明方式，不新增独立说明区域。

选择近30天或近90天时，频道必须同时满足：**原频道搜索条件 AND 指定发布时间范围内至少一条可访问、适用且当前有效命中的视频**；选择不限时不附加此存在性过滤。服务端在公共存量识别上下文中完成全范围存在性查询、计数、去重和过滤，再计算频道总数与分页。不能用关联视频的有限样本判断作者是否入选。

| 语义 | 规则 |
| --- | --- |
| 近期 | 按视频发布时间，以公共结果批次固定截止时点T解析 `[T−N×24h, T]`（N仅为30或90），与榜单使用相同边界；缺失/异常或未来发布时间不进入范围，不能用首次识别或采集时间代替 |
| 有效命中 | 沿用计算 SPEC 的 qualified、fresh、valid、allowed 与适用形态；过期、撤销、待观察、不足及非视频不计命中 |
| 去重 | 视频按平台+视频 ID、作者按平台+频道 ID；同一视频只计一条 |
| 关键词 | 保留原频道召回语义；默认不要求导致作者入选的爆款与搜索词相关 |
| 原地区/分类 | 保持频道条件原含义，不自动变成视频市场/分类限制；视频约束另标对象和聚合范围 |
| 不可见作品 | 不通过筛选资格、计数或证据 ID 泄漏存在性；不是先聚合隐藏作品再隐藏明细 |

筛选提示使用上面的说明文案，不能把结果称为“该主题爆款作者”。“同一视频同时符合关键词和爆款”是另一种内容级约束，后续单独评审。

### 4.2 计数与上下文

- 频道聚合须独立返回范围完整性（完整/部分/未知）及计数精度，不复用单视频的 `coverageStatus`。单视频账号突破纳入结果服务（`coverageStatus=full`），不代表数据充分或作者整个发布时间窗口已完整覆盖；精确值或已知下界由服务端在账号突破与权限范围内判定。
- 完整已声明范围内的精确计数可显示“近 30 天有 2 条已识别爆款”；覆盖不全但已有可见命中时显示“近 30 天至少识别到 2 条”。不得从已知下界反推精确总量或爆款率。
- 作者发布时间范围尚未完整评估时，仍可凭明确命中入选；未检出不代表该作者没有爆款。空结果用“当前已覆盖范围未找到符合条件的频道”。
- 2026-10-27已确认暂不调整关联视频展示：启用爆款筛选后，搜索结果卡片及原详情抽屉仍沿用现有视频选取、相关性和排序规则；不优先展示爆款、不替换关联内容，不新增“查看命中作品”按钮、专门明细/抽屉或匹配视频分页接口。该展示方案可能与原规则冲突，留待后续另行评估，不属于本期必做配套。
- 原关联视频未展示导致频道入选的爆款，不代表筛选错误，也不能从可见样本判断是否应入选；资格必须来自服务端全范围存在性查询。筛选说明继续明确按作者近期作品判断，作品不限定与搜索词相关。
- 30/90天窗口随新查询/新发布上下文的截止时点推进，即使视频没有新数据也须按发布时间移出范围；这不触发旧视频重算。搜索资格、总数、计数与翻页固定同一用途/范围、截止时间、批次/版本和权限上下文。服务端参与资格判断的视频必须属于当前频道并符合窗口与账号突破条件；不要求前台关联视频改为该集合。
- 原作者详情跳转、视频区域及返回保持既有行为；不因新增此筛选增加命中作品下钻。本次频道搜索翻页/返回的上下文失效或权限变化时提示重新查询，不静默换批次或窗口。

### 4.3 服务端必须提供的聚合能力

| 部分 | 最小消费语义 |
| --- | --- |
| 查询 | 相对发布时间窗口、账号突破、至少一条的存在性条件、原频道条件及关键词语义版本 |
| 上下文 | 计算用途/范围、截止时点、解析后的起止范围、结果批次/版本、权限范围或可校验的上下文 ID |
| 频道行 | 平台、频道 ID、可见命中数、精确值/已知下界、独立的聚合范围完整性 |
| 内部可追溯性 | 服务端可追溯使频道符合存在性条件的视频及判定上下文，用于正确性核查；本期不要求新增对用户的命中作品列表、证据入口或分页接口 |
| 响应 | 过滤后的频道总数/分页；不支持、失败、批次过期时有明确响应，不能忽略条件返回未过滤列表 |

字段名、URL、索引/预聚合方案、成本和性能由研发评审决定；当前关联视频 API 的存在不证明该能力已经具备。仅在接通上述契约的普通频道搜索来源启用；相似网红、营销项目、AI 扩量/匹配不因共用组件自动启用。

### 4.4 条件保存与恢复

URL、摘要、书签和返回恢复同时保存窗口、账号突破条件、存在性条件及语义版本，保留原关键词/排除词/筛选。

- **书签重开**：保存相对窗口，按新的查询截止时点解析；不保存固定命中作者名单或把旧批次当实时结果。
- **本次分页/返回**：保持当前快照和已解析范围；上下文失效时重新查询并提示。
