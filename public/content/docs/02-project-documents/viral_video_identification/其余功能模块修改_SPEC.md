目标是在用户现有的找作品、找作者、查看内容与监控链路中消费爆款识别结果。除新增榜单外，沿用原页面布局，只增加必要的筛选、视频标记、简短统计和依据入口；其他模块不再制作独立 Demo。

| 纳入，待研发排期 | 三平台频道搜索 | “近期有爆款视频”、命中作品、计数及书签/恢复配套 |

## 2. 所有模块共用的要求

### 2.1 查询与展示

- 服务端返回判定、证据、聚合与排序所需结果；前端不计算阈值、分位、基线、倍数、预测或 fallback 标签。
- 同视频只有在**计算用途、观察范围、批次/版本和权限上下文相同**时要求一致；公共存量与监控近期结果分别命名、说明时间，不能互相覆盖。
- 查询先确定原业务范围，再关联结果、执行筛选、去重、计算总数和分页。禁止只在当前页补标后过滤、从可见几行计算全量命中数或覆盖率。
- 标签使用“广泛热门”“账号突破”，双命中显示两个标签。完成评估但未达标不叫“已入选”，不可判定不作为普通视频或未达标。
- 状态提示带视角，例如“账号突破：数据不足”；保留零值、缺失、受限、不适用、未覆盖、过期与撤销的差别。
- 视频级类型与状态的组合、冲突禁用/拒绝规则见计算 SPEC。单视角状态只看该视角；不得隐含执行“广泛热门命中 AND 账号突破不足”。
- 原关键词、地区、分类、形态、日期、业务指标及排序维持各自对象含义。作者地区不等于内容市场或受众地区，未知作者所在地显示“—”，不拿其他字段补齐。
- 切换筛选只查询已发布结果，不触发重算、采集提速、扣配额、创建监控或生成 AI 报告。

### 2.2 筛选、依据和操作

| 组件 | 增量要求 |
| --- | --- |
| 筛选区 | 放在原筛选面板；默认不限，复用原提交/重置行为，不增加独立全宽说明区 |
| 已选条件摘要 | 回显真正生效的视角、状态和窗口；支持单项移除与清空，不能回显已被服务端忽略的条件 |
| 视频卡片/表格行 | 标签靠近标题/内容身份区；原播放、赞评、发布日期与业务字段保持 |
| 识别依据 | 复用共用抽屉；先结论与关键解释，再按需展开口径，来源视角优先；数据不足不伪造对照 |
| 返回 | 刷新、分页与返回保留条件；从依据返回恢复原列表位置；可用上下文失效时显式提示重新查询 |
| 原平台、作者、监控 | 沿用原真实入口、权限、项目选择与配额；标签自身不触发写操作 |

### 2.3 统计、异常与权限

覆盖统计必须由服务端按全量业务范围和权限计算，分视角返回适用、已评估和命中数量；不适用对象排除，待识别/不足保留在适用分母，未知或零分母显示“—”。爆款结果筛选不能把覆盖分母缩成已命中的集合。具体字段与去重口径见计算 SPEC。

| 情况 | 页面行为 |
| --- | --- |
| 列表加载 | 沿用原加载组件，不短暂显示“无爆款” |
| 业务列表成功、部分判定未覆盖 | 保留原内容，局部显示可用结果/限制；不能把缺失视角补成 pending 或未达标 |
| 请求失败 | 错误提示与重试；不得伪装成未覆盖或真实空结果 |
| 依据请求失败 | 保留原列表结果，抽屉提供失败与重试，不编造原因 |
| 批次延迟/过期 | 显示真实截止时间与延迟/历史状态；无有效命中时不贴当前爆款标签 |
| 受限 | 服务端先裁剪再聚合/下发；不泄漏隐藏指标、样本、基线、内部原因码及证据 ID |

## 3. 视频搜索

真实入口：`/search/{youtube,tiktok,instagram}/video`。

| 项目 | 要求 |
| --- | --- |
| UI | 在原筛选区加爆款类型与识别状态；结果项加标签和“识别依据”，保留原搜索框与结果形态 |
| 数据 | 原业务条件与新条件按已定义语义组合，服务端筛选后分页；保留原相关性及支持的指标排序 |
| 平台 | 三平台分别查询；未知/不适用的视频形态不得强行取得视频标签 |
| 来源承接（可选） | 榜单单视频“AI推荐关键词”启用时，按榜单 SPEC 第 7 节接收同平台与用户确认的搜索词；默认不复制全部榜单条件，不自动强制爆款结果 |
| 验收 | 同上下文标签与榜单一致；双命中/单命中正确；单视角状态归属明确；空、未覆盖、失败和受限可区分 |

从榜单单条视频进入搜索，是基于已确认关键词查找相关主题内容，不保证同类创意、爆款属性或名次一致。沿用原搜索框、结果形态、排序与条件摘要，不增加另一套搜索 UI；按榜单 SPEC 保存来源和合法返回地址。只有实际生效的条件才在摘要回显；推荐词不能以隐藏条件附加，不能把所有候选词未经确认按 OR 提交。

该入口是否本期交付由研发评估。未启用时，榜单相关入口整体隐藏，视频搜索本身的爆款筛选、标签与依据仍按本 SPEC 交付；不保留无关键词的旧跳转作为替代。打开依据、进入作者再返回仍保留原搜索条件、页码和位置。

## 4. 频道搜索：近期有爆款视频

真实入口：`/search/{youtube,tiktok,instagram}/channel`。该条件找作者；频道内容筛选则找该作者的具体作品。

### 4.1 控件与唯一含义

在原高级筛选增加“近期有爆款视频”，默认不限；近 30/90 天为待确认候选，不是算法观察年龄或实时刷新承诺。默认任一有效视角命中，是否开放广泛热门/账号突破的单独控件待交互评审；本期不增加次数阶梯、爆款率或“无爆款”反向筛选。

频道必须同时满足：**原频道搜索条件 AND 指定发布时间范围内至少一条可访问、适用且当前有效命中的视频**。服务端在公共存量识别上下文中完成全范围存在性查询、计数、去重和过滤，再计算频道总数与分页。不能用关联视频的有限样本判断作者是否入选。

| 语义 | 规则 |
| --- | --- |
| 近期 | 按视频发布时间，以固定截止时点 T 解析 `[T−N×24h, T)`；缺失/异常发布时间不进入范围，不能用首次识别或采集时间代替 |
| 有效命中 | 沿用计算 SPEC 的 qualified、fresh、valid、allowed 与适用形态；过期、撤销、待观察、不足及非视频不计命中 |
| 去重 | 视频按平台+视频 ID、作者按平台+频道 ID；任一视角查询中同视频双命中只计一条 |
| 关键词 | 保留原频道召回语义；默认不要求导致作者入选的爆款与搜索词相关 |
| 原地区/分类 | 保持频道条件原含义，不自动变成视频市场/分类限制；视频约束另标对象和聚合范围 |
| 不可见作品 | 不通过筛选资格、计数或证据 ID 泄漏存在性；不是先聚合隐藏作品再隐藏明细 |

筛选提示使用：“统计该作者近期作品，不限定与搜索词相关。”因此不能把结果称为“该主题爆款作者”。“同一视频同时符合关键词和爆款”是另一种内容级约束，后续单独评审。

### 4.2 计数、命中作品和上下文

- 频道聚合须独立返回范围完整性（完整/部分/未知）及计数精度，不复用单视频的 `coverageStatus`。每条视频的两视角都纳入结果服务，不代表作者整个发布时间窗口已完整覆盖；精确值或已知下界由服务端在选定视角与权限范围内判定。
- 完整已声明范围内的精确计数可显示“近 30 天有 2 条已识别爆款”；覆盖不全但已有可见命中时显示“近 30 天至少识别到 2 条”。不得从已知下界反推精确总量或爆款率。
- 部分覆盖仍可凭明确命中入选；未检出不代表该作者没有爆款。空结果用“当前已覆盖范围未找到符合条件的频道”。
- 行内增加“查看命中作品”，复用现有明细/抽屉，展示导致当前频道入选的作品与依据；关联视频默认列表不含这些作品时，需提供专门的命中作品读取。
- 搜索、总数、计数、证据作品与翻页固定同一用途/范围、截止时间、批次/版本和权限上下文。证据必须属于当前频道并符合窗口与视角。
- 下钻带入可校验的上下文、发布时间范围及视角；过期或权限变化时提示重新查询，不能静默换批次、窗口或证据。

### 4.3 服务端必须提供的聚合能力

| 部分 | 最小消费语义 |
| --- | --- |
| 查询 | 相对发布时间窗口、视角、至少一条的存在性条件、原频道条件及关键词语义版本 |
| 上下文 | 计算用途/范围、截止时点、解析后的起止范围、结果批次/版本、权限范围或可校验的上下文 ID |
| 频道行 | 平台、频道 ID、可见命中数、精确值/已知下界、独立的聚合范围完整性 |
| 证据 | 同频道、同范围、同上下文且可访问的视频引用，以及更多命中作品的分页读取方式 |
| 响应 | 过滤后的频道总数/分页；不支持、失败、批次过期时有明确响应，不能忽略条件返回未过滤列表 |

字段名、URL、索引/预聚合方案、成本和性能由研发评审决定；当前关联视频 API 的存在不证明该能力已经具备。仅在接通上述契约的普通频道搜索来源启用；相似网红、营销项目、AI 扩量/匹配不因共用组件自动启用。

### 4.4 条件保存与恢复

URL、摘要、书签和返回恢复同时保存窗口、视角、存在性条件及语义版本，保留原关键词/排除词/筛选。

- **书签重开**：保存相对窗口，按新的查询截止时点解析；不保存固定命中作者名单或把旧批次当实时结果。
- **本次分页/返回**：保持当前快照和已解析范围；上下文失效时重新查询并提示。
- **旧书签**：缺新增字段按不限恢复；过时/不支持的非默认条件须提示，不能静默删除。

## 5. 频道内容、监控、品牌资产与视频详情

| 模块与真实入口 | 最小 UI 改动 | 数据与边界 | 必须验收 |

品牌 `topVideoRate` 沿用原口径；新标签说明固定表达：“视频级爆款识别与品牌原‘爆款制造率’口径不同，不能直接比较。”旧指标的可证实定义及限制见 [保留结论汇总](保留结论汇总.md)，不得静默改名、换分母或回填历史值。

## 9. 模块验收 Checklist

- [ ] 视频搜索：三平台类型/状态组合、过滤后分页、原排序、空态/失败/受限均正确。
- [ ] 可选 AI 搜索承接：启用时，确认有效词后同平台搜索，条件回显与返回正确；未交付时相关入口无占位地隐藏，独立视频搜索功能仍可用。
- [ ] 频道搜索：只有范围内可访问有效命中才入选；旧视频近期新识别不误入；窗口起点计入、终点排除。
- [ ] 频道搜索：双标签不重复计数；部分覆盖显示至少数；隐藏作品不泄漏资格、计数或 ID。
- [ ] 频道搜索：命中作品属于当前频道、符合窗口/视角；关联样本未返回该作品时仍可下钻查看。
- [ ] 频道搜索：关键词只按已说明的频道语义使用；没有暗示命中作品必与搜索词相关。

- [ ] 来源隔离：无聚合能力的相似、营销、AI 来源不启用新筛选，也不忽略已提交的非默认条件。
- [ ] 频道内容：同上下文标签/状态一致；统计分视角、分母明确；返回原列表位置。
