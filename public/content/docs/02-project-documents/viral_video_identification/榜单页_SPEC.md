## 1. 页面目标与范围

让品牌在指定平台和内容范围中发现表现突出的作品，并从作品进入作者频道判断合作线索。一行代表一条视频；作品入选不等于作者合作效果或内容可复制。

- 本期只使用账号突破规则；不向用户展示该类型名、类型标签或类型切换，内部保留 `account_breakout` 标记；含义与结果契约统一引用[计算规则 SPEC](计算规则_SPEC.md)。监控近期识别／增长爆发为后续 TODO，不新增其他类别榜单、标签、筛选或占位。
- 沿用聚星现有导航、筛选和列表框架，保持“平台 → 范围筛选 → 结果上下文 → 单视频表格”的组织。
- 2026-10-27已确认：新榜单沿用现有榜单权限设定，游客/登录、套餐、可见条数及筛选范围以既有配置为准，不新增爆款专属权益或次数额度。真实配置映射及前后端一致执行需联调验收；本文不另造具体免费条数或套餐价格。
- 当前 Demo 仍在 `/youtube-video-rank?viralDemo=1` 展示三平台页签；正式新榜建议使用独立 `*-viral-video-rank` 路径族，保留旧 HOT URL，详见第 11 节待评审方案。新路由尚未实现或上线。
- 正式接入时明确旧 HOT 榜与新爆款榜的关系，不静默替换旧指标含义。旧榜兼容/重定向方案待路由评审。
- 不纳入作者聚合榜、连续上榜、名次升降、历史榜期、我的榜单、话题/音乐聚合、综合推荐分、预测或自动预警。
- 2026-10-27已确认：本期不额外建设新的榜单导出功能。其他模块已有导出只适配新增筛选范围，保留原模板与对象，不新增爆款字段，见其他模块SPEC第6节。

## 2. 页面结构

| 顺序 | 区域 | 展示与行为 |
| --- | --- | --- |
| 1 | 页面头部 | 面包屑、标题“爆款视频榜单”、一句说明与作者日常表现比较的用途说明、实际更新时间、“榜单说明” |
| 2 | 平台页签 | YouTube / Instagram / TikTok；沿用现有平台组织与图标 |
| 3 | 常用筛选 | 地区、分类、内容形态、作者体量、发布时间 |
| 4 | 高级筛选 | 语言、推广属性、关键词、当前结果批次；按接口实际能力提供 |
| 5 | 生效条件 | 原 Filter Summary，支持单项移除与清空 |
| 6 | 结果上下文 | 当前列表总数、评估覆盖、截止时间、排序说明及更新异常 |
| 7 | 单视频表格 | 名次、视频、作者、播放量、点赞数、评论数、操作 |
| 8 | 分页/空态 | 沿用原组件，保留范围与上下文，不以普通视频补位 |

公共识别以日更为产品目标，允许随公共视频数据更新触发增量计算；不强制每日全量重算，也不承诺每条视频每天取得新快照。结果更新时间只说明发布/榜单更新，不能代替行内依据的实际采集与评估时间。计算可以增量，列表仍须固定版本/截止时间并稳定分页；新上下文按30/90天范围移出超窗作品，不依赖其再次采集。生产触发及发布延迟待研发落实，详见计算SPEC第3.5节。

结果上下文不提供无源视频的“搜索更多同类视频”全局入口。相关内容搜索与单条视频绑定，启用时在该行“更多”中提供“AI推荐关键词”，沿用既有次要操作和推荐词选择交互，不增加完整卡片或独立区域。是否启用及隐藏规则见第 7 节。

### 2.1 向用户解释爆款口径

不新增完整说明区域或改变表格结构，复用标题下的一句用途说明及右上角“榜单说明”展开入口。

- **默认常驻**：“对比作者此前同一内容形式的视频，累计播放量达到历史中位数的 10 倍及以上。”核心规则不能仅藏在悬停提示中。
- **判定方式**：说明同作者、此前同一内容形式、累计播放和中位数；解释中位数是历史样本排序后的中间水平，不是平均值，且不含本条视频。
- **参与条件**：YouTube长视频需发布满7天，Shorts/TikTok视频/Instagram Reels需满3天，并有足够历史样本；未满时长是待观察，样本不足或关键数据缺失暂不判定，均不入榜。到达时长不代表立即重新采集或自动命中。
- **数据说明**：比较已采集的累计快照，不是同发布年龄的增速；点赞和评论不参与判定，倍数不代表榜单名次；按判定快照播放量降序，同播放量较新发布优先，只显示当前有效结果。
- **Demo 边界**：10倍和7天/3天为当前暂定口径，后续可调整；历史样本量仍未定。明确模拟数据不证明全量覆盖或及时更新，不额外编造未经确认的参数。正式版依据当前已启用规则展示实际阈值和参与条件，不输出“待研发确认”等过程文案；平台/形态切换后说明与实际规则一致。

说明中的时间范围解释候选近90天、默认近30天、按发布时间筛选和清空恢复30天，并明确作者历史参考不受90天限制。

“榜单说明”默认收起，通过键盘或点击展开/收起；`aria-expanded` 与内容显示一致。增加“时间范围”和“地区口径”段，说明频道国家、全球包含未知国家以及具体国家仅匹配已知归属；展开说明分段换行，使用现有次级文字与布局，不新增卡片、抽屉或营销式标记。切换说明不更改 URL、筛选、列表、识别状态或排序，也不发起业务请求。当前示例见[口径说明展开态](assets/榜单_口径说明.png)。

设计依据沿用第9节引用的设计规范 README、语义 token 和 Accessibility；代码为 Demo 分支的 `pages/youtube-video-rank.vue` 与 `components/viralVideoDemo/messages.js`。本轮仅在本地3323预览核对文案、键盘状态和布局，不代表线上发布或真实算法验收。

## 3. 入榜资格与排序

### 3.1 入榜资格

服务端对当前平台与固定结果上下文查询账号突破。只有适用、允许读取且 `qualified + fresh + valid`、发布于当前批次截止时间前90天内的视频进入榜单；状态与契约统一引用计算 SPEC。

用户不主动选择时查询近30天，控件常驻显示“近30天”；选择近90天扩大至候选上限。默认30天在常用控件中明示，筛选摘要只将非默认90天作为可移除条件；移除或清空恢复30天。旧不限/近7天URL改为30天并提示，其他有效条件保留，不自动展开高级筛选。作者历史对照作品不受90天限制，窗口外视频不等于未达标。公共计算也在目标发布超过90天后停止自动首次判定及重算，但已有快照和历史判定保留，其他模块可按权限读取；详见计算 SPEC 第3.4节。此计算期限不增加榜单控件或一类爆款标签。

未达标、数据不足、待观察、未覆盖、过期、撤销、不适用或受限均不能入榜。没有结果不补成“未达标”或“待识别”。

榜单不提供普通列表的复杂识别状态筛选，也不提供与入榜资格必然冲突的未覆盖、数据不足或待观察选项。评估范围与覆盖限制保留为结果说明，不另建筛选维度。

### 3.2 排序与名次

- 资格决定能否入榜，排序决定名次。已确认按判定快照累计播放量降序；同播放量优先发布时间较近的视频，仍相同以平台原生视频ID固定字典序升序，倍数不参与名次。
- 正式列表由服务端返回账号突破的顺序、分页与名次，使用已发布的排序策略版本与 `rankKey`。前端不重排、不从播放量/倍数重算名次。
- 2026-10-27 已确认上述业务顺序。名次为当前筛选范围内的连续序号，跨页延续，不显示并列名次。服务端稳定分页、排序键编码及缺键异常仍需联调验收；Demo 用固定键模拟已排序的结果，不能将其编码直接搬作生产实现。
- 页面“排序依据”直接说明“按判定快照累计播放量降序，同播放量优先发布时间较近的视频；仍相同时保持固定顺序”，不再对用户展示“按模拟排序键降序”。
- 不在跨平台、不同用途、不同观察范围或不兼容版本间比较名次。切换平台后从第一页重新展示。
- 首期播放、点赞、评论表头不提供自由排序；按原指标查找通过视频搜索完成，搜索顺序不保证复现榜单名次。
- 更新采用实际成功发布的结果；刷新只取结果，不触发采集/重新计算。每日更新、实时更新等频率须有服务端 SLA 后才能对外承诺。

## 4. 筛选与上下文

### 4.1 条件语义

| 条件 | 要求 |
| --- | --- |
| 平台 | 独立数据范围；切换时移除不适用形态/属性并提示，保留仍适用条件 |
| 频道国家/地区 | 沿用频道榜中频道记录的国家归属；先限定频道，再取其爆款视频。全球不加国家限制，未知国家只可进入全球范围；不与内容市场、受众地区或视频语言互相映射 |
| 分类 | 使用结果服务声明的内容分类，缺失/不支持不暗中转为其他分类 |
| 内容形态 | 按平台确认普通视频/Shorts/Reels 等；带货/推广属性不混成视频形态 |
| 作者体量 | 沿用产品体量分档，明确边界与搜索粉丝区间的映射，边界作者不重复/漏选 |
| 发布时间 | 只筛视频发布时间：近30天/近90天，缺省和清空回近30天，不提供不限/近7天。按当前批次截止时间回推，榜单候选最多90天；不代表指标采集时间，不更改历史基线 |
| 语言/推广属性/关键词 | 只提供后端支持的条件，不用前端当前页过滤冒充全量筛选 |
| 结果批次 | 本期展示当前成功批次；历史批次浏览不因一个下拉控件自动成为首期能力 |

所有条件在服务端按约定组合并过滤后分页；改变条件回到第一页。生效条件在摘要中完整显示，移除后结果/URL/分页同步更新。加载失败保留用户当前条件供重试，不静默清空。

### 4.2 覆盖率与结果数

“已评估”表示完成账号突破的有效评估，“命中/已入选”表示达到账号突破条件。用户文案不得把二者都叫“已识别”。

以当前平台、内容形态、地区、分类、作者体量、发布时间、语言、推广属性及关键词定义业务范围 S；不先以“已命中”缩小 S。

- 服务端在 S 中按平台+视频 ID 去重，并先执行权限裁剪。
- `eligible`：S 内账号突破可适用的视频数。不适用对象排除；待识别、不足、未覆盖、过期/撤销留在适用分母中。无法知道全量适用数时返回未知，不用已加载页数代替。
- `evaluated`：S 内账号突破结果新鲜、有效且已判定为命中或未达标的视频数。
- `hits`：S 内账号突破当前有效命中的视频数。该计数与可入榜列表总数分开；缺少兼容排序键的有效命中仍计入 `hits`，但不能入榜。仅在排序数据完整可用时二者才可能相等。
- 覆盖率 = `evaluated / eligible`，由服务端返回；未知或零分母显示“—”。前端不从分页数据推算。
- 单记录 `coverageStatus=full` 仅表示账号突破纳入服务，不等于数据充分或业务范围已完整评估。

界面优先显示“共 N 条入选视频 · 数据截至……”。覆盖率旁用轻量说明解释“已评估 E / 适用 A；命中 H”，避免所有计数常驻抢占主阅读路径。未知分母同时说明“覆盖范围暂不可确认”。

## 5. 视频表格与下一步操作

| 列 | 展示要求 | 操作 |
| --- | --- | --- |
| 名次 | 服务端返回当前筛选范围的连续名次，跨页延续；同值已按发布时间和稳定ID分出顺序，无并列名次 | 无升降/新上榜标记 |
| 视频 | 原平台封面、标题、形态、发布日期；标题最多两行 | 新标签页打开源站原视频，保留榜单条件与位置 |
| 作者 | 头像、名称、粉丝数、频道国家/地区（未知显示“—”） | 进入现有频道内容页 |
| 播放量 | 主行本条播放量与已提供的倍数；次行“历史中位数 + 基准原值”，不新增列 | 悬停/键盘聚焦查看样本与比较范围；不自由排序 |
| 点赞数/评论数 | 与播放同一声明快照；缺失“—”，真实零显示 0 | 不自由排序 |
| 操作 | 更多 | 提供加入现有内容监控；可选提供该视频的“AI推荐关键词”；原视频入口与内容链接合并 |

- 不设置整行点击；作者、视频和更多动作彼此独立。
- 作者频道国家未知显示“—”，禁止用内容市场、受众地区、语言或访问IP补齐；频道国家不解释为作者国籍或实际居住地。
- “账号突破”只表达相对作者常态的突出表现，不合成总分或作者等级。该名为研发内部定义；榜单所有记录都已入选，不单列“爆款判定”或逐条重复标记，移除榜单“查看依据”入口及抽屉，比较范围与样本放在行内基准说明中。
- 播放量单元格维持两级信息：主数值按原正文样式，倍数用小号品牌色弱强调；历史中位数用次级文字，数值等宽对齐，不新增进度条或独立类型列。例：“980,000  20× / 历史中位数 49,000”。这些数字为模拟示例，不是正式阈值。
- 本期计算使用中位数，界面不能改叫“频道平均值”。悬停或键盘聚焦基准行说明：同频道、此前同形态作品的累计播放中位数、样本量、不含本条、使用判定快照；采集时点可能不同，不是同龄对比或频道全部作品平均值。说明入口有明确焦点态。
- 榜单行内对照与其他模块的依据读取相同上下文的 `evidence.baseline.medianViews`、`multiplier` 和样本信息。基准必须为服务端已授权的有限正值，作者/形态一致；过期/撤销/受限不继续展示当前对照。基准缺失时显示“基准未提供”，不从播放量和倍数反推；倍数缺失仅隐藏倍数，不隐藏已有有效中位数。该展示缺失不改写判定状态，正式接口需保证可用证据一致。
- 短对照只用服务端可公开证据。账号倍数需有效正基线与符合最低发布时长及快照政策的历史样本，不再要求同龄匹配。未提供时说明“当前未提供该项对照”，不补百分比、门槛或图表。
- “为什么入选”和“为什么排在前面”分别说明。累计播放快照决定主排序，突破倍数解释入选；不以倍数冒充排名依据。
- 原平台与监控继续原权限、项目选择和配额链路；查看行内说明或改变筛选不创建任务、不扣配额、不触发 AI。加入监控不自动触发公共爆款重算，不承诺早期识别或立即获得新判定。

## 6. 共用“识别依据”抽屉

**本节仅供搜索、频道、内容监控与品牌等其他模块的状态解释参考，榜单不再挂载此抽屉，也没有查看依据入口。**

默认先回答“是什么作品、是否突破作者常态、与谁比较”，具体结构如下：

1. 固定标题“识别依据”和关闭按钮，合并视频/作者身份。
2. 一句话结论，如“已入选爆款”；不展示判定类型名。下方直接解释相对作者常态的表现与当前状态。
3. 播放、点赞、评论三个主要指标，附快照观测时间。
4. “比较范围与数据说明”默认收起，不再按类型增加小标题，包含比较对象、历史播放中位数、样本量、补充互动、观察及评估时间、限制。

## 7. 跨页承接与可选 AI 推荐关键词

### 7.1 本期交付取舍

按复用频道搜索“AI推荐关键词”的能力设计，入口属于单条视频，用户确认搜索词后进入同平台视频搜索。**这是可选增强，不是榜单主流程的必交依赖。** 研发评估排期、数据可用性、原始关键词提取及推荐效果后决定本期是否启用；情况不允许则隐藏整个入口，仍按本 SPEC 交付榜单、筛选、标记与依据。

- 未启用时，列表、更多菜单及复用的相关抽屉不展示入口、禁用按钮、“敬请期待”或空占位；不以无关键词搜索替代。
- 已启用但某条视频事先可确认无有效文本、无权限或不满足现有 AI 使用条件时，按现有权限交互处理，不发起无效生成，不从作者名、播放指标或其他视频猜主题。
- 本节只定义功能与隐藏行为，不要求新增后台配置页或独立推荐系统；具体能力开关与现有权限/配额复用由研发确定。

### 7.2 推荐与确认流程

1. 用户主动点击该视频的“AI推荐关键词”；只取该源视频权限范围内可读取的标题/描述、标签等作为主题证据。现有接口支持 `videoIds`；不能直接把频道搜索结果集合与全部作者标签混作该视频主题。
2. 先保证核心主题及原始关键词提取准确，再按视频检索目的生成少量候选词。保留对象、动作、作品/角色、场景与消歧限定；避免泛流量标签、无依据的竞品/品类扩展或语种歧义。复用调用链不代表原 Prompt 可以不经适配直接使用。
3. 沿用既有推荐词选择交互，允许用户确认、修改搜索词或取消；只有用户确认有效非空搜索词后才跳转。不自动逐词执行多次搜索，不承诺“更多同类视频”或相同创意。
4. 生成中采用原操作的轻量 loading 并防重复点击，列表与榜单状态保持。无可靠候选时说明“暂无合适的推荐关键词”，允许修改/手动输入或取消；请求失败提供重试，不伪装成生成空结果。
5. 主动生成沿用现有 AI 权限与配额策略，具体规则由研发确认；仅浏览榜单、筛选、分页、打开/关闭依据或返回不触发生成与扣费。

### 7.3 搜索范围与返回

这是从作品出发查找相关主题内容，不是把全榜单筛选复制到另一个列表。默认仅传入同平台与用户确认的关键词，界面说明“使用所选关键词搜索当前平台视频”。不自动强制结果仍为爆款，不承诺搜索顺序与榜单一致。

| 上下文 | 承接要求 |
| --- | --- |
| 平台 | 与源视频一致，进入 `/search/{platform}/video` |
| 搜索关键词 | 使用用户本次确认的词，显示在原搜索框/摘要；不静默拼入榜单已有关键词或把推荐词全量按 OR 提交 |
| 形态、分类、日期、作者体量、地区、语言、推广属性 | 默认不继承；如沿用已有承接能力，须由用户确认且语义等价，搜索页完整回显、可移除，不声称自动保留所有榜单条件 |

业务对象已确认，不再作为待评审取舍；仍须研发对齐频道榜国家字段与视频作者关联、来源和可用性，才能启用生产国家筛选及SEO入口。已核查频道榜新旧查询均过滤频道记录的country；详情库字段可能叫country_code，需显式映射。不得把旧HOT的data_region或视频内容市场当作该字段。Demo已使用独立固定频道资料creator.country，scope.market保留为不同对象，不再用于榜单国家筛选或展示兜底。源码证据见[结论汇总8.5](保留结论汇总.md#85-频道榜国家口径核查与本版决定)。

- 国家未知的作品可在适用且有效时进入全球范围，不分配到某个国家；频道国家未知继续显示“—”。
- 国家筛选不改变作者历史基线或判定；频道信息、列表、计数与结果上下文应一致，不能翻页时临时换用另一版本的频道地区。
- 当前筛选示例见[频道国家筛选](assets/榜单_频道国家筛选.png)。Demo旧market查询不是频道国家同义参数：移除非默认market时明确提示重新选择，保留合法country及其他筛选。不得静默把旧市场条件当作频道国家；正式旧HOT页面不受此兼容处理影响。
- 全球指没有国家限制的已覆盖公共结果，不承诺覆盖全网；同一全球 URL 不因访问 IP、登录账号、站点语言或历史偏好改变默认国家。
- 前端、结果查询、聚合分母、排名、SEO 标题及缓存键必须使用同一国家范围。切换国家只筛选结果，不能更换作者历史基线或重算阈值。
- 规范国家码建议使用 ISO 两位码，路径小写；英国使用 `gb`，展示可用“英国 / UK”。如实际服务仍需 UK，必须在接口适配中显式映射；新路径 `uk` 仅作为别名重定向到 `gb`，不更改旧 HOT 路径。
- 站点语言与内容语言分开：英文站的日本国家榜仍是日本作者范围，不自动附加“视频必须英语”。内容语言继续作为额外筛选条件。

### 11.5 入口与筛选的衔接

1. **一级导航**：在对应平台下增加“爆款视频榜”入口，先落到该平台全球榜；不新增“账号突破榜”等类型入口。
2. **国家筛选**：沿用现有榜单国家/地区下拉；不新增六国快捷链接、国家导航条或独立门户。选项根据实际支持的国家范围提供。

4. **筛选控件**：改变国家时保留其他仍适用条件，用“国家路径 + 高级 query”恢复；若存在高级条件则是筛选结果页，不冒充纯国家 SEO 页。摘要完整显示实际生效条件。
5. **切换平台**：国家和其他条件受支持时保留；未有该国家独立 SEO 入口、但接口支持该国家筛选时，可保留为不索引的 query 结果，不为跳到静态入口而擅自清空条件。不支持的条件明确提示后移除。
6. **URL 恢复**：已有独立 SEO 路径的纯国家 query 同义入口归一到该规范路径；尚未登记独立路径、但接口支持的合法国家继续保留 query，不执行到不存在路径的重定向。路径国家与 query 国家冲突须明确报错/提示纠正，不静默忽略有效条件。无意义默认参数及追踪参数归一不改变结果范围。
7. **站内互链**：复用现有导航和相关榜单位承接三平台全球榜；回到全球通过原国家筛选选择“全球”。不额外增加国家快捷区或跨平台同国链接区，不改变旧页面默认结果。

交互继续沿用现有表格、筛选摘要和链接的语义 token、焦点状态与键盘行为。设计依据见第 9 节的设计规范 README、Filter Summary 与 Accessibility 引用，不新增一套榜单 UI。

### 11.6 哪些页面可索引

| URL 类型 | 首期策略 | canonical / sitemap |
| --- | --- | --- |
| 已登记且审核通过的平台全球页、国家页 | 可索引；SSR 输出该范围的公开结果、唯一标题与 H1 | 自指规范路径；列入本语言站的新榜 sitemap 白名单 |
| 大小写/尾斜杠/全球长路径/UK 等同义别名 | 单跳永久重定向到相同范围的规范路径 | 不单独进入 sitemap |
| 仅带来源追踪的等价页面 | 归一到不含追踪参数的同范围 URL；不改变用户结果 | canonical 使用干净路径 |
| 分类、形态、作者体量、非默认发布时间（90d）、语言、推广属性、关键词等额外筛选 | 保留功能，`noindex,follow`；不自动生成 SEO 落地页 | 使用归一后的同范围 URL，不把不同结果集合一律 canonical 到全球；不进 sitemap |
| 分页第二页及以后 | 首期不作为独立 SEO 落地入口，`noindex,follow`；仍可分享并服务端恢复 | canonical 保留自己的页码，不指到第一页；第1页归一到不带 page 的 URL |
| 历史批次、内部类型、Demo 参数 | 不是首期索引入口；生产拒绝未支持的业务参数，Demo 保持 noindex | 不进 sitemap，不产生历史榜期承诺 |
| 未登记的国家独立 SEO 路径、非法国家码或非法路径组合 | 404；接口支持但没有独立 SEO 路径的合法国家 query 按上方 noindex 筛选结果页处理；不得返回“全球榜”冒充有效国家页 | 不进 sitemap |

默认SEO入口展示近30天发布的榜单结果；缺省与显式30d是同义入口，归一到同一平台/国家规范路径。90d是非默认筛选，按noindex、follow和同范围规范URL处理，不新增独立SEO落地页。国家入口是否有足够内容按默认30天范围审核，不用90天池数量冒充默认供给；空榜不自动扩至90天，由用户主动选择。

国家是不同业务范围。**美国页不能全部 canonical 到全球页，否则该国家入口失去独立规范页面身份。** Google 的 canonical 用于重复或非常相似的页面，不应被用来掩盖不同筛选集合；分页也不应全部指向第一页。参考 [Google canonical 指南](https://developers.google.com/search/docs/crawling-indexing/consolidate-duplicate-urls)、[分页指南](https://developers.google.com/search/docs/specialty/ecommerce/pagination-and-incremental-page-loading)。

本方案选择对可分享的高级筛选页使用 noindex，并控制自动生成链接与 sitemap 范围；不要同时用 robots.txt 阻止这些页面抓取，导致搜索引擎读不到 noindex。抓取规模的进一步控制由 SEO/研发单独配置，不把全部筛选排列暴露成链接池。参考 [Google 筛选导航指南](https://developers.google.com/crawling/docs/faceted-navigation)及 [noindex指南](https://developers.google.com/search/docs/crawling-indexing/block-indexing)。

### 11.7 页面内容、元信息与发布门槛

- **标题**：`{国家或全球} {平台} 爆款视频排行榜 - Nox聚星`；英文示例 `Viral YouTube Videos in the United States | NoxInfluencer`。H1 表达同一范围，站点语言与国家分别解析。
- **用途说明**：说明已覆盖范围、国家对象和相对作者历史表现；不把本榜叫作 Most Viewed、实时热点、全网最热或投放效果榜，不暴露内部类型名。
- **真实差异**：国家页必须实际过滤同一国家结果，并展示对应有效入榜总数、当前批次/截止时间、历史中位数对照与限制。只换标题、列表仍是全球结果不能发布。
- **SSR**：首屏在服务端输出可授权公开的标题、说明、视频列表、现有导航链接与元信息，不能只有客户端执行后才出现的空壳。不能为 SEO 绕过权限；没有合法公共内容的入口不发布为可索引页。
- **多语言**：复用现有语言域名策略；仅在对应翻译与内容页面就绪时设置同一国家/平台范围的 hreflang，不能把日本国家榜的英文页配成美国国家榜。各语言站按实际就绪情况发布，不自动承诺全部语言或国家同时开放。
- **入口注册表**：集中维护平台、国家、规范路径、标题 key、路由可用性和 `indexEnabled` 等发布配置。路由登记与允许索引分开：已登记但暂不索引的有效入口仍可正常访问；未登记的独立路径才返回404。结果从当前成功批次读取，发布开关依据真实内容量与连续可用性审核，不从 Demo 的43条样例推出生产门槛；索引门槛与负责人需在上线清单记录。
- **空态与失败**：尚未具备稳定内容的国家入口不加入索引白名单。已登记入口暂时无有效结果时诚实展示空态，保留该路由并按 noindex 暂停索引发布，不重定向到全球、不补普通视频。接口失败独立处理：可保留仍有效的上次成功结果并标明实际时间；无可用结果时返回可重试的服务失败，不把服务故障当作不存在或成功的空榜。
- **sitemap**：只列已审核可索引的规范首屏地址，lastmod 使用实际成功更新时点，不写请求时间。国家页新增后必须同步 sitemap 生成器，不能只把 URL 加进导航。

#### 11.7.1 SEO meta 按入口区分

**每个可索引的固定榜单入口都要有准确表达其范围的 title 和 description，不能只区分 URL 或 H1。** 本次线上实读中，YouTube 国家榜和涨粉榜已体现这种差异；TikTok 美国榜的 description 仍通用，Instagram 美国路径本次读取的 title/description 未体现美国，不能直接照搬。原始响应和浏览器 DOM 证据见[保留结论汇总 8.4](保留结论汇总.md#84-线上-seo-meta-实读补充)。

| 字段 | 本版交付规则 |
| --- | --- |
| `<title>` | 按站点语言、平台、全球/国家及“爆款视频排行榜”生成；同一语言站内不同固定入口可区分，不沿用频道榜、旧 HOT 榜或通用全站标题。当前只有一种判定，不加“账号突破”类型名 |
| `meta description` | 用可读句子说明对应平台、国家对象及相对作者历史表现的用途；国家页明确国家范围，不能所有页面共用全球描述。不堆关键词，不承诺全网覆盖、固定100条、实时/日更或投放效果 |
| H1 与页内说明 | 不是 meta 字段，但必须与 title/description 和真实列表的范围一致。H1 可省品牌尾缀，不能路径美国而页面仍叫全球榜 |
| `canonical` | 使用第11.6节的规范 URL；不同国家自指各自入口，去除追踪参数。不是所有榜单统一指向平台全球页 |
| Open Graph | 输出 `og:title`、`og:description`，与当前页 title/description 表达同一范围；`og:url` 使用同范围的干净规范 URL，不附加分享来源参数。`og:type=website`、站点名和分享图片可以共用，不为形式上的差异逐国制作图片 |
| Twitter Card | 沿用站点分享卡片能力，title/description 与当前页同步，图片可复用。不得残留上一次平台或国家的字段 |
| `robots` | 按索引发布状态、额外筛选和分页策略生成，遵循第11.6节；不因国家不同而随意改变。同一响应的 meta 与 HTTP 索引指令不得冲突 |
| `hreflang` | 链接到已就绪的同平台、同国家、不同站点语言的等价页面；与用户筛选的内容语言分开 |
| `meta keywords` | 本方案默认不输出。当前频道榜公共 head 已通过 `suppressKeywords` 抑制该字段；旧 HOT 榜虽保留 keywords，但本次全球/美国音乐页读到相同内容。不能把“每页填写不同 keywords”当作 SEO 验收目标；如另有站内兼容用途，单独记录 |

Google 建议标题和描述准确表达各页内容，并明确不使用 `meta keywords` 参与索引和排名；搜索结果也可能根据页面内容改写标题或摘要。因此验收以页面实际输出为准，不承诺搜索结果逐字显示所配置文案。依据：[标题指南](https://developers.google.com/search/docs/appearance/title-link)、[描述指南](https://developers.google.com/search/docs/appearance/snippet)、[支持的 meta 字段](https://developers.google.com/search/docs/crawling-indexing/special-tags)。

#### 11.7.2 文案示例与生成边界

以下为中文站推荐示例，国家页以第11.3节已确认的频道国家口径为依据，真实字段接入后发布；字段未确认前不能直接拿旧 `data_region` 套用。品牌尾缀按站点统一命名确认，其他语言须分别翻译。

| 固定入口 | title 示例 | description 示例 |
| --- | --- | --- |
| YouTube 全球 | 全球 YouTube 爆款视频排行榜 - Nox聚星 | 浏览聚星已覆盖且近30天发布的 YouTube 爆款视频，对比作品播放量与作者历史中位数，查看相对倍数和作者信息，发现表现突出的作品。 |
| YouTube 美国 | 美国 YouTube 爆款视频排行榜 - Nox聚星 | 浏览美国地区 YouTube 频道近30天发布的爆款视频，对比作品播放量与作者历史中位数，查看相对倍数和作者信息。榜单基于聚星已覆盖的视频识别。 |
| TikTok 日本 | 日本 TikTok 爆款视频排行榜 - Nox聚星 | 浏览日本地区 TikTok 频道近30天发布的爆款视频，对比作品播放量与作者历史中位数，查看相对倍数和作者信息。榜单基于聚星已覆盖的视频识别。 |
| Instagram 美国 | 美国 Instagram 爆款视频排行榜 - Nox聚星 | 浏览美国地区 Instagram 频道近30天发布的爆款视频，对比作品播放量与作者历史中位数，查看相对倍数和作者信息。榜单基于聚星已覆盖的视频识别。 |

- 由同一份已解析入口范围生成规范路径、meta、H1及结果查询条件；复用入口注册表和国际化文案，不逐页面硬编码。国家翻译缺失不得输出原始 key，也不得静默退回全球文案后继续索引发布。
- 首次 HTTP 返回的 HTML head 与浏览器接管后的 head 必须一致；切换平台/国家时同步更新，并去重 title、description、canonical 及同名分享字段，不能只改可见标题。
- 高级筛选和分页仍按第11.6节 noindex；文案准确说明当前是筛选结果/第几页，不误称默认首屏榜。无需为每个 query 组合另策划一套可索引的 SEO 文案。
- 不在稳定 SEO 标题中加入内部类型、批次、阈值、候选参数、样例名次或未经承诺的更新周期；结果数量和真实截止时间放在页内上下文。有效国家页空态/失败时仍保留其真实国家标题，按发布策略处理索引，不改名成全球榜。

### 11.8 实施顺序与验收

建议顺序：确认国家字段/编码 → 确认新旧榜路由隔离 → 配置三平台全球入口 → 对齐受支持的国家筛选、URL与索引配置 → SSR/head/导航/sitemap 联调。分类及形态 SEO 扩展留到第二批，不阻塞本期国家筛选及SEO接入。

- [ ] 国家口径、源字段、未知值、GB/UK 映射及全球不按 IP 补国家已确认。
- [ ] 同一模板按入口恢复筛选，路径/标题/H1/列表/计数/缓存范围一致。
- [ ] 新旧榜独立，旧 HOT URL 和 `video_score` 语义未改变；正式新榜不依赖 Demo 参数。
- [ ] 每个平台至少逐条验证全球与一个已启用国家；通过后检查全部启用白名单，跨平台返回/分享保持条件。
- [ ] 每个可索引入口唯一 canonical、SSR 有授权内容、sitemap 可找到；空态/失败不伪装有结果。
- [ ] 全部启用固定入口逐条验证 title/description 含正确平台与国家范围，彼此可区分，与 H1/查询条件一致；全球页不按访问者位置改成国家页。
- [ ] 对照原始 HTTP head 与浏览器 DOM head：description/canonical/同名分享字段各一份，Open Graph/Twitter 文案同步；站内切换与直接进入均不残留旧 meta。
- [ ] 国家页自指，分页/高级筛选不误 canonical 到全球或第一页；无效组合404，别名不出现重定向链。
- [ ] 域名语言、内容语言与国家互不混用，hreflang 仅指向已就绪的等价页面。

**评审要定的不是复制多少页面，而是：已确认频道国家的真实字段接入、受支持国家的字段/路径恢复、新路径命名及索引发布条件；不再决定固定首批国家数量。** 本节给出可执行推荐，不替代真实数据可用性、生产排序和接口能力的验收。
