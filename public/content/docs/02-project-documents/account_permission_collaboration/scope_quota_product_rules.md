# Scope 配额产品口径

## 能力目标

本页统一说明套餐能力中的 Scope 在产品上如何生效：它可能代表可消耗额度、正在占用的资源、一次解锁、频率限制或功能门禁。

本页不替代各业务域的具体流程。邮件项目、收藏夹、推广任务和 TikTok Shop 私信项目等对象由各自业务正文定义谁能查看、编辑或执行；Scope 只决定账号是否具备执行某项能力以及如何计算使用量。

## 业务前提

- Scope 是套餐与账号权益的能力标识，不应统一表述为“扣次数”。
- 团队会员权益归属主账号；子账号使用能力时，先依赖主账号已有的 Scope，再受自己的分配上限约束。
- 子账号的额度分配只限制其可使用范围，不能为主账号本来没有的 Scope 新增权限。
- 同一项能力是否由团队共享、由单个操作账号独立统计，取决于该 Scope 的产品规则，不能按“主子账号”一概推断。
- 套餐页存在只用于展示的静态能力项；静态展示项不参与 Scope 校验或用量计算。

## 主链路

1. 主账号开通会员或由运营调整权益后，团队获得相应的 Scope 能力和基础额度。
2. 主账号可为子账号设置部分 Scope 的个人可用上限。
3. 用户在具体业务模块执行操作时，系统先校验 Scope 是否可用，再按该能力的产品规则判断团队总剩余和子账号个人剩余。
4. 操作成功后，系统按实际业务对象记录一次使用、占用一个资源席位，或维持一次已解锁状态。
5. 套餐与额度面板据此展示团队可用量和个人可用量；项目协作权限仍由业务对象本身决定。

## 关键规则

### 团队额度与协作权限

- 有限额度的 Scope 同时受团队总额度和子账号个人分配上限限制；任一上限耗尽，子账号都不能继续使用。
- 主账号额度为无限时，子账号仍可能被自己的分配上限限制。
- Scope 不授予项目协作权限。例如，邮件项目是否可操作取决于创建人和协作人规则；TikTok Shop 私信项目不设协作人，店铺与项目按用户归属。即使账号有足够 Scope，也不能越过项目自身的访问与操作规则。

### 模块协作模式

| 模块或对象 | 产品协作模式 |
| --- | --- |
| 推广任务 `RW` | 创建人和正式协作成员共同构成项目成员；成员可以处理该任务下的创作者建联和消息。 |
| 邮件邀约 `YJ`、智能营销计划 `RW2` | 创建人与正式协作成员共享任务级访问和消息协同。创建人还可以把单个对话指定给同账号体系的其他账号处理；被指定账号只能处理该对话，不能取得整个任务的访问权。 |
| 创作者收藏夹、CRM | 是团队协作的入口，创作者沟通和合作状态同时存在个人与团队口径；具体分组和列表操作仍按对象自身权限校验。 |
| TikTok Shop 店铺与私信项目 | 当前不设协作人或多人共享店铺权限。店铺绑定到当前用户，项目从属于店铺；主子账号关系不会自动把某个用户绑定的店铺变成共享项目。 |
| 支付管理 | 不使用项目协作人表。付款单和草稿按创建人记录，团队内可按创建人筛选和查看；草稿等需修改的对象仍按其实际创建 UID 校验。 |
| Shopify 联盟营销 | 管理的是店铺、推广项目和创作者成员，不把创作者成员等同于内部协作人；店铺和项目操作由店铺权限与对象归属决定。 |
| 搜索、榜单、详情、品牌洞察、监控、物流和 Skill | Scope 链路没有定义项目级协作人。它们首先是账号或团队权益：用户是否能使用由团队权益和个人分配决定，涉及资源池、监控任务等业务对象时再由相应模块校验对象归属；不能仅因同属一个主账号体系就推断为可互相编辑。 |

完整的任务级成员、单对话指定协作、消息未读和实际发件账号规则见源知识库中的「创作者协作」；付款单创建人边界见源知识库中的「支付管理」。这两份跨项目文档不在本发布包内。

### 搜索、榜单与详情能力

| Scope | 产品口径 |
| --- | --- |

| `18` 联系方式筛选 | 只在搜索中选择联系方式筛选条件时校验，是筛选功能门禁，不等同于邮箱或 WhatsApp 解锁。 |
| `22` 创作者榜单 | 限制通用创作者榜单的可查看 Top 窗口；默认窗口内可直接查看，超过默认窗口时需具备对应权益且请求范围不能超过配置上限。 |
| `28` MCN 搜索 | 控制 MCN 搜索及其详情入口访问，不计次。 |
| `29` 优质创作者筛选 | 控制搜索中的优质创作者筛选条件，不计次。 |
| `30` 优质创作者合作详情 | 控制 YouTube、TikTok、Instagram 优质创作者的合作信息详情访问，不计次。 |
| `48` 详情内容搜索 | 控制创作者详情页内对内容列表使用筛选条件的能力，不按内容条数扣减。 |
| `60` 合作倾向分筛选 | 只在使用合作倾向分区间筛选时校验，是筛选功能门禁。 |
| `69` TikTok Shop 榜单 | 控制商品、店铺、直播和达人榜单的访问及可查看窗口；付费账号请求范围不能超过配置上限。批量收藏也只能从该榜单可见范围中选择候选，不按每次查看扣减。 |

### 一次解锁与按结果消耗

| Scope | 产品口径 |
| --- | --- |
| `34` 创作者基础信息 | 免费用户首次查看某平台的某个频道详情时占用一次团队额度；同一团队再次查看同一频道不重复占用。付费用户具备该能力时不按免费解锁历史重复消耗。 |
| `2` 创作者详情分析 | 控制创作者详情中的分析数据访问，是功能门禁；不把访问详情表述为一次独立扣量。 |
| `10` 创作者广告分析 | 控制创作者详情中的品牌合作、合作成本和效果等广告分析区域，不计次。 |
| `84` AI 创作者详情 | 团队首次对某平台的某个频道生成 AI 详情分析时占用一次；同一团队后续重复查看或生成不重复占用。 |
| `87` 创作者搜索 | 按最终返回的创作者或视频数量消耗；默认结果、空结果以及在扣量前被过滤的结果不占用。搜索额度按团队月度周期汇总。 |
| `4` 邮箱解锁、`59` WhatsApp 解锁 | 按频道解锁联系方式，而不是按视频或帖子计数；同一团队已解锁的频道不重复占用。用户自己维护的邮箱不消耗邮箱解锁额度。 |
| `51` AI 邮件生成 | 按成功生成的邮件内容份数消耗，一次扩写可能生成多份内容，不能按点击次数描述。 |
| `82` AI 消息 | 每次成功生成一条 AI 回复、总结或润色结果消耗 1。 |

### 资源席位、容量与周期用量

| Scope | 产品口径 |
| --- | --- |
| `24` 视频监控 | 按监控任务时长计算：30 天占用 `0.5`，60 天占用 `1`，120 天占用 `2`；INS 每日新增任务数是另一套独立限制。 |
| `17` 子账号席位 | 限制团队可启用的子账号数量。已加入的子账号和仍有效的待接受邀请共同占用席位；没有“无限子账号席位”语义。 |
| `56` 自动追踪网红席位 | 按正在运行的自动追踪网红占用席位，不是一次性扣减。暂停规则会释放其网红席位；恢复时需重新满足席位、监控额度和运行规则数限制。 |
| `65` 自动追踪天数 | 定义自动追踪规则的运行时长，不作为独立可消耗次数。 |
| `71` AI 商品分析 | 按团队已创建过的商品分析记录占用分析席位。同一商品已有有效分析时直接复用；删除分析不会释放席位，重新启用同一商品也不新增占用。 |
| `76` 物流追踪 | 按会员月度周期内创建的物流运单数统计。删除追踪记录不返还当期额度；重复运单不会形成新的独立追踪对象。 |
| `78` TikTok Shop 商品、店铺和直播详情 | 三类受 Scope 控制的详情分析共用团队额度。首次进入某个详情分析时，按“详情类型 + 详情 ID”解锁 1 次；同一团队后续访问相同类型和 ID 不重复占用。相同 ID 在不同详情类型下分别计算。解锁记录跨周期持续复用，当期用量只统计本周期首次解锁的详情数；子账号同时受团队总剩余和个人分配上限约束。 |
| `31` 资源池数量、`32` 资源池内创作者数量 | 分别限制可保有的资源池数量和单个资源池可容纳的创作者数，属于容量限制。 |

### 邀约、发件与 Campaign

| Scope | 产品口径 |
| --- | --- |
| `6` 邮件邀约对象 | 限制推广任务可加入的、具备邮箱的受邀创作者总量。新增收件人时按任务中已有收件人和本次可用邮箱的受邀对象预校验，属于任务容量而不是实际发信次数。 |
| `7` 推广任务推荐创作者 | 限制一次推广任务推荐结果最多返回多少创作者，是结果数量上限，不按查看或收藏逐条扣减。 |
| `21` 邮件发送 | 按实际进入发送的有效收件人计数；暂停后恢复发送不重复占用，退信会返还对应发送额度。日发送上限按实际发件账号独立统计，团队报表仍可汇总查看。 |
| `38` 自有 Gmail/企业邮箱群发 | 控制邮件项目能否使用当前操作账号自己绑定的 Gmail 或企业邮箱作为群发发件人；不具备该能力时，项目改用平台账号池，而不是扣减一次发件额度。 |

| `85` Campaign 每日发送上限 | 限制智能营销计划的每日实际发送数。上限从主账号权益读取，但按实际操作账号统计；命中后会暂停当前 Campaign 的队列、任务和收件人，恢复前不能继续发送。 |
| `79` TikTok Shop 插件邀约、`80` TikTok Shop 插件私信 | 两类插件动作分别按团队当日成功提交的记录数限制。每次提交新增一条动作记录即计入当日总量；可选“跳过天数”只阻止对同一达人过快重复操作，不会把不同提交合并为一次。 |

### 频率限制和纯功能门禁

| Scope | 产品口径 |
| --- | --- |
| `63` AI 聊天频率 | 限制单个操作账号近 1 分钟内的 AI 请求数，不是可累计的消耗余额。 |
| `25` 视频监控评论情感分析、`33` 视频监控报告 | 分别控制监控任务的评论情感分析和各类监控报告导出资格，不按报告份数扣减。 |
| `55` Shopify 联盟营销 | 控制 Shopify 店铺注册入口，是联盟营销功能门禁，不计次。 |
| `67` 会员资格、`70` TikTok Shop 高级搜索、`88` TikTok Shop 店铺授权和私信项目 | 主要用于功能访问门禁。`67` 用于 AI 扩展词等通用会员能力；`88` 仅控制店铺授权、解绑和私信项目操作，查看店铺绑定列表不校验该 Scope。 |

## 关键分叉与边界

- Scope 的名称、套餐展示项和实际用量规则并非一一对应。新增或调整 Scope 时，应先明确它属于“按结果消耗、资源席位或容量、一次解锁、频率限制、功能门禁”中的哪一类，再定义团队与子账号统计范围、去重对象、周期、返还条件和项目协作边界。
- 本页只汇总跨模块的稳定额度规则；模块内的对象归属、协作人、可见范围和状态流转，以对应业务域正文为准。
