# Design v1 · 智能精选（v6.3.10）

> 交互设计 · 上游规格：`spec_v1.md`  
> 状态：v1，可进入真实页面 demo。  
> 原则：按真实产品页面表达，不做状态机说明器或视觉方案工作台。

---

## 1. 页面定位

智能精选是标准搜索结果后的工作台。

它不与标准搜索平级表达，不在页面上制造“标准搜索 / AI 搜索”两种搜索模式并列的心智。

推荐页面关系：

```text
频道搜索结果页
  -> 智能精选工作台
```

进入智能精选后，用户的注意力应集中在：

- 这份输入快照来自哪里。
- 当前策略在筛什么。
- 当前轮次结果是否值得采纳。
- 接下来是继续筛，还是重新筛。

## 2. 标准搜索结果页入口

### 2.1 入口位置

入口放在标准搜索结果页的结果工具区。

它应靠近结果数量、排序、筛选摘要，而不是放在搜索框内部。

推荐文案：

- `对当前结果做智能精选`

次级说明可表达：

- `基于当前结果快照创建精选工作台`

### 2.2 点击反馈

点击后进入轻量创建态：

- 展示正在生成输入快照。
- 保留当前结果页背景。
- 创建完成后进入智能精选工作台。

Demo 第一版可用 mock 触发完成。

## 3. 智能精选工作台布局

### 3.1 页面骨架

沿用 NoxInfluencer 后台式布局：

- 左侧主导航。
- 顶部 bar。
- 左侧可收起 session 列表。
- 右侧主工作区。

主工作区结构：

1. 输入快照卡。
2. 精选策略输入区。
3. 当前轮次结果工具条。
4. 结果列表。

### 3.2 输入快照卡

位置：主工作区顶部。

内容：

- 来源：标准搜索结果。
- 候选数。
- 平台。
- 快照生成时间。
- 来源条件摘要。
- `查看来源条件`。
- `返回标准搜索结果`。

样式：

- 不做大宣传卡。
- 信息密度接近业务工具。
- 可以用浅底色强调“输入对象已冻结”。

### 3.3 Session 列表

位置：工作台左侧。

默认展开，但必须支持收起。

条目展示：

- session 标题。
- 来源快照规模。
- 当前轮次。
- 已采纳 / 已排除数量。
- 最近活动时间。

操作：

- 新建 session。
- 切换 session。
- 改名。
- 归档。
- 恢复。

## 4. 精选策略输入区

### 4.1 默认态：继续筛

默认状态表达：

- `基于：当前列表`
- 输入框 placeholder：`继续描述你想优先保留或排除的频道`
- 主按钮：`继续筛`

辅助提示：

- `下一条策略将继续收窄当前结果`

### 4.2 系统理解摘要

策略执行后，在输入区下方展示轻量摘要。

建议结构：

- `优先`：2-3 个短项。
- `排除`：1-3 个短项。
- `重点研究`：1-2 个短项。

默认不提供逐条编辑。

### 4.3 重新筛态

入口放在当前轮次结果头部右侧。

入口文案：

- `重新筛本轮`

点击后：

- 输入区切换到重新筛态。
- 基底自动切到 `本轮基底`。
- 顶部提示条显示：`重新筛将基于本轮基底重新生成，不沿用当前结果继续收窄`。
- 主按钮变为：`重新生成这一轮`。
- 提供退出动作：`返回继续筛`。

## 5. 基底选择器

位置：策略输入区内，放在输入框上方。

默认显示：

- `基于：当前列表（第 N 轮，X 个频道）`

点击后打开轻量浮层。

第一版选项：

- 当前列表。
- 原始快照。
- 最近 3 轮结果。

每个选项展示：

- 列表身份。
- 候选数量。
- 一行策略摘要或来源说明。

固定提示：

- `切换基底只影响下一条策略，不会立即改变当前结果。`

## 6. 当前轮次结果

### 6.1 结果头部

结果头部展示：

- 当前轮次名称。
- 基于哪份列表生成。
- 结果数量。
- 相对本轮基底减少数量。
- 相对原始快照保留比例。
- `重新筛本轮`。

### 6.2 结果列表

列表保持频道搜索结果的业务感。

每行包含：

- 频道头像、名称、handle。
- 平台、地区、粉丝、平均观看、互动率。
- 最近内容摘要。
- 系统判断说明。
- `采纳`。
- `排除`。

采纳 / 排除后：

- 进入当前 session 的对应集合。
- 不直接加入收藏或营销计划。

### 6.3 已采纳 / 已排除摘要

摘要可放在结果工具条或右侧轻量区域。

默认显示数量。

支持展开查看集合。

第一版不做复杂改判流程；如保留改判，只作为轻量菜单，不影响主路径。

## 7. Demo 第一版页面

真实页面 demo 至少包含：

1. `search-results.html`：标准搜索结果页。
2. `curation-workbench.html`：智能精选工作台。
3. `curation-rescreen.html`：重新筛态，或在同页通过前端状态切换实现。

交互最小闭环：

- 从标准搜索结果页点击 `对当前结果做智能精选`。
- 进入快照创建中。
- 进入智能精选工作台。
- 输入策略并点击 `继续筛`。
- 结果区更新为下一轮。
- 点击 `重新筛本轮`。
- 进入重新筛态。
- 返回继续筛。

## 8. 待 Demo 后回看

- `重新筛本轮` 的入口是否过弱或过强。
- 基底选择器是否让用户误解为切换当前结果。
- 输入快照卡是否占据过多首屏空间。
- 已采纳 / 已排除是否需要更强可见性。
- 分页 / 增量展示是否需要在第一版出现。
