# 搜索体验 v6.3.10

> `current_release`: `v6.3.10`
> `depends_on`: `v6.3.9`
> 文档流：`input -> spec -> design -> demo -> prd`

## 版本定位

`v6.3.10` 聚焦 `智能精选`。

本版本只涉及独立的频道搜索页，不改造 `智能营销计划` 中的频道搜索模块。`智能营销计划` 内的频道搜索入口、候选池和上下游项目状态，计划在下个版本 `v6.3.11` 中单独适配。

本版本不再把智能精选定义为“另一个 AI 搜索助手”，而是定义为：

> 对当前标准搜索结果做进一步精选，帮助用户从已有候选频道中收敛出更可信、更适合后续消费的 shortlist。

换句话说：

- 经典搜索负责产出候选频道列表。
- 智能精选负责在这份列表上继续精筛。
- 精选策略抽屉只整理 Agent 如何筛当前结果，不修改搜索条件。
- Agent 精选页承接长时间生成、批次进度、结果处理和后续精选动作。

## 当前主线

v6.3.10 的搜索体验主线分为五段：

1. **经典态搜索及结果**：通过标准搜索条件和 raw 数据匹配召回结果集。该页面应尽量保持线上经典频道搜索心智，不因智能精选而明显变形。
2. **自然语言搜索入口**：仍从同一个经典搜索框内部切换进入，主搜索框按钮保持线上搜索心智，先展示经典搜索结果，不直接打开智能精选。
3. **结果区智能精选入口**：关键词模式和自然语言模式共用结果列表右上方的 `对当前结果做智能精选`。
4. **精选策略抽屉**：只整理精选策略说明、策略项和输出设置；候选频道来自外部搜索结果，若要改变候选范围必须回到搜索页调整。
5. **Agent 精选实体页**：展示当前精选任务、批次进度、精选结果、结果后动作，以及 `重新精选 / 继续精选`。

当前 Demo 已覆盖以上主线。后续 PRD 阶段再收口真实接口、异常恢复和证据详情。

## 版本边界

本期包含：

- 经典态搜索结果页的智能精选桥接入口。
- 同一经典搜索框内的自然语言输入形态。
- 精选策略抽屉：精选策略说明、策略项、输出设置。
- Agent 精选结果页：任务摘要、批次进度、精选结果、保存至收藏夹、进入邀约、导出结果。
- 当前 session 内的追加目标、移出后补齐、继续精选。
- 基于原搜索结果快照创建新 session 的重新精选。
- 短期精选任务列表和删除规则。

本期不包含：

- 从 0 开始的全库 AI 搜索入口。
- 其它列表入口到智能精选的桥接。
- `智能营销计划` 中的频道搜索模块、营销计划候选池和项目上下游状态适配；该部分计划进入 `v6.3.11`。
- 完整策略编辑器。
- 证据详情页。
- 后端异步任务、失败恢复和日志规则。
- 跨页面长期持久化或营销计划上下游状态。
- 树状历史或全量轮次 lineage 图。
- 重型 diff 对照视图。
- PRD 阶段才应收口的后端接口字段细节。

## Demo 方向

Demo 采用真实产品页面形态，而不是场景说明工作台。参考 `v7.6.1` 内容监控 demo 的方式：

- 以真实业务页面承载交互。
- 使用接近线上产品的导航、列表、筛选、抽屉和工作台布局。
- 不再把“状态解释”作为页面主体。

当前阶段 Demo 优先覆盖：

- 标准搜索结果页。
- 同一个经典搜索框内的 `关键词 / 自然语言` 输入形态切换。
- 结果列表右上方的 `对当前结果做智能精选`。
- 精选策略抽屉。
- Agent 精选结果页。
- 批次生成、停止生成、追加目标、移出后补齐。
- 保存至收藏夹、进入邀约、导出结果。
- 重新精选和当前 session 内继续精选。

暂不定稿：

- 证据详情页。
- 真实后端任务恢复、失败、过期和服务端日志。
- 与收藏夹、邀约、导出中心的真实数据联动。
