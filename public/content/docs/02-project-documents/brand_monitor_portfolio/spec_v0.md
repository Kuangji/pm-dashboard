## 营销资产库的两种取数方式

下钻范围与来源说明一并生成、恢复。普通浏览（含带筛选新开库）隐藏下钻说明；同库的列名、列序、含义与浏览入口一致，有效空结果也展示表头。[资产库一期修改点](营销资产库一期修改点.md)

报告及覆盖诊断的所有作品、账号名单均直接在新标签页打开对应资产库。来源报告保留当次筛选和定位。点击有效的名单入口时只打开一个新页；来源批次或权限校验失败时提示原因，不能扩大名单。

| 入口 | 内容库 | 网红库 |
|---|---|---|
| 子视图归属多选 | 同批、同日期、同平台内，取命中任一所选视图的作品并按平台作品键去重。无选择时可见主池中未归属的作品 | 按相同条件取作品并集，再按平台账号去重，统计每个账号在该范围的发文数。常规参与名单按原指标要求匹配频道资料 |
| 图表传入精确名单 | 接收平台与作品 ID 数组。共同作品、分类、Top 5 等沿用来源集合，Top 5 保留同批排名 | 接收平台与账号 ID 数组。共同达人另带在两侧的发文数；多次发布名单保留达到阈值但缺频道资料的账号 |

归属候选取本客户在该主品牌可读、有同批结果的有效子视图，独立于报表勾选的 0–5 个成员。空归属选择表示当前入口可访问范围内的全部，显式空 ID 数组表示 0。主报告入口的基础范围为同批主池；子报告自身的营销资产以该子视图同批作品为上限。两项同时给出即取交集。对精确账号名单再筛子视图，以该账号在期间内是否为该视图发过文判归属，双方次数和排名保留来源口径。跨平台同字符串 ID 分属不同实体。详见[名单传递及验收](营销资产库下钻接入调研.md#一期接入范围)。

生产列表、计数、分页及启用的导出须执行相同的权限和范围约束。由服务端校验当前客户、主品牌、子视图、实体类型及快照，跨池、跨客户或来源失效时提示对应状态。下钻范围的传递方式留待技术评审。[待讨论问题](营销资产库下钻接入调研.md#资产库下钻范围如何传递)

## Q01、Q02 子视图定义、查询与预览

一期由有创建权限的用户人工选择主品牌配置、补充池内条件，预览后保存为本客户的私有子视图。主报告对比使用本客户已配置的同批子视图快照。

Anker 场景演示人工选取主配置和补充池内条件。主品牌 ID 为 17220。候选值引用只读核对的 MIS 配置，视频、外链分布和账号身份映射使用演示数据。[查询方案](query_scheme_review_v1.md)

每份子视图保存名称、可选的自定义视图标签、所属主品牌池、适用平台、纳入与排除条件以及条件版本。主池由创建入口确定，名称在同一主池内唯一。报告临时筛选与所保存的平台和查询条件独立。

名称和视图标签用于识别子品牌、主题或活动等用途。查询中的内容标签用于匹配内容。子视图的对比资格取决于归属、启用状态和同批快照状态。只改名称和视图标签时，保存后直接更新展示。与查询一并修改时，名称、标签及规则随新快照发布；生成中或失败时继续显示已生效版本。现有 Demo 样例可通过视图标签承接既有用途。真实历史数据如何处理需在生产接入时核验。

| 规则 | 建议口径 |
|---|---|
| 平台和字段 | 选择主池覆盖的平台。Demo 使用 YouTube 标题、Instagram 和 TikTok 说明、平台内容标签及发布账号。生产按平台核验可用字段后开放。 |
| 纳入 | 至少一项。内容文本按短语匹配、忽略大小写和首尾空白。标签按规范化后的完整标签匹配。发布账号从品牌已配置的社媒账号中选择，底层按平台与稳定账号 ID 精确匹配发布者。新建手填条件支持内容文本、内容标签。历史手填账号条件按原平台和 ID 回读，可保留或移除。同一包含组内的纳入条件任一命中即可。 |
| 排除 | 支持文本短语及完整标签；任一排除命中即移除。先限定主池和保存的平台，再判断纳入，最后应用排除。 |
| 条件适用性 | 平台专用条件只在对应平台判断。岩途样例要求每个所选平台至少有一项适用的纳入条件。Anker 样例允许只选某个平台的主配置，该条件只匹配对应平台。单条内容字段为空时，该条件在该条内容上未命中；所选平台缺失整项已配置字段时给出不可执行状态，修正后再生成。 |

### Q02 Anker 人工查询

- **候选。** 从关键词标签、品牌子网站、第三方服务商和品牌其他链接中选择具体值。标签按完整值匹配。社媒发布账号按对应平台和账号身份匹配。网站、店铺及其他外链按视频样本携带的外链匹配，比较主机和路径边界。
- **主配置的选择。** 所有包含组均可独立选择或调整上述四类主配置，支持仅由主配置构成的组。选择器绑定打开它的组，已选项、批量选择和应用仅作用于本组。排除区仅支持文本、标签。搜索和类别筛选只影响候选列表。批量选择固定本次搜索命中的具体配置 ID，之后新增的同名或近似项须重新选择。跨页选择按配置 ID 保留，应用时一次提交。取消或应用相同集合时，原先的预览继续有效。
- **包含组数。** 每个子视图最多 5 个包含组，首组及每个附加包含组各计 1 个。组内条件和独立排除区均不占额外组数。历史定义和已发布快照完整保留；若旧规则回显后超过上限，用户须将包含组调整至 5 个以内再保存。
- **条件关系。** 在指定平台的同批主池内，每个包含组至少选一项主配置或填写一条池内条件。每个包含组内固定用 OR，命中任一项即满足本组。各包含组之间固定用 AND，同一条内容须满足所有组。排除区统一移除命中任一排除条件的内容。同一条内容命中多条线索只计一次，按各组列出实际命中的字段和值。组关系由系统固定。快照保存每条条件所属组，重开时按原分组显示。读取旧版规则时，原先必须同时满足的每条限定各自还原为独立的单项组，保留原规则的命中范围。
- **命中原因。** 样本应能指出主配置或用户补充项及对应的视频字段。这里解释的是子视图匹配结果。逐视频原始入池凭据仍待生产核验。
- **批次。** 预览与按该预览保存的子视图共享来源主池批次。发布子视图时可产生新的发布版本；报告按保存时使用的主池及规则取得结果。完整命中为零时也可生成快照。

编辑时由组标题、组间连接词和条件行共同表达完整规则。用户主动请求预览后，允许等待计算完成。只有结果对应当前规则和主池批次且计算完整时，才展示命中总数或据此保存同批快照。等待、失败及已失效的结果均不能按零命中处理。线上预览耗时待研发验证，逐步增减量不列入一期要求。

以下通用约束适用于两个样例。预览和生成共用匹配逻辑。预览提供统计日期、平台、数据截至、命中总数和可核对的样本，显示样本命中的条件。Anker 的有效预览绑定主池批次。规则或来源批次变化时重新预览再提交。完整结果为零时仍可保存。池外内容无法被子视图收录；独立报告、标题文字或账号关系均不能补写主池。

Anker 初始主池 `anker-17220-pool-1` 有 12 条样例视频。在默认初始场景创建首个子视图，发布版本从 `pub-1` 切换为 `pub-2`，两者共享原主池批次。统一刷新取到新样本时才切换主池批次。

## S01 快照与发布

| 数据或动作 | 建议口径 |
|---|---|
| 取数与冻结 | 每次记录主池身份及数据版本、统计时区、起止时间、平台、数据截至、批次内视图及其已采用规则版本、去重后内容身份、指标值，或可重现命中集合及指标的不可变版本。以平台和原始内容 ID 作为内容去重键。 |
| 对比窗口与子报覆盖 | 按快照覆盖选择完整自然月或滚动 7／30 天，报告显示绝对日期和观看数据截至。子报与明细继承所选范围，自身固定窗口模块另按其定义取数。 |
| 生成 | 首次保存、修改查询、主池新批次发布及手动统一刷新触发计算。Demo 将同池已启用子视图的成功规则随统一刷新重新生成。完整数据及必要成员的分项就绪后可发布新的数据批次。 |
| 发布 | 每个主池有一份当前已发布数据批次。新增或编辑能够使用当前数据版本时，可基于该版本发布新结果。切换数据版本时，独立子视图可分别发布。对比须等同批主池基准和全部已配置成员就绪后整体切换。迟到、被替代或已停用视图的任务不得覆盖现行结果。 |
| 读取 | 独立进入子报读取最近一次成功快照。对比下钻绑定当时的发布版本、日期和平台，共享筛选模块继承该范围，固定窗口按各自定义读取。超出快照覆盖范围，需要新生成。成功覆盖后只保留当前结果。已被覆盖的下钻链接提示「结果已更新」，并提供有权限的当前入口。 |

Anker 人工创建路径在确认「保存同批快照」时自动完成本地模拟生成。岩途场景供单独评审任务状态。首次成功前呈现进度或失败状态。已有成功结果时，刷新或编辑失败均保留原结果、已采用规则及过去的统计口径。Demo 用手动任务成功或失败模拟这些状态，生产的调度策略、保存期限及最大查询窗口待确认。

## R01 主报告与总分计算

[打开月报版子视图对比](../../../demos/brand-monitor-portfolio-754/index.html#comparison)。v0.20 使用同一主品牌池中的私有子视图作月报分析。默认示例读取岩途 2026 年 10 月发布的视频；观看值统一取该快照的数据截至时点。可切换完整自然月或最近 7／30 天。

[月报指标及适用场景](comparison_charts_review_v0.md#月报视角下的一期取舍)规定本轮月报内容。对比 TAB 查看表现、渠道差异和两个可见子视图的重合度，管理抽屉检查全部已配置成员的覆盖、共同命中与未覆盖集合。

标准主品牌报告保持原取数与更新方式。对比设置集中在「子视图管理」抽屉。报告对比区展示同批基准和分项指标，绝对日期、平台、数据截至时间和批次通过标题旁的提示查看。各行共用该范围内的主池基准。视图保存的平台限制自身命中集合，分项说明该限制并可逐条下钻。

「观看量占主品牌比重」将每个子视图的观看量占比和视频数占比并列。前者回答这个视图获得了主品牌多少观看，后者用于判断这种表现对应多少内容。两项均使用同批、同日期、同平台的主品牌总量作为各自分母。两条横条均使用 0–100% 刻度。先按观看量占比降序展示，无法计算的行排在有效值之后。子视图命中可重叠，各行独立计算；临时隐藏或移除其他成员时，该行的分母仍取主品牌。分母为零、观看值缺失及未收录所选平台时分别给出原因；视频数完整时仍可显示视频数占比。

| 对比操作 | 建议口径 |
|---|---|
| 历史选择超额 | 若旧配置包含超过 5 个成员，完整保留原选择，报告提示需要调整；管理者在列表撤选至 5 个以内并保存后恢复对比。 |
| 配置对比 | 由管理者在子视图管理主列表勾选已启用且有成功同批快照的子视图。每客户每主品牌保存 0–5 个不同成员 ID，主品牌基准单列。新增子视图首次成功生成后成为候选，由用户勾选加入。保存时复核数量、资格和权限，再整体替换原选择；取消或关闭抽屉沿用原配置。Demo 会话内延续选择。数据批次独立于成员配置，另存聚合报告留待后续。 |
| 日期与平台 | 用户在「对比设置」中临时调整本人查看范围，只筛选当前批次中的数据。 |
| 显示分项 | 用户在「对比设置」中临时隐藏已配置的表行及趋势系列。覆盖率仍用同批主池基准，未覆盖数继续按已配置成员计算。 |
| 统一刷新 | 具有管理权限的用户在「对比设置」中发起，任务及结果状态均在抽屉内呈现。 |
| 对比区显隐 | 主品牌有效监控读取者可进入 TAB。未选择成员时显示空状态，管理者从子视图管理配置。 |

| 指标 | 计算 |
|---|---|
| 提及视频数 | 主品牌从主池按本批次的筛选条件读取，按内容身份去重计数。每个对比成员在同批筛选范围用自己的命中集合去重计数。主池包含所有已收录内容。 |
| 观看量 | 在各自去重后的视频集合内汇总统一截至时点的观看量。完整观看值可汇总。缺失时相应总量和覆盖率为不可计算。主池和对比成员使用同一口径。 |
| 分项覆盖率 | 子视图该指标值 ÷ 同批同日期、平台范围内的主池该指标值。值不可用或分母为 0 时，覆盖率为不可计算。完整分子为 0 且分母大于 0 时显示 0%。 |
| 单条观看中位数 | 取同批、同窗口及所选平台的去重视频观看值，按数值排序；偶数取中间两项均值。标明样本量，空集合与字段缺失分别解释。 |
| 平台构成 | 各互斥平台上的视频数 ÷ 当前视图视频数，按组内比例呈现；每段可查看对应视频。在单平台范围内收起此图。 |
| 观看量前五条 | 按截至观看值从高到低排序，展示前五条及其占该视图总观看量的比例。小样本展示实际作品，缺失值或零分母不计算贡献率。 |
| 未覆盖内容数 | 按本批次及当前筛选获取主池视频集合，减去已配置子视图命中集合的去重并集后计数。已配置成员的同批内容集合完整时可计算。 |

同一视频在各命中的分项各计一次，在主品牌总量和对比成员命中并集中各计一次。分项覆盖率相加可能超过 100%。最近 30 天的样例为同批主池 100 条，默认成员的命中分别为 60 和 55 条，重叠 25 条，未覆盖 10 条。加入「新品体验内容」后未覆盖 8 条，分母仍为 100。标准主报可以展示更新的数据。

所选单一平台不在子视图的收录范围时，该分项不适用，并提示「未收录所选平台」。平台在收录范围、同批数据完整且实际无命中时，显示 0。

### 三组月报对比指标

表中每个成员以及主品牌基准，分别从自己的冻结记录中取当前日期、平台范围内的去重内容。计数键为平台与原始内容 ID；达人键为平台与发布账号 ID。同一内容、达人可分别计入命中的不同视图。所有下钻均校验主品牌监控读取权并沿用原快照。

| 指标 | 计算与解释 |
|---|---|
| 参与网红数 | 统计当前范围内可匹配频道资料的去重发布账号。各平台分别识别账号。 |
| 多次发布达人占比 | 分子为在本范围、本视图发布至少两条不同命中内容的账号数；分母为在此发布过命中内容的全部可识别账号数，包含有账号 ID 但未匹配频道资料的账号。按当期发文计算。列表列出账号和发文数。 |
| 总互动量 | 每条内容按平台取赞、评论，TikTok 另含分享、收藏。在视图内按去重内容汇总。Instagram 的图文也可贡献总互动，互动率另取视频子集。 |
| 同平台互动率 | 在同批同平台的合资格内容上先汇总，再计算总互动 ÷ 总观看。YouTube 使用赞和评论，Instagram 仅用视频贴的赞、评论及对应观看，TikTok 使用赞、评论、分享和收藏。分子、分母来自同一组内容；分母为零时显示不可计算。 |
| 推广类型构成 | 按内容与该主品牌的推广关系，为每条去重内容取一个分类。付费推广、疑似付费推广、自然传播、未识别四类的条数之和等于该行内容数。每类单独除以本行内容数；空行显示实际样本数。对同一条视频，主品牌分类随同批快照进入命中的子视图。 |

当前名额、临时隐藏和权限规则沿用 R01。同平台互动率先在既定样本中检查互动字段、形式和观看是否齐全，再汇总计算；显示有效样本数与应计样本数。样本不全或观看分母为零时用「—」及原因。某平台字段缺失只影响依赖它的指标。推广识别用于描述内容，商业合同、实际付款及续约结论需另外取证。

### 满载样例的对账口径

同批主池明细按平台和内容 ID 去重。子视图取该明细集合中命中自身规则的记录，每个视图只计同一条内容一次。发布日期确定月报及周桶归属，观看、互动字段取同一快照截至值。每行三个平台的内容数之和、四类推广条数之和、所选期间各发布日或周的条数之和，都应等于该行内容数。

报告和网红库复用同批发布账号的身份与频道资料匹配结果。标准主品牌概览展示最近 30 天的较新采集，页首标明实际日期和截至；从月报进入子报告时沿用月报批次和范围。

管理侧将已选成员的命中集合先取并集再计算覆盖。已覆盖与未覆盖的条数之和等于同批主品牌内容数。共同命中两个及以上成员的内容已经包含在并集中。替换对比成员可以改变覆盖数；平台和日期相同时，主品牌基准与其他保留成员的分母和明细保持一致。

### R07 两个子视图的重合度

计算采用两份子视图的同批快照、同一日期和平台筛选。展示对象为当前可见的已选子视图，主品牌基准另列于指标表。矩阵两轴沿用指标表的子视图顺序。5 个可见成员得到 5 × 5 的矩阵，20 个非对角格对应 10 对唯一组合。A × B 与 B × A 共用一份计算结果，点击任一格均可检查该对。对角格只标识自身。切换维度、日期或平台时沿用仍可见的已选组合，其中一侧退出可见范围时清除选择。

| 项目 | 口径 |
|---|---|
| 内容集合 | 按平台与原始内容 ID 去重。同一作品命中 A、B 才进入共同内容。 |
| 参与网红集合 | 与指标表「参与网红数」一致，取视图当期命中作品中匹配到频道资料的去重平台账号。同一账号至少在两侧各发过一条命中作品，即可进入共同达人；两侧的作品可以不同。共同达人明细列每个账号在 A、B 的发文数。 |
| 两组相似程度 | 共同数 ÷ 两组去重合计，即交集 ÷ 并集。共同数相同时，两个规模较小的集合可以有更高重合度。 |
| 两侧分别有多少被涵盖 | 分别计算共同数 ÷ A 总数、共同数 ÷ B 总数。仅 A = A 总数 − 共同数，仅 B 同理；“仅”相对当前这一对判断，仍可能命中第三个子视图。 |
| 边界 | 两侧都适用且并集非空、交集为空时，重合度为 0%；并集为空时不可计算。单侧为空时，该侧占比不可计算。所选平台不在一方收录范围时，该组合标注不适用。账号身份或资料匹配状态不足以确定集合时，达人重合度标为不可计算。 |

同一条视频若命中三个视图，会同时出现在三对的交集中。整组「至少命中两个」的视频数按主池身份去重，不能直接使用配对交集求和。隐藏成员只影响报告中的可见组合，其他两两指标、已保存成员和管理诊断沿用原口径。所有明细复核读取权限、成员有效性、当前查询范围与批次。

## R02 子报告与模块依赖

子视图报告提供所属主品牌、已发布的视图名称和标签、采用的规则版本、快照范围及数据截至。在可计算范围内承接标准指标和明细。建议一期在主报告对比中呈现覆盖率，子视图报告沿用标准指标。新增专有指标待评审。

| 标准板块 | 一期候选基线 | 待证实或待补依赖 |
|---|---|---|
| 品牌概览 | 提及视频数、观看量及内容明细。 | 相关网红、互动统计所需的频道和互动字段。推广占比与花费依赖推广关系和估价。AI、竞品矩阵需要按子视图收录内容重建输入。 |
| 营销策略 | 已具备数据的发布频率、时段、语言和标签分布。 | 网红画像、受众重合和商品策略需要频道、受众、竞品及商品关系。 |
| 市场动态 | 按当期快照覆盖提供发布变化、标签趋势与榜单。 | 新合作达人需要长期合作历史，累计观看增量依赖历史指标版本。 |
| 营销资产 | 内容明细、具备稳定身份的频道、内容标签。 | 频道属性和商品库需要能追溯到子视图收录内容的关系。 |

Demo 用同一快照演示四个板块中可计算的内容及依赖缺失状态。待确认各标准模块本期承担的范围。运行时缺数据的模块要说明缺失依据，已确定为发布必需的模块须先补齐数据再验收。

## R03 发布趋势与同批内容下钻

主品牌报告的「子视图对比」TAB 直接展示同批发布内容数趋势。

| 项目 | 趋势评审规则 |
|---|---|
| 展示与取数 | 在独立 TAB 默认按周，支持按日；按每个日期桶的实际起止下钻发布视频。主品牌参考线与所有可见成员使用同一窗口和平台。 |
| 内容计数 | 主品牌从该批主池取数，子视图从同批各自命中集合取数，按发布时间归入主品牌统计时区的日期桶，各自按平台与原始内容 ID 去重。各系列使用相同时间桶。有效零显示为 0，视图未收录所选平台时提示原因，无可下钻点。 |
| 日期桶 | 日桶按统计时区的自然日，周桶从周一开始。实际桶范围与当前日期窗取交集，首尾不满一周时只计算窗内日期。 |
| 下钻 | 点击有效数据点在新标签页打开内容库。按该视图、批次、平台和日期桶的实际起止展示作品，初始列表总数等于所点发布数。原报告保留日期、平台和图表粒度。 |

## L01 入口、权限及生命周期

一期由客户同时满足「有效付费权益、该主品牌已开通且仍有效的品牌监控（45）」并具有该品牌管理权限的成员创建和维护私有子视图。新建、预览自定义查询、修改名称或条件、保存、启停、重算及批量修复均按此规则校验；变更对比成员和统一刷新沿用相同写入资格。读取已发布子报告、对比及同批明细沿用有效监控和本客户读取权。仅解锁 47／49、试用选中品牌或限免示例的读取放行，均不单独授予写入资格。提交与异步发布前复核资格，失效后保留已有定义和快照，阻止本次写入。生产接入需核实正式付费权益来源，不能直接复用含试用放行的监控读权限返回值。

**批量修复。** 仅当前主品牌的管理者可执行。以子视图为单位采用同一个配置 ID 的当前匹配值，或移除已删除的引用。每个原包含组仍有条件且整份候选规则校验通过时，可用当前主池批次计算并发布；成功后清除该视图提示。任一原包含组会变空、校验失败或已有未完成编辑时，保留该视图的完整生效规则和快照，交由管理者处理。重复执行只检查仍受影响的视图。

从主品牌报告全局「子视图管理」入口打开抽屉，并在其中创建、编辑、重试、停用或启用。关闭抽屉后回到当前报告标签和所选查看范围。抽屉呈现子视图任务和统一刷新状态。从管理层或直接入口可打开最近成功的快照，从报告对比可下钻同批结果。创建与维护适用下述付费监控管理资格。只读用户可以查看已发布结果，并在「对比设置」中调整本人临时日期、平台和显示分项。保存成员和统一刷新须有管理权限。每次读取和写入时校验当前权限及视图状态，包括旧快照和直接链接。

| 状态 | 建议行为 |
|---|---|
| 首次生成中／首次失败 | 显示状态和任务；成功后开放报告。任务执行期间可按原参数技术重试。最终失败后显示原因，用户可重新提交。 |
| 可用／真实零条 | 读取成功发布的结果。确认范围完整且查询成功才显示真实零条。 |
| 更新中／更新失败 | 持续读取旧快照及其规则，明确待更新或失败的是哪个版本。新批完成并通过发布检查后切换。同次任务可技术重试。未生效查询最终失败后不另存，再次打开编辑器读取当前生效规则。 |
| 停用／重新启用 | 停用即时限制报告、明细和旧链接，并从对比成员及候选移除。用剩余已配置成员重新计算未覆盖数。重新启用并成功发布后可再次选择该子视图。 |
| 主品牌访问撤销 | 即时拒绝对比、子报、下钻及旧链接；权限结果和真实零条分别返回。 |

## F01 Demo 回流与生产核验

每条评审反馈记录编号、步骤、实际结果、期望结果、决策及待验证项。将规则写回 Spec，将行为写回 Design，将范围变更写回 Input，并在同轮更新 Demo 与对应场景验收依据。原始差异和未确认事项留在 [Sync Inbox](../../03-research/2026-11-13-brand-monitor-hierarchy/_sync_inbox.md)。[评审入口](README.md)

| Demo 验收路径 | 结果 |
|---|---|
| Q02 Anker 同批保存 | 以标签 `anker solix` 单独命中的 3 条为起点，在同组添加短语 `C1000` 为 5 条，从同一起点另建限定组填该短语为 1 条。直达示例首组为标签或型号，第二组为「户外」或「收纳」，预览 2 条。移除「收纳」后为 1 条。子报告与预览共享同批、同规则的内容集合。 |
| Q01 预览并保存子视图，编辑名称、视图标签或查询条件 | 样本可解释，零命中与不可执行可区分。视图标签随成功发布生效，新发布的子视图可选作对比成员。 |
| S01 编辑后模拟失败，再重试发布并查看旧批次 | 失败时旧结果可下钻，成功后同批对比整体切换。 |
| R01 在抽屉配置成员和临时显示，返回报告核对指标 | 对比区展示范围、指标及明细入口。基准和分母保持同批。未覆盖数随成员配置变化，临时隐藏只影响展示。零分母或观看量缺失时，相关覆盖率不可计算。 |
| R02 打开子报四板块和明细 | 已计算数字与所读快照一致，依赖缺失单列状态。 |
| R03 在对比 TAB 切换日、周趋势并从点位查看内容 | 同批主品牌和子视图共用日期桶与平台，首尾周裁至当前窗。点位内容数与新标签页初始列表总数一致，原图保持所选粒度。未收录平台与真实零分别呈现。 |
| L01 从不同标签开关抽屉，停用、启用，切换只读或撤销权限 | 报告位置和筛选可恢复。权限和状态按当前有效条件判断，旧链接遵守同一读取规则。 |

生产核验优先确认主池服务端是否能取得完整内容集合、主品牌与子视图是否能重现同批数据及指标、各平台字段是否可用、观看值与标准报告字段是否一致，以及配置权限与报表读取行为。已有静态核对发现内容列表的 10,000 条上限及某些鉴权失败返回空结果。需用真实主池和权限验证全量读取、截断及失败分类。正式范围还需确认各模块必交项、真实刷新、对比配置持久化与批次保留策略。[一期建议与证据出处](子品牌视图一期建议方案_v1.md)
