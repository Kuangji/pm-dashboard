# v7.5.4 子视图对比盘点与展示规则 · 评审稿 v0

2026-11-23。承接 [Input v2](input_v2.md)、[评审版 Spec](spec_v0.md)、[评审版 Design](design_v0.md) 与[调研范围共识](../../03-research/2026-11-13-brand-monitor-hierarchy/brand_monitor_common_context_v1.md)。本文为供评审的展示和交付建议。当前 Demo v0.7 已有概览对比表与同批下钻。本稿中的其他对比形态仍待验证。

## 1. 建议交付范围

| 建议优先级 | 对比位置 | 用户要解决的问题 | 展示规则 |
|---|---|---|---|
| 一期基础 | 品牌概览「子视图对比」 | 哪些分项规模大，主池里还有多少内容未覆盖 | 配置有效成员后，建议常驻在核心 KPI 之后、合作网红概览之前。主品牌同批基准加子视图分项，保留提及视频数、观看量、两项覆盖率、未覆盖内容数及下钻。 |
| 一期重点增量 | 品牌概览「推广活动趋势」 | 选中的子视图在什么时候开始放量 | 原图保留主品牌惯用口径，模块内入口「按子视图对比」默认收起。先支持同批发布内容数日线或周线。 |
| 一期基础 | 营销资产的内容库 | 哪些具体视频构成当前数值 | 从对比行、趋势数据点进入已选子视图的同批内容列表，呈现范围与筛选。主品牌四个库保留现有工作方式。 |
| 一期增补候选 | 品牌概览内容和互动分析、营销策略内容策略、市场动态新增内容 | 哪类内容互动强、不同视图在哪些语言和时段更活跃、最近出现了什么 | 保留模块内按需入口。分别核验互动字段和分母、发布时间与语言字段覆盖、市场动态固定窗口及权限。达到同行可比要求的项才展示。 |
| 后续候选 | 网红进阶、受众、商品、付费归因、AI 与异动 | 需要回答画像、成本效率或历史变化问题 | 优先按各视图的现有单视图报告读取。具备同批关系、分母或历史数据后，再考虑模块内对比。 |

展示分层建议为「常驻总览」「模块内按需」「只下钻」「暂缓对比」。常驻服务一眼判断，按需服务趋势或结构差异，只下钻服务查证，暂缓项继续按主报告原规则展示。

## 2. 对照标准报告逐块盘点

| 现有 Tab / 模块 | 现有数据 | 子视图对比建议 | 计算与证据要求 |

| 品牌概览 / 核心 KPI | 总内容数、总网红数、总互动量、商品总数量、预估总花费、战略浓度、资产沉淀率 | **常驻**内容数和观看量的同批值及覆盖率。总网红数、总互动量具备数据条件后可按需补列。商品总量、花费及两项比例先暂缓对比。 | 保留绝对值。同一账号用 `platform + original_channel_id` 去重，合作指标须先锁定有效合作集合。战略浓度与资产沉淀率以每份视图各自满足条件的合作网红为分母。 |
| 品牌概览 / 核心 KPI 内的 AI、竞争合作矩阵、付费推广 vs 自然传播 | AI 战略评估、竞品矩阵、付费/疑似付费/自然的内容量或播放量增长 | **暂缓对比**。付费分类确认后，考虑按需用分组条形图展示各子视图的来源结构及数量；AI 和竞品依赖独立逻辑。 | 子视图归因需按内容与主品牌的付费关系重算并明示未知项。现有曲线中的播放量增长需有历史观察值。 |

| 品牌概览 / 内容和互动分析 | 点赞、评论、互动率及其平均/中位数，播放、点赞、评论内容榜 | **按需候选**点赞、评论、互动率的绝对值或百分点差。榜单**只下钻**内容明细。 | 锁定现网互动率定义与平台可用分子。各视图基于内容重算平均/中位数，缺失值不填 0。只在相同指标定义和有效样本窗口下比较。 |
| 品牌概览 / 商品数据 | 商品总数量趋势、商品分类、价格/关联网红/观看/互动榜 | **暂缓对比**，有支持时**只下钻**商品及关联内容。 | 原模块按支持的平台与品牌商品数据条件显示。需商品稳定身份、内容到商品关系和去重归因。单条内容关联多个商品时先确定统计单位。 |
| 品牌概览 / 推广活动趋势 | 内容发布和观看量走势，含环比字段 | **一期按需**发布内容数趋势；观看量趋势为**条件候选**。对比单一指标时主品牌同批基准作参考，子视图并列。 | 发布数按内容发布时间，同一时区、日期桶和批次。累计观看量按发布日期分组与每日新增观看量分开命名，后者需历史采集点；环比要求前段等长且完整。 |
| 品牌概览 / 互动分析 | 互动趋势 | **按需候选**按日或周看点赞数、评论数等已验证指标，一次展开一项。 | 说明是内容发布日期切片还是历史增量。平台定义、字段和快照截点一致才比较，缺失日期显示缺口。 |
| 营销策略 / 网红策略 | 网红合作象限、合作效率、网红层级与类别、防御缺口 | **只下钻**合作网红。符合要求时**按需**量级和类别分布，对比入口与概览合作网红分布共享指标。CPE、爆款率、头部缺口待核。 | 区分现有量级、类目判定口径，与需要估价、互动、被排除对象及爆款判定的复杂指标。 |

| 营销策略 / 受众策略 | 受众地区、语言、性别、年龄及受众重合 | **暂缓对比**。 | 需要可按命中网红重算的受众估计模型和权重。跨视图或跨平台受众重合要有用户级身份或既有可信算法，不能由两份比例推导。 |
| 营销策略 / 商品策略 | 推广强度与流量贡献、商品声量占比、推广效能、推广适配度、集中度、商品推广矩阵 | **暂缓对比**。 | 指数基准、商品到内容和网红归因、多个商品命中的去重或分摊规则需要独立核验。 |
| 市场动态 / 内容数、观看量、标签图榜 | 72 小时新增内容与相关观看量、近 30 天走势、新增标签趋势与榜单 | **按需候选**72 小时新增内容数及同批证据列表，30 天内容走势按现有口径另验。榜单**只下钻**；观看量变化、真正新增标签待核。 | 固定模块窗口按同一截至时间与统计时区推导，说明其与通用 7/30 天对比日期的区别。新增内容的截至观看量、历史观看量新增分开；首次出现标签需要历史。 |
| 市场动态 / 异动通知 | 新晋头部或首次合作、内容表现飙升、付费互动率变动、自然声量和高频词 | **暂缓对比**。可在有资格的当前视图查看关联证据。 | 需合作历史、头部判定、连续指标版本、付费归因或主题分类时序，缺历史不能当作首次。 |
| 营销资产 / 内容库 | 内容明细、标签、观看与互动字段 | **一期只下钻**，可从基准、视图分项、已支持的图表数据点进入。 | 继承批次、视图 ID、时间桶、平台及该模块维度。按同批快照分页，列表总数和点击处同口径计数一致。授权失败和缺数据单独提示。 |
| 营销资产 / 网红库 | 网红明细、合作内容及网红维度筛选 | **只下钻候选**，支持已验证的合作网红指标后，从该数值下钻网红库。 | 只有明确的频道去重身份和同窗口有效合作关系才显示网红数。必要时支持由网红回到命中内容。 |
| 营销资产 / 标签库 | 标签榜、内容数、关联网红、观看及互动指标 | **只下钻候选**，由策略结构图或动态榜单下钻。 | 标签是内容属性。同一个内容可多标签，标签分项计数之和可能超过内容数。新增与热门分别遵循历史窗口。 |
| 营销资产 / 商品库 | 商品、关联频道、内容、商品声量及效能指标 | **暂缓跨视图对比**。已有同批商品关系能力后可**只下钻**。 | 继续按现有功能资格显示。通过商品标识和关联内容识别重复归属，确认价格和效能指标的币种、模型与更新时间。 |

## 3. 展示与计算共用规则

1. 所有 Tab 使用同一组已配置子视图。成员、统一刷新、临时显示和平台设置继续在「子视图管理 → 对比设置」。常驻表沿用现有行级设计，按需模块在原图旁提供「按子视图对比」的阅读入口，指标和时间粒度在展开层内切换。跨模块保持稳定的成员颜色、名称与顺序。
2. **一个子视图即可与同批主池对比。** 有可用同批成员时显示常驻对比表。未配置时建议收起整块数据表，仅在管理抽屉提供配置；已有配置但首批生成中或当前范围不可比时，展示对应状态或上一成功批次，不把它当作未配置。此建议与 Demo 当前保留基准空表的做法需要一起评审。临时隐藏行不改变已配置成员和未覆盖数。
3. **可加总值显示绝对值，可归属且口径一致的绝对值才显示覆盖率。** 内容以平台和原始内容 ID 去重。各子视图分别统计重叠内容，主池和已配置成员命中并集各去重一次。未覆盖数为同批主池内容集合的大小减去已配置成员命中并集的大小。覆盖率加总可能超过 100%，用并列条或折线表示，默认不做累积堆叠或整体份额饼图。
4. **比率按各自样本重算。** 互动率、推广占比、语言占比等采用各组自己的有效分母，显示原比率及与主品牌基准的百分点差。均值、中位数和各类指数分别从其所需的数据重算。同一个绝对值可计算两种不同方向的比例，必须标明是「占主品牌」还是「组内占比」。
5. 日期或平台是可比范围，批次是对应的数据版本。主报告标准模块仍可以按原口径更新，主池对比基准和子视图值从同一已发布批次读取，以当时的绝对日期、平台、时区、窗口和数据截至时间说明。共用筛选模块沿用抽屉日期与平台；固定窗口模块使用自身窗口，切换入口时明示。
6. 趋势默认先看一项指标。使用同日期桶、同长度时间序列和同一纵轴单位，克制选择同屏曲线；视图较多或量级悬殊时使用统一刻度的小多图或在本图临时减少可见系列。主池同批线显示为参考，标签、日期与指标点可下钻。明细页返回时恢复相同范围。
7. 有权限、范围齐全、成功取数且零命中时显示 0。若分母为 0，覆盖率与相对增长均用「—」并说明原因。未发布、视图未包含所选平台、缺字段或快照窗口、无权访问、刷新失败均标为对应状态。发布不完整时保持旧批次和其截至时间，避免同表混用新旧值。

## 4. 取证与验收

**现网界面取证**。2026-11-23 在 Anker 的 YouTube 品牌报告核对四个主 Tab。概览可见核心 KPI、合作网红、内容和互动、商品、推广及互动趋势。营销策略逐区核对了网红合作象限与防御缺口、月/周发布频率与内容语言标签、受众属性与重合度、商品声量和推广矩阵。市场动态可见 72 小时内容、观看和标签图榜及异动通知。营销资产可见四库，并逐一查看内容库、标签库和商品库。该样本确认模块标题及位置，数值口径和各平台覆盖需另证。[品牌概览](https://cn.noxinfluencer.com/brand/brand-analysis?pkId=17220&tabId=overview&platform=1) · [营销策略](https://cn.noxinfluencer.com/brand/brand-analysis?pkId=17220&tabId=strategy&platform=1) · [市场动态](https://cn.noxinfluencer.com/brand/brand-analysis?pkId=17220&tabId=dynamics&platform=1) · [营销资产](https://cn.noxinfluencer.com/brand/brand-analysis?pkId=17220&tabId=assets&platform=1)

**静态代码证据**。`kol-next` 使用 `master/a00cc966b` 与固定的 i18n 子模块版本 `2b54b612`，核查 `components/brandAI/tabComponent/{overview,strategy,dynamics,assets}/` 与 `api/brand/brandAnalysis.js`。后端按 `KOLServer master/706dc8ea0e`、`kol_server_v2 master/234e9dad` 双查。标准市场动态的近 30 天总观看量曲线在旧服务里使用较长窗口内按采集版本选出的观看值，并用各日发布内容的观看量回推（`BrandVideoRelation.xml:400`、`BrandMonitorV2Service.java:1277`）。新服务现有互动聚合区分总和、均值、中位数，也区分平台字段（`BrandVideoQuerySupport.java:158`）。主题词模块在中文词条中存在，Anker 样本本轮未确认渲染。以上均为静态代码或词条证据，生产数据完整性和复制同批口径尚待验证。[服务端证据基线](../../03-research/2026-11-13-brand-monitor-hierarchy/evidence/nox_brand_static_baseline_2026-11-17.md)

验收优先跑四条路径。

1. 主池 100 条，两个视图分别 60 条和 55 条、重叠 25 条。常驻表应显示 60%、55% 和 10 条未覆盖。临时隐藏一行保持 10 条，移除配置成员后按剩余成员重算。
2. 从概览的发布内容数某个日期桶下钻同一视图的内容库，对比图点与列表总数一致。切换平台、报告 Tab、关闭按需区再打开，不改变同批成员和口径。
3. 覆盖一个视图、未配置、配置后仍生成中、真实零条、分母零、局部指标缺字段、快照覆盖不足等状态。上次成功的数据日期与新任务状态分别显示。
4. 观看趋势验收使用有多次采集记录的同一条内容，分别检查按发布日期归属的观看数与采集值差分。只有日期桶、快照截点和历史覆盖都满足相应定义，才启用对应趋势；资产列表验证权限、数据完整性和日期窗口。
