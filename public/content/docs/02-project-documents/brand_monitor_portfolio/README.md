# 品牌监控：关联品牌聚合与定制视图

> 创建：2026-11-13（Asia/Shanghai）｜正式产品版本号：待核定｜阶段：竞品调研 / VDR 前置输入。

## 已确认目标

将相互关联的品牌（包括子品牌、产品线、事业群）的数据组织到一起，通过总—分形式的定制化视图，解决不同子品牌之间数据离散、需要用户手工拼接的问题。

本项目属于**品牌监控**，独立于 v7.5.2 品牌舆情雷达和 v7.5.3 品牌舆情二期。`portfolio` 是项目检索名，不代表已经选择“品牌组合”作为产品实现。
