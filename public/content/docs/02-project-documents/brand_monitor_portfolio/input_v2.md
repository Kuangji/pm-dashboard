# v7.5.4 主子品牌视图化查询｜Input v2

> 2026-11-23 · 当前范围及快照要求 · 品牌监控

## 1. 本期目标

用户可以在一个主品牌范围内看家族总览，并比较按子品牌、产品线、主题、活动等维度保存的子视图。**主品牌全量数据池是物理数据源，子视图从该池按条件生成快照。** 每份主品牌报告及其子视图使用同一个数据池。

## 2. 数据来源和子视图定义

| 对象 | 本期定义 |
|---|---|
| **主品牌** | 对应监控范围内的全量数据池。目标范围覆盖主品牌自身、各子品牌，以及已经识别属于家族但尚未分到任何子品牌的内容。主视图直接按该池取数。 |
| **子视图** | 保存名称、所属主品牌数据池、查询条件及可选的自定义视图标签。在指定池内按条件生成快照，查看时读取快照。子品牌、主题、活动等用途由用户用名称或标签标识。 |
| **对比配置** | 在「子视图管理」主列表勾选并保存 0–5 个成员。候选来自本客户在该主品牌下已启用且已有成功同批快照的子视图，主品牌基准另列。 |

Anker / Solix 作为本期的查询替换验证样本。新版 Solix 从 Anker 池内按条件重建，线上已有的 Solix 独立报告作为旧口径对照。要纳入 Anker 家族统计的内容由 Anker 数据池的定义决定。见 [Anker Solix 查询替换验证](子品牌查询与快照讨论_v0.md#anker-solix-查询替换验证)。

## 3. 总量与分项的计算

- **主品牌总量**直接从主池按当前日期、平台等统计条件取数并去重。未被所选子视图覆盖的池内内容仍计入总量。
- **子视图分项**使用由主池和查询条件生成的快照。每一分项的内容都可在用于生成快照的主池里找到。规则修改后的结果随快照更新。
- **同池对比**以已选子视图的实际命中内容计算指标。分项覆盖率的分子为该子视图指标值，分母为同批次、同日期和同平台的主品牌池指标值。重叠内容在各分项分别计数，在主池和所选视图命中并集中各去重一次。

例如主池有 200 条内容，所选两个子视图分别命中 100 条、80 条，其中 20 条重叠。主品牌总量为 200 条，分项覆盖率分别为 50% 和 40%，未被所选子视图覆盖的内容为 40 条。

本期在营销资产的内容库、网红库增加子视图归属多选，并支持接收同批作品或平台账号 ID 数组，用于在新标签页直接打开报告及管理诊断的明细名单。[两库接入范围](营销资产库下钻接入调研.md#一期接入范围)

## 4. 报告内容与版本边界

- **主品牌报告**沿用当前线上标准品牌报告内容。子视图对比区展示统计范围、同批基准、分项指标及下钻入口。
- **子视图管理**是主品牌范围内的全局设置入口。抽屉内集中管理子视图和对比设置，保留当前报告位置和标签。
- **子视图报告**以标准品牌报告内容为基础，使用自身快照。视图标签用于标识用途，查询所用的内容标签由查询条件单独定义。
- **同池对比**保存主报告上参与对比的子视图选择。另存为一份聚合视图留待后续。[评审版 Input](input_v0.md)

- **留待后续版本。** 多个主品牌池的聚合视图，以及主视图、子视图或独立报告混选形成的聚合视图。组合运算和二次组合随聚合场景一起讨论。
- **NIKKE 留作后续样本。** 当前已有多个独立运营地区报告，缺少一个可作为物理来源的主品牌池。地区报告合并属于后续聚合场景。
- **当前待细化。** 子视图查询条件、快照的范围及刷新、同池对比和占比指标、子视图报告指标及生命周期。本轮使用非正式草案和 Demo 评审。[评审入口](README.md)
