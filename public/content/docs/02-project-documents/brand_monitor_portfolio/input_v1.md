## 1. 背景与目标

关联品牌的数据分散在不同报告中，用户需要来回切换和手工汇总。v7.5.4 让用户从主品牌看家族总体和子品牌分项，也能把多个视图或现有独立报告组合成新的报告。主视图、子视图和组合视图在同一层级展示、打开和管理，各自保留数据来源。

| 线上数据现状 | 本版兼容方式 |
|---|---|
| **有主品牌和子品牌实体**。Anker 与 Anker Solix 目前已有各自的独立报告。 | 以主品牌全量数据池作为主视图的数据目标，再从池内定义子视图。现有报告之间的包含关系仅作现状参考。 |
| **没有主品牌数据池，有多个独立报告**。NIKKE 在聚星按运营范围分为多个独立报告。 | 直接选择相关的独立报告创建组合视图。各来源继续按现有报告独立取数，组合可以覆盖全部或部分地区报告。 |

## 2. 三种业务实体与数据来源

| 实体 | 数据来源 | 报告形态 |
|---|---|---|
| **主品牌** | 对应主品牌监控范围内的全量品牌家族数据池 | 以主视图呈现。数据池目标覆盖主品牌自身、各子品牌，以及已纳入家族范围但没有归到任何子品牌的内容。 |
| **子品牌** | 有独立报告时可按该报告的既有范围取数。从主品牌派生时，按查询条件在所属数据池内取数。 | 现有独立报告可供直接引用。从池内派生时，将名称、所属主品牌数据池和查询条件保存为子视图。 |
| **聚合视图** | 用户选取的多个主视图、子视图或现有独立报告 | 下文也称组合视图。支持同类或混合组合，来源可跨主品牌，也可完全由独立报告组成。保存名称、各来源引用和组合定义。 |

## 3. 派生与组合关系

- 从主品牌数据池向下查询可创建子视图。子视图的结果始终在所属主品牌数据池的范围内。
- 主视图、子视图和现有独立报告都可以作为组合来源。没有主品牌数据池时，多个独立报告可直接组合。独立报告作为可引用的数据来源，视图类型仍为主视图、子视图和组合视图。
- 组合结果归为组合视图。即使来源包含同一主品牌下的全部子视图，或包含 NIKKE 样本中全部独立报告，结果仍是组合视图。
- **主视图只能由主品牌全量数据池定义，禁止以子视图组合定义主视图。** 当主品牌数据池和统计条件固定时，新增、修改或删除子视图均不改变主视图总量。

## 4. 总量计算口径

先确定当前视图在有效统计条件下的内容集合，再按指标口径计算。内容数按内容身份去重，同一内容在同一视图的结果中计一次。播放量、互动量等内容指标使用当前视图去重后的内容计算。比率等非加总指标按自身口径重算。各来源视图里已算好的汇总数字不能直接相加。

| 视图 | 总量取数范围 |
|---|---|
| **主视图** | 对应主品牌的整个数据池。未命中任何子视图的池内内容仍计入总体。同一内容可出现在多个子视图中，在主视图总量中计一次。 |
| **子视图** | 所属主品牌数据池中命中该子视图查询条件的内容。同一内容可以分别计入它命中的各个子视图。 |
| **组合视图** | 对所选视图或独立报告的内容集合按组合定义运算，再计算结果集合的总量。以 NIKKE 为例，总量表示所选运营范围组合后的结果。具体运算方式待定。 |

**演算示例。** 在相同统计条件下，主品牌池有 200 条内容。子视图 A1 命中 100 条，A2 命中 80 条，其中 20 条共有。主视图总量为 200 条，A1、A2 的总量分别为 100 和 80 条，未命中两个子视图的内容有 40 条。若以取并集为例，A1 与 A2 的组合包含 160 条，保留独立的组合视图身份。这个示例只演示计算关系。

例如由 `nikke-sea` 和 `nikke-jp` 创建的组合视图，其总量按这两个来源的组合结果计算。`nikke-global` 也按现有报告的范围作为独立来源供选择。
