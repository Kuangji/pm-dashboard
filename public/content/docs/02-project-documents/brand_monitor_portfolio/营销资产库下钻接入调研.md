# v7.5.4 子视图对比下钻到营销资产库

2026-11-26 · 非正式评审输入。现状来自 Anker 已监控报告的只读实测及代码核对。子视图和交集沿用 v0.26 的模拟数据；两库筛选与名单下钻见 Demo v0.29。

## 一期接入范围

**内容库和网红库均为一期交付。** 两库都增加「子视图归属」多选；作品查哪些视图收录它，账号查它在哪些视图的当期内容里发过文。普通多选按命中任一项去重。图表能用日期、平台及所选视图精确描述时带入这些条件；共同名单、Top 5、多次发布等派生结果可以直接传 ID 数组。

| 传入条件 | 意义 |
|---|---|
| 未传 ID 数组，未选子视图 | 当前品牌、批次、日期和平台允许浏览的整库，含没有归入任何子视图的作品 |
| 未传 ID 数组，选 A、B | 作品取 A 或 B 的并集；网红从这些作品归集，按平台账号去重。一个账号发布一条同时命中 A、B 的作品，在并集内计一次 |
| 仅传作品或账号 ID 数组 | 严格取同批指定名单。显式空数组得到 0 项；账号或作品以「平台、ID」成对传递 |
| 同时传 ID 和归属多选 | 在精确名单内继续筛选。清除追加条件回到原名单，原图的两侧发文数或 Top 排名仍有同一解释 |

例如岩途 10 月，勾选山野与居家得到 **1,268 条作品、292 个已匹配参与网红**。从矩阵点击同一对的共同名单得到 **44 条作品、140 个共同网红**。两个入口表达不同业务问题，不能互换。

两库的改动及表头规则见[资产库一期修改点](营销资产库一期修改点.md)。

### 资产库下钻范围如何传递

从报告打开资产库时，下钻范围（Demo 中称为 `assetScope`）应通过 URL 参数直接传递作品或账号 ID 列表，还是由服务端生成临时记录、在 URL 中传记录 ID？留待技术评审确定。如采用服务端临时记录，生成时同步保存本次下钻定义和口径，以便资产库恢复展示。

## 线上四个库实际能做什么

在 Anker 的 YouTube 报告逐库打开列表及「自定义筛选项」，再分别新开 Instagram 和 TikTok 的内容库。当前页面一次选一个平台。Anker 在 YouTube 有四库，在 Instagram 和 TikTok 只出现前三库。商品库还取决于品牌是否有 YouTube 商品数据。以下操作能力同时参考组件实现，实测只做读取和筛选，未执行导出、收藏或监控操作。

| 目标库 | 一行是什么 | 现有筛选和后续操作 | 对本轮下钻的意义 |
|---|---|---|---|
| 内容库 | 一条平台作品 | 内容关键词、频道地区/语言、内容相关性、提及方式、内容形式及观看/评论/点赞/互动率区间。可切卡片或表格、排序、看汇总和按权益导出。内容形式随平台变化 | 趋势、推广、共同内容、互动样本都能复用。线上相关性选项无法完整表达快照里的「未识别」 |
| 网红库 | 一个平台账号 | 有「多次合作网红」「新晋合作网红」预设，可按频道地区/语言、年龄性别、最近推广、粉丝、互动等筛选，支持勾选、收藏、按权益导出及查看提及视频 | 适合浏览名单和选人。当前合作次数与提及视频按主品牌计算，不能直接解释子视图内的发文或双方交集 |
| 标签库 | 一个内容标签 | 标签语言、发布区域、内容形式、关联账号数、内容数/占比、观看及互动，可筛排、导出 | 用户按关键词定义子视图，点趋势后要找的是作品。只有图上统计对象本身是标签时，才导向这里 |
| 商品库 | 一个商品 | 价格、关联网红数、总观看量、平均互动率、产品声量占比等，可查看提及视频、收藏商品、导出 | 适用于未来的商品排名或商品名单。当前没有相应下钻入口 |

可复核的线上入口：[内容库](https://cn.noxinfluencer.com/brand/brand-analysis?pkId=17220&tabId=assets&platform=1&subTab=content) · [网红库](https://cn.noxinfluencer.com/brand/brand-analysis?pkId=17220&tabId=assets&platform=1&subTab=influencer) · [标签库](https://cn.noxinfluencer.com/brand/brand-analysis?pkId=17220&tabId=assets&platform=1&subTab=tag) · [商品库](https://cn.noxinfluencer.com/brand/brand-analysis?pkId=17220&tabId=assets&platform=1&subTab=product)。需要相应报告访问权限。

### 新开标签页和页内筛选的差别

| 只读实验 | 线上观测 | 对设计的约束 |
|---|---|---|
| 带品牌、平台、资产 TAB、四种 subTab 分别冷启动 | 四库均能首开定位。标签库首开请求 brandTagRank，随后地址栏只保留 tabId、platform、pkId；刷新发出 brandKolList，变成默认网红库 | 新增的下钻入口要连同库和范围一起保留在地址中，覆盖刷新和复制链接 |
| 在内容库输入 solix 回车 | 默认窗口为 2025-11-25 至 2026-11-25。列表由展示上限 10,000 条缩至 5,323 条，总浏览量由 15.23 亿变为 1.43 亿；地址不变 | 页面确实能筛，地址不足以重现这次筛选。这里用搜索词验证路由，不用于定义子视图 |
| 新页显式带 videoTitle=solix、startTime、endTime（2026 年 10 月）及按观看量升序 | 列表以表格打开，首屏有零观看的作品；搜索框为空，仍为默认年度窗口、10,000 条、15.23 亿 | 首载读取排序和部分呈现参数。页面实际使用的关键词和报告日期仍需单独初始化 |
| 新页带内容预设 otherConditions=8 和按观看量降序 | 当时显示 552 个视频，「最近 3 天更新内容」已有入口 | 固定预设可复用。这个预设随日期移动，无法代表历史快照中的某周 |

这些数量仅用于同次对照。内容列表服务将可翻页数和展示总条数封顶在 10,000，因此 10,000 不能作品牌全量，也不能作来源图的分母。

## 对照现有 Demo，点下去到底要找谁

| 报告点击入口 | 应交给资产库的初始集合 | 图上或目标页仍需解释什么 |
|---|---|---|
| 主品牌/子视图指标表「明细」、子报告内容、平台构成、发布趋势点 | 内容库。取所选视图同批作品，叠加报告日期、平台；趋势再取点击的日/周与报告期间的交集 | 标题指明来源、平台与绝对日期，首次数量等于该点发布量 |
| 推广类型构成 | 内容库。只取该视图该类型的快照作品，包括「未识别」 | 由图的分类结果给出名单；在线筛选器没有对应选项也能打开 |
| 内容重合矩阵、管理侧覆盖诊断 | 内容库。前者取点选 A、B 的作品交集；管理侧分别取已配置成员并集、主池减并集、命中至少两个成员 | 矩阵保留双方覆盖比例和各自分母，再提供「查看共同内容」。管理诊断沿用保存的成员范围 |
| 总观看量的 Top 5、同平台互动率 | 内容库。前者先按同批观看量全范围取前五，同值按平台作品键稳定排序。后者取适用作品，Instagram 仅视频，保留字段缺失的适用样本 | Top 5 保留对该视图总观看量的贡献；互动率保留有效/全部样本、计算分子分母及评论中位数。名单可跳，指标解释留在图旁 |
| 参与网红数、多次发布达人占比 | 网红库。前者取能匹配频道资料的参与账号；后者先按视图内当期发文聚合，再取发文至少两次的账号，包含未匹配频道资料者 | 展示该账号在本范围的发文数和对应作品。资料缺失时仍需保留可辨识的平台账号行 |
| 参与网红重合矩阵 | 网红库。分别从 A、B 求出参与网红，再按平台账号取交集 | 在账号行内展示「在 A 发文」「在 B 发文」的次数和各自作品。既有主品牌合作记录可单独打开，两侧的次数分别按对应视图的命中作品核对 |

观看/视频占比条、互动总量和中位数未单独提供名单入口。创建视图时的逐条命中原因仍在规则预览里看。全程不产生新的可保存聚合视图。

## 最小接入方案

**一个下钻范围，两种名单，沿用现有资产页。** 目标是让用户首屏核对数量，接着在同一批记录内筛选、排序、翻页和选择。无需为每种图在资产库添加新的高级筛选器。

1. **来源图决定初始范围。** 新页及刷新后的名单须对应同一主品牌、快照批次、期间、平台和来源指标。共同网红保留两侧发文数，Top 5 保留来源排名。
2. **目标页先恢复范围，再发首个列表及汇总请求。** 在资产列表标题旁显示来源，例如「山野 × 居家 · 共同内容 · 10 月 · YouTube」。范围外的条件由页面锁定；用户追加的筛选在范围内生效。「清除筛选」仅清除追加项。排序、分页、计数、勾选以及开放给用户的导出都遵守同一范围；不能正确限定的批量操作先不在这个入口开放。频道资料等补充信息可以沿用当前资料，带回解释日/月报的指标必须取同批值。
3. **平台范围随图带入新页。** 单平台来源直接打开该平台。全平台来源直接打开完整名单，可在资产库内按平台细筛；Top 5 先在全平台截五。线上现有库一次只展示一个平台，生产接入需处理全平台名单的承接，并验证各分项之和等于来源数量。

4. **空结果、失效和权限有各自的落点。** 有效空集显示 0；旧快照被覆盖、视图失效或权限撤回，给出对应状态和回报告入口。打开链接及后续取数均校验当前客户的品牌监控权限、对应私有视图访问权和目标操作权益。切库或退出范围应显式返回常规资产库。刷新、复制链接及判断无权限时都不能默默变为主品牌全量列表。
5. **保留必要的短解释。** 档位、百分比或矩阵单元格可以先在原图展示分子、分母和「查看明细」。所有作品或网红名单入口直接打开对应资产库。Top 5 贡献、互动率的有效样本数及共同达人的两侧发文随来源口径带入资产页。

### 两库实现顺序和验收

| 顺序 | 开放入口前的条件 | 可执行的验收样例 |
|---|---|---|
| 首轮接内容库 | 先通单视图趋势和 A∩B 共同内容两条贯穿链路，分别覆盖日期和现成筛选无法表达的集合。首屏、汇总及全量范围内二次筛选均从同批结果取数，再用同一能力接推广类别、平台、覆盖诊断 | 用 Demo 岩途 2026 年 10 月，「山野 × 居家」共 44 条共同作品。跨平台分项加总为 44；逐平台核对键集，筛选后再清除能恢复，刷新仍是共同作品。空交集始终为 0 |
| 再接带解释的样本 | 快照排序、缺值与图一致，来源指标和列表条数分别标清 | 岩途全池 Top 5 为 2 条 TikTok、3 条 YouTube；清除附加筛选仍只有这 5 条。互动率可以查看缺值记录及有效样本数 |
| 同期接网红库 | 先验证已匹配参与名单，再验证共同网红两侧发文证据及重复发布的未匹配账号行。验收包括对应名单可在网红库继续筛选；研发联调时按同批来源作品及账号键集逐项对照。 | 岩途两视图共有 140 个参与网红，其中 103 个没有发过同时命中两边的作品。全池有 328 个多次发布账号，其中 17 个缺频道资料。分别验名单、发文数及点开后的作品，而不只比总数 |
| 所有入口共用 | 过期/无权/跨客户不能读原名单；一个名单超过现行可翻页上限时仍能对整批执行筛选。若暂沿用上限，明确显示「命中 X，可浏览前 10,000」，提供缩小日期/条件，并验证缩小后能命中原先在首万之外的记录 | 用不同权限账号、被替换的快照、边界日期和大于一万条的测试集验收。涉及全量导出的承诺须另验权益和服务端范围；首万截断不能充当全量 |
