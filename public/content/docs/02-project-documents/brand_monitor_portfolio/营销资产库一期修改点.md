# v7.5.4 营销资产库一期修改点

2026-11-26 · 非正式评审稿 · Demo v0.29。改动覆盖主品牌及子报告里的内容库、网红库。标签库和商品库沿用现行报告。

## 1. 两种入口，共用一套列表

| 用户如何进入 | 列表初始范围 | 列表上方 |
|---|---|---|
| 在「营销资产」直接浏览、手动多选子视图，或把该库在新标签页打开 | 普通浏览范围及用户选中的筛选条件。子报告以该子视图为上限 | 展示常规筛选与日期等浏览信息，隐藏下钻说明 |
| 点击指标、趋势点、图表分段、矩阵的共同名单或管理诊断明细 | 新标签页打开来源指标对应的同批名单。首次显示的对象和数量必须能对回来源 | 展示这次下钻的定义、统计范围及必要的计算口径 |

显示说明取决于**入口用途**。普通浏览即使带了子视图筛选或在新标签页打开，仍属于普通浏览；点击周趋势即使只需日期和视图条件，也属于下钻。

## 2. 两库新增「子视图归属」多选

候选取本客户在该主品牌下可读、已启用且有同批结果的子视图。报告最多勾选五个对比成员，资产库可以筛选其他符合条件的子视图。

- **内容库**按作品是否命中任一所选视图筛选。同一作品同时命中多个视图，按平台和作品 ID 计一行。
- **网红库**先取所选视图命中作品的并集，再按平台账号归集。在当前范围发过文的账号可以命中多个视图，一行展示其归属和去重发文数。
- 普通浏览清空归属后回到当前报告范围。复杂图表可指定精确作品或账号名单，追加筛选与名单取交集，清除附加条件后回到来源名单。空名单显示 0 条。来源批次失效或权限撤回时提示对应状态。

## 3. 下钻说明随名单一起生成和恢复

创建下钻范围时一并固化用户需要读到的信息。刷新、排序、翻页或继续筛选后，说明仍解释**点击时的原始结果**；列表条数显示**当前筛选结果**。

| 信息 | 展示规则 |
|---|---|
| 来源与名单定义 | 显示来源视图或视图组合、所点指标及入选规则。例如「山野系列 × 居家系列 · 共同网红」指在同一期间分别向两个视图发布过作品的已匹配平台账号，允许两侧是不同作品 |
| 统计范围 | 显示当时的日期窗口、平台、快照批次和数据截至时间。点击某一周就显示那一周 |
| 指标专属口径 | 按需要显示。Top 5 说明按何种观看量排序及前五条的贡献；互动率说明平台公式、有效样本和适用样本数。简单的发布明细只需说明收录条件 |

**技术评审项。** 若由服务端生成临时 `assetScope` 记录，建议在生成该记录时同步保存上述说明及其所依据的范围，读取名单时一起返回。若采用其他传递方式，也应能恢复当时的说明。是否建立临时记录、如何存储和传递继续由技术评审决定。[已记录的技术问题](营销资产库下钻接入调研.md#资产库下钻范围如何传递)

## 4. 同一个库的表头、列序和含义一致

以该库在同一平台及权限下的标准列表为基准。普通浏览、下钻、精确名单和有效空结果共用这套表头。生产接入沿用现网已有业务列，两库统一补充「子视图归属」。下表列的是 Demo 用于评审的精简列。

| 库 | Demo 基础表头（按顺序） | 指标专属明细放在哪里 |
|---|---|---|
| 内容库 | 作品、平台、发布日期、观看量、子视图归属 | 互动率下钻可在作品行展开点赞、评论及平台适用的分享和收藏；子报告有命中证据时，可在作品行查看命中原因 |
| 网红库 | 网红、平台、范围内发文数、子视图归属 | 共同网红在账号行内分别查看 A、B 两侧发文数及作品。两侧的同一作品在「范围内发文数」只计一次。多次发布账号缺少频道资料时保留账号标识 |

例如某账号在山野发 3 条、居家发 2 条，其中 1 条同时命中两边，标准列「范围内发文数」显示 4，行内两侧分别显示 3 和 2。若历史数据仅给出两侧次数，无法还原去重数，则该单元格显示「—」。

## 5. 评审核对

1. 普通打开内容库和网红库，选两个子视图，再从库内新开同库。筛选条件可带入，两处都没有下钻说明。[普通资产库](../../../demos/brand-monitor-portfolio-754/index.html#assets&scene=full)
2. 从互动率、Top 5、周趋势分别进入内容库。核对各自说明，逐项对照普通内容库的列名与顺序；刷新后仍能读到原说明。[满载月报](../../../demos/brand-monitor-portfolio-754/index.html#full-comparison)
3. 从「山野 × 居家」进入共同网红。10 月样例有 140 个账号，表头与普通网红库一致。展开一个账号核对双侧发文，再筛到零结果；表头和来源说明仍可见，清除后回到 140 人。[重合度矩阵](../../../demos/brand-monitor-portfolio-754/index.html#overlap)
