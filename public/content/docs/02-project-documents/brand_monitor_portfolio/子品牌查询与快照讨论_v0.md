## 1. 子品牌查询规则

建议把一份子品牌视图定义为**所属主品牌、子品牌名称与持续有效的收录条件**。日期、平台等本次分析条件另行处理。若业务规则就限定某个平台，则将其作为收录条件保存。

| 条件 | 一期建议 |
|---|---|
| 识别子品牌 | 先评估品牌名及别名、产品关键词、标签。若指定发布账号能明确识别子品牌，使用平台与频道 ID。已有可靠的子品牌归属字段也可作为候选。 |
| 约束或排除 | 允许明确限定收录平台，并用排除词或标签剔除同名误命中。基本逻辑可用「至少命中一个识别条件，同时满足适用约束，且未命中排除条件」。条件字段和组合方式待评审。 |
| 保存前检查 | 在选定主品牌池范围内预览命中条数和样本，方便检查漏掉的典型内容与明显误收。预览、生成与后续可解释性使用同一份条件定义。 |

以 Solix 为例，可以把 `Anker SOLIX`、`SOLIX E10` 及已核实的发布账号作为候选条件，在 Anker 池里抽样看命中。孤立的 `Anker` 容易带入其他产品线。现有 Solix 独立报告可供抽样对照。

现有内容库支持临时关键词等筛选。以本地服务端实现为例，YouTube 关键词查标题或关键词，Instagram 和 TikTok 查说明或标签，发布账号可按单个频道 ID 精确筛选。多词组合、多账号和规则持久化仍需具体定义。[Anker 内容库](https://cn.noxinfluencer.com/brand/brand-analysis?tabId=assets&platform=1&pkId=17220&subTab=content)

## 2. 快照冻结什么，怎样做同批对比

**建议采用报告结果快照。** 每次生成记录主品牌池使用的数据批次、子品牌规则版本、覆盖日期及平台、命中内容集合，以及生成报告所用的指标值或可复现的指标数据版本。同时保留同批主品牌基准。打开子品牌报告时读取最近一次成功发布的快照。快照支持的筛选可在已保存范围和数据维度内读取或重算。

- 如果只冻结命中的视频名单，观看量等仍取当前值，历史报告的数字会变化。结果快照需明确固定哪些指标和关联结果。日期范围和数据采集截至时间分别记录，生成时将「最近 30 天」之类的相对范围解析为具体起止时间。
- 主品牌现有标准报告可以按其线上方式更新。**新增的子品牌对比用同一主品牌批次、同一日期及平台和同一指标定义。** 子报分别来自不同批次时，建议沿用上一次可比批次，或为选择的子品牌生成同批结果。跨批次数字不直接计算占比。
- 例：Solix 快照有 60 条，同批 Anker 池有 100 条，覆盖率是 60%。主品牌标准报告后来显示 200 条时，这份 Solix 快照的覆盖率仍按 60／100 解释。

首次生成、数据刷新与规则修改是三种触发。候选是先支持首次生成和明确触发的刷新。自动刷新节奏、覆盖的历史区间及保留多少批次待确认。

## 3. 主品牌报告增加什么

**沿用当前线上标准品牌报告，并新增同池子品牌对比。** 已在线核对 Anker 和 Anker Solix 的品牌概览、营销策略、市场动态与营销资产入口。Anker 的营销资产含网红库、内容库、标签库、商品库。[Anker 标准报告](https://cn.noxinfluencer.com/brand/brand-analysis?pkId=17220&from=brand_search&word=anker) · [Anker Solix 标准报告](https://cn.noxinfluencer.com/brand/brand-analysis?pkId=3547978&from=brand_search&word=anker%20s)

子品牌对比应能看到同批主品牌基准、各已选子品牌的绝对值和覆盖率，并进入对应子品牌报告或明细。建议先比较**提及视频数与观看量**，两项都能用同一内容集合计算。每条内容在主池总量中计一次，可以同时出现在它命中的多个分项，所以覆盖率可以相加超过 100%。根据需要补充未被子品牌覆盖的内容数，与各子品牌的覆盖率一起解释总体。相关网红数和互动指标仍待对齐频道身份、互动分子和分母。

## 4. 子品牌报告沿用哪些内容，是否增加专有指标

标准品牌报告内容是子品牌视图的目标基线。每个模块要能在子品牌自身的快照范围下解释。以下是按线上报告和静态代码核对出的数据依赖。

| 标准报告板块 | 可按快照重算或读取 | 仍需核对的依赖 |
|---|---|---|
| **品牌概览** | 提及视频数、观看量、互动量、具备频道身份时的相关网红数。 | 推广归因、预估花费、竞品矩阵及 AI 战略评估。现有 AI 使用单个品牌 ID、竞品集和固定分析窗口，需明确子品牌口径。 |
| **营销策略** | 发布量、发布时段、语言及标签等内容分布。 | 网红画像、受众及重合、商品策略依赖频道、受众、竞品或商品关系。 |
| **市场动态** | 快照覆盖范围内可按发布时间计算近期内容或标签趋势。 | 异动及新合作达人依赖较长合作历史，时效以快照截至时间为准。增长类指标是否需要历史观察值需按定义核对。 |
| **营销资产** | 内容、已关联频道和标签的明细。 | 频道属性及商品库需要相应关系数据，商品按子品牌范围归属。 |

**建议先沿用已有指标，新增必要的统计说明。** 子品牌报告应标明所属主品牌、覆盖日期和平台、快照截至时间。若用户独立打开子报时确实需要看它在家族中的分量，可增加「占主品牌的提及视频数／观看量覆盖率」，与主报告对比采用同一份分母。其余子品牌专有指标暂由实际任务决定。对依赖不足的标准模块，后续明确哪些可补数据再算，哪些标明当前快照缺少所需数据。

## 5. 创建、查看与生命周期

**入口候选。** 用户从对应主品牌报告进入子品牌管理，定义、预览并保存条件，生成成功后可以从该主品牌的对比或分项入口打开子品牌报告。子品牌报告可单独打开，能识别自己的主品牌、快照范围和时间，并返回主品牌。品牌搜索或全局列表是否展示子品牌视图留待讨论。

| 状态 | 建议的业务行为 |
|---|---|
| **首次生成中** | 收录条件已保存，正在生成结果。此时暂无可读快照。 |
| **可用** | 独立查看和同批对比读取已发布快照。成功但未命中内容属于有效零结果。 |
| **更新中** | 读者继续使用上一份成功快照。新快照完整生成后整体切换。 |
| **生成失败** | 初次失败可重试。更新失败时保留旧结果和当时的规则、截至时间，单独说明新一轮失败。 |

修改收录条件产生新的规则版本，配套快照生成成功后再发布。旧结果继续对应旧规则。停用、历史快照保留和失权后的处理待定。

本轮最需要确认的是收录条件的最小字段、结果快照冻结哪些标准模块及指标、同批生成和刷新方式。入口位置、具体页面样式及完整状态交互留在后续阶段。
