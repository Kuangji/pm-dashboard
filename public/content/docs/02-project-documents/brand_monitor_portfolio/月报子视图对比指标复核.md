# v7.5.4｜品牌负责人月报的子视图对比指标

2026-11-26 · 候选评审稿。对照线上标准品牌报告，记录 v0.23 已实现的三组分析及后续候选。适用于同一主品牌下手选的 1–5 个私有子视图。

## 建议的月报阅读顺序

先看本月哪条产品线投入了内容、动用了多少达人，再看典型内容引起多少回应。遇到明显差异，依次检查推广类型、达人组合、渠道或主题，最后落到具体达人或作品。已有 Demo 能看提及视频数、观看量及其主品牌占比、单条观看中位数、平台构成、发布节奏和头部视频。v0.23 已在本地样例中补足**参与达人、互动表现、推广结构**，三者分别回答谁在发、观众怎么回应、内容从哪里来。

| 负责人要解释的差异 | 标准报告来源与建议口径 | 合适的图、展示时机与下钻 |
|---|---|---|
| **发得多，是参与的人多，还是同一批人发得勤？** | 概览「总网红数」「资产沉淀率」。各视图分别统计有频道资料的去重网红数；另按该视图内当期发布至少两条命中内容的频道数 ÷ 当期发布命中内容的全部频道数，显示「当月多次发布达人占比」。比例与资料匹配后的总网红数使用不同分母。 | **优先**。总网红数放现有矩阵，旁列提及内容数。每视图一行的点图比较多次发布占比，附分子/分母，下钻达人名单及各自发布数。跨平台按平台账号计，同一达人可进入多个视图。 |
| **声量高，观众也更愿意回应吗？** | 概览「总互动量」「内容和互动分析」，资产内容库的赞评明细。用总互动量看规模，用同平台互动率看相对表现，用单条评论数中位数看典型作品引起的讨论。TikTok 的分享、收藏可单看。 | **优先**。总互动量进矩阵；同平台时用横向点图比较互动率，标有效样本数。点击某行看高评论作品及评论中位数，判断是否由一两条内容拉高。多平台先分面，同图内沿用相同的互动率公式及内容范围。 |
| **哪个系列依靠识别为付费的推广，哪个更多来自其他提及？** | 概览「付费推广 vs 自然传播」，按内容和主品牌的推广关系，取本视图内各类去重内容数 ÷ 本视图全部命中内容数。沿用「付费推广」「疑似付费推广」「自然传播」的线上展示名，不能归类的单列「未识别」。自然传播对应系统识别的提及，不能据此判断实际合同或现金支出。 | **优先**。每个视图一根 **100% 堆叠横条**，共同图例、右侧列总条数。两条线即使同为 30% 付费，也可能分别只有 3 条和 300 条，比例旁保留数量。点色段核对视频。上线前用明细核对分类与内容数。 |
| **达人组合偏头部还是偏中小达人？** | 概览「战略浓度」、营销策略「网红层级与类别」。核对的核心 KPI 路径以粉丝数超过 100 万的频道为分子、全部命中频道为分母；策略分层使用平台自己的档位。两套定义分别呈现，列资料覆盖。 | **按需**。同平台下每视图一条达人层级构成条，点某档看人数和名单。若月报只需头部依赖程度，用一个头部占比点即可。达人类别支持多选时改用并列条。 |
| **差距是在某次上新形成，还是整月持续？哪条线比上月更活跃？** | 概览「推广活动趋势」、策略「内容发布」。周发布数已有 Demo；优先拟加提及内容数、当月参与达人、本期与上期的变化量。以发布日期分桶的互动表示这些作品截至快照的表现。 | **保留周折线**，按需显示本月与上月的配对点图及差值。月长不同时可补日均发文；前期为零标「本期新增」及绝对差。要有同规则、两段完整快照覆盖。若比较活动波次，可在窗口具备时按活动第几天对齐。 |
| **是平台组合、内容形式还是当地运营方式不同？** | 策略「内容策略」有内容语言，内容库有形式筛选。沿用已有各视图平台构成，在单平台内继续比较适用形式或内容语言。渠道用视频数，构成百分比以本视图有效内容为分母并交代未知项。 | **按需**。平台或形式是互斥分类时，每视图一根 100% 条；语言若为多值则按共同语言并列。分析地区视图时分别标清运营账号、内容语言和达人所在地区。点分段看作品。 |
| **产品线靠哪些内容主题被提到？哪些卖点只在某条线突出？** | 营销资产「标签库」有标签关联内容数及关联占比。用各视图共有的一组候选标签作横向比较，每格为含该标签的去重内容数 ÷ 本视图内容数。 | **按需**。标签 × 视图热力图，附命中条数。对按关键词定义的视图，默认避开直接用于建视图的条件词，优先看伴随出现的场景或卖点。点格核对作品。 |
| **两条产品线推广的是不同品类，还是不同数量的商品？** | 概览「商品总数量／商品分类」、营销策略商品专题。优先核对子视图视频到商品的关联后，算视图内去重关联商品数及品类；须标明按内容发布日期还是商品建档/上架日期。 | **有条件专题**。YouTube、有商品、归属可回溯时，用横条比商品数，共用品类 × 视图矩阵比结构，点击查看关联商品及视频。商品关联表示内容覆盖的货品，销售成果另需交易数据。 |

## 哪些看得到，但本期不宜直接搬入月报

| 现有板块 | 月报处理 |
|---|---|
| 概览预估总花费、策略合作效率与 CPE | 线上存在预估报价区间，不同模块按频道或内容估算。一位达人发多条、同时命中两个系列时需明确归属。先保留主品牌上下文，待估价覆盖与分摊规则就绪再评审分项区间图。真实预算、ROI 要有实际费用与结果数据。 |
| 策略「受众策略」地区、语言、年龄、性别 | 现有地区画像与年龄/语言使用不同权重。子视图要有可按命中频道重算的样本、权重及覆盖率；届时可用共同地区的并列条或年龄构成条。受众地区、网红所在地和运营区域各自回答不同问题。 |
| 市场动态的 72 小时新增、异动通知；策略中的竞品象限 | 72 小时排行适合回看某次发布或异动。完整自然月的走势采用月内数据重新分桶。竞品象限、商品 SOV 等使用外部参照，所选子视图之间的份额另有分母。 |
| 未覆盖、整组覆盖和条件失效 | 在管理侧诊断。v0.25 月报可按两两视图分析共同的作品与发布账号，帮助解释产品线或主题之间的联系。 |

## 跨视图计算与展示

- 最多五个已保存成员，主品牌单列，沿用现有监控权益和私有视图读取规则。各行同批、同日期、同平台，同一内容或频道可进入多个视图。用独立横条看各自占主品牌的比重；用堆叠条看**一个视图内部**的互斥构成，类别要覆盖完整。
- 粉丝数、互动值、推广关系使用对应快照；缺字段、零分母、未收录的平台分别提示，真实零保留。互动率分平台复用标准报告公式，尤其注意 Instagram 的视频子集和 TikTok 的分享收藏。按运营阶段比较累计互动时，还要考虑内容发布后有多少天可以积累互动。
- 仅选一个子视图时可用主品牌作参考；对没有可比基准的结构图仅展示该视图自身构成。月报按品牌线、地区、主题建视图均用同一套规则；同一条内容在多个关键词组出现时，各组占比之和可能超过 100%。
