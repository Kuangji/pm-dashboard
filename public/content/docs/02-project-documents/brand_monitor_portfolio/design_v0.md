## 两个资产库的入口与反馈

在主报告「营销资产」切换内容库或网红库，即可在列表上方筛选。报告内和新标签页共用同一份资产列表组件。两库都展示「子视图归属」多选；进入时可直接浏览全部，也可勾选多个视图、搜索、翻页。点击趋势点、表格明细、平台或推广类型分段，直接在新标签页打开内容库；参与及多次发布网红直接打开网红库。矩阵先在报告内显示所选组合的双向覆盖，点击该组合唯一的名单入口打开对应资产库。管理诊断的已覆盖、未覆盖和重复命中也直达内容库，原管理面板保留。仅下钻入口在列表上方显示来源、定义、日期、平台与批次，普通浏览及库内新开页隐藏该说明。Top 5 贡献、互动率样本说明及共同网红两侧发文随数据呈现。子报告快照含逐条命中原因时，在内容库的作品行展开。[资产库一期修改点](营销资产库一期修改点.md)

主报告的普通归属筛选允许更换所选子视图。在子报告自身的营销资产内，清除或更改归属仍受该子报告的内容范围限制。在报告内已筛好的列表打开同库新页时，带入归属、平台、关键词与排序；切换另一类资产时沿用归属与平台。复杂名单进入时显示来源及名单规模，在这份名单内追加归属、平台或关键词筛选。清除追加条件可回到来源名单。两库沿用各自标准表头；互动证据及共同达人的两侧发文次数和作品在行内查看。资料缺失的多次发布账号仍展示账号标识。无命中与名单失效分别反馈。

## 1. 报告与管理入口

| 界面 | 入口与目的 | 信息及操作 |
|---|---|---|
| 主品牌报告 | 「品牌监控」内进入岩途 TerraPeak | 品牌概览、营销策略、市场动态、营销资产共用页首的「子视图管理」入口。独立的「子视图对比」TAB展示统计范围、指标及明细。 |
| 子视图管理 | 主品牌页首右侧的全局入口 | 右侧抽屉在视图列表上方提供「对比设置」。列表显示视图名称、标签、平台、任务状态和最后成功快照。有本品牌监控读取权时可打开已发布报告；仅向当前有效付费、已监控该品牌且有管理权的成员提供创建和维护操作。 |
| 子视图报告 | 管理列表、对比行或直接链接 | 页首显示名称、已发布视图标签、所属主品牌、规则版本、快照范围与截至时间。提供返回主品牌的入口。从对比进入时保留该批次和范围。 |
| 评审清单 | Demo 外壳内进入 | 可以直达评审点、切换测试场景与身份、记录并导出本次意见。 |

打开抽屉时保留报告标签及滚动位置，关闭后查看已应用的对比范围，焦点回到全局入口。创建、编辑及确认操作在抽屉上方打开弹窗，关闭弹窗后回到抽屉。管理任务状态在抽屉中呈现。

主品牌和子视图沿用四个标准板块及指标名称。子视图页首补充来源，主品牌对比负责展示覆盖率等总分信息。Demo 用样例展示四个板块的主要定位和明细入口，交付深度按 Spec 和后续评审收口。

## 2. 创建与编辑子视图

[条件组示例](../../../demos/brand-monitor-portfolio-754/index.html#anker-query)直接打开「Anker SOLIX 户外与收纳」的未保存规则。[Anker 子视图管理](../../../demos/brand-monitor-portfolio-754/index.html#anker)支持空白创建。两种入口使用相同的并列条件组。空白创建时只显示首组，组头说明本组满足任一项即可。每个包含组均可点「选择主配置」或「调整主配置」，选择器显示当前组的已选项。组内也可点「添加条件」手填内容文本或内容标签。打开选择器后，默认可跨类别搜索，也可限定配置类别并翻页浏览，每页最多 8 项。输入搜索词后可一次选中当前类别下全部匹配项，按钮显示跨页合计。切换搜索、类别或页码时保留勾选，点「只看已选」可核对并撤选。应用时仅更新打开选择器的组。取消或按 Esc 放弃本次选择。

在组外点「添加条件组」会新建一个限定组并提供首条可编辑条件。各组平级，相邻包含组间显示「并且」。例如，第一组填标签 `anker solix` 和文本 `C1000`，第二组填文本「户外」和「收纳」。同一条内容在第一组和第二组都至少命中一项即可纳入。每个组都标注「满足任一项」，点本组的「添加条件」即可增加一个备选项。组中只有主配置也可以预览并保存。移除附加组的最后一个条件时移除该组，重开已保存规则时还原各组。需要排除内容时，在独立排除区添加内容文本或标签。发布账号在本组的主配置中选择。旧版手填账号可回读和移除。每组的已选配置通过本组「调整主配置」修改，组头为固定文字。预览时按视频核对实际命中字段、原因与来源主池批次。点击「保存同批快照」自动完成本地模拟生成，从管理列表点击视图名称，打开报告并在明细中核对命中依据。模型辅助留待后续设计。

线上交互建议在编辑时只呈现当前条件组。主动点击预览后可显示「正在计算」，完成后再展示本次命中数与样本。若期间修改了查询，回到「待预览」，旧请求返回也不覆盖新规则。失败时保留输入，可重新预览。Demo 本地样例的响应时间仅供操作演示。

达到 5 个包含组时，「添加条件组」置灰，旁边提示「已达 5 个条件组上限」。此时仍可在各组内添加、修改或移除条件，并单独维护排除项。删除一组使组数降到 4 后，「添加条件组」恢复可用。历史规则超过 5 组时完整显示，提示调整至 5 组以内后可重新保存。

岩途场景用于核对通用创建、编辑和状态流程。

1. 在「子视图管理」抽屉点击「创建子视图」。弹窗显示所属主品牌、子视图名称、可选的视图标签和收录平台。名称和视图标签供用户识别子品牌、主题、活动等用途。编辑填回已保存的名称、标签和查询规则。
2. 「纳入条件」每行指定条件类型和值，支持文本短语和内容标签。「排除条件」支持文本短语与内容标签。行内提示缺失、不适用或暂不可执行的条件。至少一条纳入条件适用于每个所选平台。
3. 点击「预览」查看命中数、统计窗口、平台、数据截至时间和明细样本。样本露出命中的条件，帮助解释某条内容为什么进入。允许保存预览为 0 的有效查询。查询或字段不可用时呈现具体原因。
4. 点击「保存并生成」，返回抽屉查看任务状态。首次成功后可打开报告或将其选作对比成员。编辑期间可继续查看旧报告。报告页显示已发布的名称、标签和规则版本，抽屉另显示待生成或失败的版本。

查询平台是视图定义的一部分。「对比设置」中的日期、平台控件只影响本次查看范围。

## 3. 子视图对比与下钻

[打开月报版子视图对比](../../../demos/brand-monitor-portfolio-754/index.html#comparison)。v0.20 使用同一主品牌池中的私有子视图作月报分析。默认示例读取岩途 2026 年 10 月发布的视频；观看值统一取该快照的数据截至时点。可切换完整自然月或最近 7／30 天。

| 阅读路径 | 核对点 |
|---|---|
| 指标矩阵 → 内容明细 | 主品牌基准与每个可见子视图显示提及视频数、占主池视频数、总观看及其占比、单条观看中位数。观看值均以页面标明的截至时点统计。 |
| 总观看 → 代表视频 | 打开本行观看量前五的视频，核对贡献与样本数。列表不足五条时看实际作品，空或观看字段不完整时显示对应状态。 |
| 平台构成 → 平台明细 | 全平台下并列显示每个子视图的渠道结构。条内比例按该视图自身的视频总数计，点击分段可见对应平台明细。单平台筛选后收起本图。 |
| 发布节奏 → 时间点明细 | 默认按周，可切日。月首、月末的周按当月实际日期裁剪；关闭明细返回原范围。 |
| 子视图管理 → 覆盖诊断 | 在配置成员时查看已覆盖、未覆盖及成员间重叠。临时隐藏显示行不会改变配置成员的并集。 |

### 子视图重合度

在指标表之后展开「子视图重合度」，先看矩阵。行列均取当前可见子视图，按同一顺序排列。格内百分比取共同数除以两组去重总数，底色标记高低。内容和参与网红共用固定的连续色标，图例标出 0%、2%、5%、30%、60%、100% 的参照色。真实零保留 0%，不适用或无有效分母的组合用「—」。对角线不参与选择。

点任一交叉格，同时标记该格与对称格。详情给出各自总数、共同数及共同部分分别占两侧的比例，可查看共同作品或共同账号及其在两边的发文数。首次进入不预选组合；切换「内容 / 参与网红」保留当前选择，便于直接比较同一对。桌面在矩阵旁显示详情，窄屏在矩阵下方显示。管理抽屉继续按全部配置成员核对覆盖与未覆盖。 [满载矩阵实测截图](assets/v026-overlap-matrix.png)

### 满载月报评审

[五成员样例](../../../demos/brand-monitor-portfolio-754/index.html#full-comparison)直接打开十月子视图对比。先横向阅读主品牌基准与五个成员，再按需查看达人、互动、推广类型和发布节奏的明细。窄屏的指标表可横向滚动；各图使用同一组可见成员，并保留数量、单位及下钻入口。

四至五个可见子视图触发紧凑布局。表格固定行名、压缩重复标签与行距。推广和平台构成共用一行图例，图上标出较宽色段的占比，较短色段保留颜色；可展开查看全部类别的条数与精确占比，或点击色段查看作品。按日发布趋势保留全部曲线，突出所选日期，其他点仍可悬停或通过日期控制下钻。

在本地 Chrome 以相同的五成员规模测量对比 TAB 内容区高度，日期均为十月，类别数字保持收起。1440 × 900 视口从上一版 2,809 px 降至 2,381 px；390 × 844 从 4,073 px 降至 3,237 px。桌面首屏能看到完整六行指标和下一组图的标题。手机端仍需要纵向滚动；推广构成从 794 px 缩至 437 px，用户可在同一屏比较六行。窄屏保留表格自身横向滚动。 [390 px 下的推广类型构成](assets/v024-full-promotion-mobile.png)

### 参与达人、互动与推广结构

指标表给主品牌基准与每个可见子视图增加「参与网红数」「总互动量」。以下三图沿用这组成员、日期范围和快照。

| 月报阅读路径 | 展现与操作 |
|---|---|
| 找到重复发布较集中的视图 | 用点位比较多次发布达人占比，同时给出账号计数。点开该行，核对重复发布账号及发文条数。 |
| 比较同一平台的互动表现 | 报告选全部平台时，图内先看 YouTube，可切 Instagram、TikTok；报告已选单平台时图随之切换。在同平台点图中比较比率、核对有效样本，点行查看参与计算的作品，按评论数定位代表内容。 |
| 解释传播来源 | 每行一根 100% 堆叠条，列出各类的数量与占比。点击分类下钻到对应视频，未识别单列，小样本保留条数。 |

### 观看量占主品牌比重

指标表之后展示成对横条，同一行先读观看量占比，再对照视频数占比。各条显示独立百分比，行按观看量占比降序。点击指标表中的总观看量可追溯头部视频。

### 管理主列表的「参与对比」

管理者直接在「子视图管理」主列表逐行勾选，保存后，所选子视图进入该主品牌报告的「子视图对比」TAB。每个客户在每个主品牌下可选 0–5 个子视图。至少选中一个时，报告另列同批主品牌作为基准。

列表显示当前勾选数和 5 个名额。达到上限时，其余候选行的勾选框禁用；已选行仍可撤选，腾出名额即可换选。编辑中的选择可取消，保存后指标表、图表及管理侧覆盖诊断一起使用新成员。保存空选择后，对比 TAB 提示从管理列表选取成员。阅读时临时隐藏某行，仍保留该成员的名额。[试用 7 个子视图中选 5 个](../../../demos/brand-monitor-portfolio-754/index.html#compare-select)。

### 上一轮概览内嵌方案（位置对照）


页首三个数值用于示意现有指标。总内容数和总网红数对应线上「核心KPI」，观看量对应「推广活动趋势」中的观看量。Demo 把三项汇在页首使用虚构数据。标准概览的其他模块继续按线上报告作为交付基线。[Anker 标准报告](https://cn.noxinfluencer.com/brand/brand-analysis?pkId=17220&from=brand_search&word=anker)

本期新增的是主报告中的「子视图对比」。表内复用提及视频数和观看量，补充视频覆盖率、观看覆盖率、未覆盖数和同批下钻。

当前客户对主品牌有有效监控权益且至少配置一个可读同批子视图时，在核心 KPI 之后常驻对比表。报告对比区可通过标题旁的问号查看同批基准的绝对日期、平台、数据截至时间及批次。清空配置时整表隐藏，可从「子视图管理」重新配置。Demo 默认演示截至 2026-11-22 的 30 个完整日历日。

在「子视图管理」抽屉的「对比设置」中，用户可以切换最近 7 天或 30 天和平台，并用「显示分项」临时隐藏已配置行。日期及平台切换只筛选同一冻结范围内的结果。成员勾选采用上文的管理主列表交互。Demo 会话内延续成员选择。管理者也可在「对比设置」发起「统一刷新」，在抽屉查看任务状态及结果。新批次完整发布前，报告继续展示上一成功批次。

| 对比区 | 展示 |
|---|---|
| 主品牌基准行 | 展示对比所用的提及视频数和观看量，作为分项覆盖率的分母。主报告页首可以展示更新的标准报告数据。取数时间分别在主报告页首和对比统计范围提示中标明。 |
| 已配置的子视图分项 | 逐行显示已配置子视图的收录平台、提及视频数、观看量及相应覆盖率，并提供报告和明细入口。所选单平台不在该视图收录范围时显示「未收录所选平台」，有效零条展示为 0。 |
| 未覆盖内容 | 具备同批完整数据且已选择成员时，展示未被所选子视图覆盖的视频数。变更对比成员会重新计算。「显示分项」仅控制展示行。 |

问号提示默认收起，展开时覆盖下方区域。支持点击、触屏及键盘操作，按 Esc 或点提示外关闭。表格下方展示未覆盖视频数及其差集明细入口。分项可能重叠的说明收入问号。详见[一期品牌概览的对比指标](comparison_rules_review_v0.md#一期品牌概览的对比指标)。

从对比行打开子报或明细，入口传入该批次、日期与平台。页首或明细头部明示该范围，返回后仍能定位原对比。管理抽屉提供最近成功发布的子视图报告。若指定批次已过期，给出当前报告入口。指定子视图已停用或用户失去主品牌权限时，显示不可访问状态。

### 发布趋势下钻

打开「子视图对比」TAB，可在发布内容数趋势中查看同批主品牌参考线和各可见子视图系列。主品牌参考线用虚线区分。未收录当前平台的成员在点位数字处提示「未收录所选平台」，真实零保留在图上。图内「按日」「按周」只切换阅读粒度，成员、日期范围、平台和临时显示继续在「子视图管理 → 对比设置」调整。

可点击图上数据点，也可使用「查看日期」选择日期后点击分项条数。两种方式都在新标签页打开内容库。下钻说明给出视图、所选平台、日期桶的实际起止及批次。原标签页保留图表及所选粒度。其他报告模块的子视图对比形式保留为候选。[对比盘点](comparison_rules_review_v0.md)

## 4. 状态与反馈

管理者在当前主品牌的子视图列表顶部点击「一键处理全部」，直接处理所有已启用且已发布的受影响子视图。完成后显示已处理及需手动处理的视图数，剩余项仍可点「处理条件」。只读身份可查看变动与当前快照。主配置变动后，在管理抽屉对应子视图行内显示「需处理」和原因；子报告在标题附近的快照信息旁说明更新受影响及实际截至时间；编辑器将原值和处理入口放回发生变动的条件组。有管理权限可修复并保存，预览或取消后原发布规则的提示继续保留。仅有刷新任务运行时显示「更新中」。详见[维护评审稿](子视图编辑维护讨论.md)。

| 场景 | 用户看到的状态及处理 |
|---|---|
| 首次生成 / 首次失败 | 尚无可用快照。可编辑身份在失败后可重试，其他身份可查看状态。 |
| 更新中 / 更新失败 | 有最新一次成功的快照可用，并区分其规则版本与更新任务的规则版本。批次完整发布后再切换。 |
| 零命中 / 零分母 | 有效结果为零时用数字 0 表达。分母为零或不可用时，覆盖率用「—」及可读原因表达。 |
| 数据缺失 / 超出快照范围 | 明确缺失的指标或范围。部分观看值缺失时，内容数仍可按完整的内容集合展示。范围超出时提示可查看范围及生成入口。 |
| 停用 / 权限变化 | 停用视图即时退出候选及现有对比配置，直接或历史链接也给出不可访问反馈。重新启用并成功发布后可再次选择。只读用户可在抽屉调整本人临时日期、平台和显示分项。保存成员与统一刷新须有管理权限。撤销权限后按主品牌访问限制处理。 |

## 5. 组件规范与评审边界

采用同级 `kol2.0-design-specification` 的 `playbook/semantic-tokens.md`、Navigation、Tabs、Table、Modal / Dialog 和 Accessibility。使用语义色和主行动色 `#FA6300`。表格数字对齐、列名单独说明单位，任务和数据状态通过文字表达。导航、对比行、弹窗和表单支持键盘操作与可见焦点。弹窗关闭后恢复焦点，字段错误靠近输入并可被辅助技术读取。窄屏保留必要的控制顺序，宽表按规范滚动。

评审入口、身份切换、样例场景和操作结果模拟属于独立 Demo 外壳。Demo 标明 Anker 配置来源，并标注两组报告的演示数据，并为暂未演示的标准报告能力保留清楚的模块定位或说明。真实模块依赖、线上权限接入及生产交付范围在后续单独审定。评审场景和反馈规则见 [Demo 评审约定](demo_review_contract_v0.md)。
