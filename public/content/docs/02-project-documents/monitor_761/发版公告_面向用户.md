# 发版公告｜v7.6.1 内容监控 2.0 体验升级

尊敬的用户：

在 **v7.6.1** 版本中，我们继续优化「内容监控 2.0」的使用体验。本次更新重点围绕 **项目表现速览、数据看板分析、监控内容筛选处理、单条内容详情查看，以及数据导出** 进行升级，帮助您在创建监控后更快看懂项目当前状态，发现值得关注的内容，并完成后续处理。

本次更新后，您可以从项目列表快速查看近期表现，并进入统一的内容监控工作台查看单个项目、多个项目或全部可见项目的数据。工作台中新增数据看板，用于查看观察周期内的内容变化、关键指标趋势、达人/频道贡献和标签贡献；监控内容列表也支持更清晰的处理筛选、批量操作和详情抽屉。

## 本次更新内容

### 1. 项目列表新增近期速览

- 项目列表展示近期观看量、互动率、需关注内容等核心信息，帮助您快速判断哪些项目需要优先查看
- 项目卡片整体可点击，进入对应项目的内容监控工作台
- 支持从项目列表进入单项目、已选多项目或全部可见项目的监控视图
- 项目列表支持分页和筛选，便于管理项目数量较多的账号

### 2. 内容监控工作台统一升级

- 内容监控详情页升级为统一工作台，支持单项目、多项目和全部项目范围
- 页面顶部展示当前项目范围、内容数量、覆盖平台和需关注内容
- 原「总监控列表」相关查看场景会逐步收敛到同一套工作台结构中，减少不同页面之间的理解成本
- 已归档项目仍可查看历史数据，但不能继续新增监控或通过自动追踪新增任务

### 3. 新增数据看板，帮助快速理解项目表现

- 新增「观察区间概览」，展示当前观察周期内的观看增量、互动增量、互动率、活跃内容和待处理提示
- 新增内容变化榜，帮助发现近期观看、互动或评论变化更明显的内容
- 新增关键指标趋势，可查看观看量、互动量、短链点击等指标的变化趋势
- 新增达人/频道贡献分析，帮助了解哪些达人或频道贡献了主要变化
- 新增标签贡献分析，支持查看不同标签下内容的观察期增量和当前累计表现

### 4. 筛选口径更清晰

- 工作台中的内容集合筛选与数据观察周期分开展示，避免将发布时间筛选和数据变化周期混淆
- 平台、标签、创建人、监控时长、观看量、视频类型、来源等筛选会影响当前工作台的数据范围
- 数据观察周期用于计算数据看板中的增量、趋势和贡献分析
- 监控内容列表新增处理型筛选，例如短链状态、预算状态、评论状态、近期新增等，便于快速定位需要处理的任务

### 5. 监控内容列表和详情抽屉优化

- 监控内容列表支持更灵活的表头配置，可按账号偏好显示、隐藏和调整字段顺序
- 列表支持多选，并可进行移动项目、打标签、修改监控时长、导出、删除等批量操作
- 未绑定短链、未填写预算等状态会在列表中直接提示，并提供快捷处理入口
- 点击单条内容后，可在详情抽屉中查看内容信息、监控配置、原始数据、趋势、短链、评论和备注等信息
- 单条内容趋势支持导出当前任务、当前日期范围和当前指标的数据

### 6. XLSX 数据导出能力增强

- 保留既有 XLSX 全量导出能力，可导出未经过当前筛选缩小的监控任务表格数据和原始聚合数据
- 全量导出适配单项目、多项目和全部可见项目范围
- 新增数据看板导出，可导出当前筛选视图下的看板数据
- 新增当前视图导出，可导出当前筛选视图下的监控任务表格和原始数据
- 导出文件继续使用 XLSX 格式，并通过多个 sheet 承载不同类型的数据

## 如何使用

### 查看项目近期表现

1. 进入「内容监控」项目列表
2. 查看项目卡片中的近期观看、互动、需关注内容等信息
3. 点击项目卡片进入对应内容监控工作台
4. 如需跨项目查看，可选择多个项目或进入全部可见项目范围

### 使用数据看板分析项目

1. 进入内容监控工作台
2. 在页面顶部确认当前项目范围和筛选条件
3. 在「数据看板」中选择数据观察周期
4. 查看观察区间概览、内容变化榜、关键指标趋势、达人/频道贡献和标签贡献
5. 如需继续处理具体内容，可进入下方「监控内容」列表

### 处理监控内容

1. 在「监控内容」列表中使用短链状态、预算状态、评论状态、近期新增等筛选条件
2. 点击单条内容打开详情抽屉，查看数据趋势和配置状态
3. 对未绑定短链、未填写预算等内容进行补充处理
4. 如需批量处理，可勾选多条内容后使用批量操作

### 导出数据

1. 如需导出全部数据，可在当前范围区域使用全量导出
2. 如需导出看板分析结果，可在数据看板区域导出当前看板数据
3. 如需导出当前筛选后的内容列表和原始数据，可在监控内容区域导出当前视图

## 温馨提示

- 数据观察周期用于计算观察区间内的增量、趋势和贡献分析，不等同于内容发布时间筛选
- 预算、成本等数据需要用户手动填写，默认可能显示为未填写
- CPM、CPV、CTR 等效率指标依赖预算或短链等配置，缺少必要数据时可能无法计算
- 评论相关能力本次不扩展抓取范围，页面会尽量解释评论为空或样本不足的原因
- 已归档项目仍可查看历史数据和导出数据，但不能新增监控，也不会继续通过自动追踪新增任务
- 不同账号可见的项目范围、导出能力和批量操作权限可能受套餐、权限或数据范围影响
