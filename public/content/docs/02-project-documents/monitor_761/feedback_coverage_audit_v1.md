| 分类 | 数量 | 含义 |

但这 53 条里，绝大多数不是遗漏，而是已经在 input/spec/PRD 中明确被放入 `Backlog / TODO / 后续子 topic`。

## 5. 对 PRD v1 的影响

当前 PRD v1 不需要因为反馈池再大改范围。

建议只做三件事：

1. 在 PRD 评审时重点看 10 个 `待单独确认 topic`，决定哪些保留为 open question，哪些推进为后续小需求。
2. 对 43 条未覆盖项不要隐藏，保留在 feedback audit 中，避免评审时被误解为遗漏。
3. 若后续要继续吸收反馈，优先级建议是：
   - P1：自定义标签交并集、短链统计起点、月环比/第 N 天指标口径。
   - P2：导出字段结构、频道均值、项目级高频词。
   - P3：创建链路小体验、平台扩展、权限/配额治理。
