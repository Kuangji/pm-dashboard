# 品牌监控调研范围共识 v1

> 创建：2026-11-13 · 对应项目 v7.5.4 主子品牌视图化查询 · 当前口径见 [Input v2](../../02-project-documents/brand_monitor_portfolio/input_v2.md)。

Demo v0.7 统一为池内「子视图」，名称及可选的视图标签可用于标识子品牌、主题或活动。通过主品牌页首的「子视图管理」抽屉维护视图并设置对比。主报告页首用样例示意现有指标，子视图对比展示本期新增能力。对比的统计范围从标题旁的问号查看。下文保留前期调研语境。[Demo 回流记录](_sync_inbox.md)

## 已确认范围

解决相关品牌数据离散，探索总—分形式的定制化视图；先研究外部产品。与品牌舆情版本分开管理。

## 本轮术语

| 术语 | 本轮含义 | 不可自动推导 |
|---|---|---|
| 主品牌 / 子品牌 | 用户表达的业务关系 | 固定两级树、法律控股关系、品牌名包含关系 |
| 产品线 / 事业群 | 可能参与汇总的业务组织维度 | 一定有独立社媒账号、一定是品牌实体 |
| 总 | 某个明确范围的汇总结果 | 子项数字简单相加、母品牌自身提及就是集团总量 |
| 分 | 构成总体的品牌、业务单元及其内容/达人明细 | 只有横向竞品对比 |
| 定制化视图 | 用户可决定某种数据范围或阅读组织 | 已决定支持拖拽组件、任意公式、BI 编辑器 |
| 关联 | 需要研究的业务关联或分析集合 | 已决定全局统一/用户私有、自动识别/人工维护 |

## 证据边界

`kol_brain` M04 基线最后核验 2026-04-30（已超 180 天），只用于定位品牌方向与对象，不作为 2026-11-13 现网事实。本轮未作聚星代码、服务端或页面验收，因此不声明现有系统缺少某个表、接口或 UI 能力。

竞品资料分“官方帮助文档 / 官方产品宣传 / 官方案例 / 第三方用户声音”。文档流程不标为实测；官方客户案例不能当独立用户访谈。

## 后续 VDR 边界

当前位于 Input 阶段。后续写 Design、交互方案或 Demo 前必须读取 `../kol2.0-design-specification`，并核对 `../kol-next` 与真实浏览器；涉及汇总口径、权限、品牌映射时检查实际服务端归属，必要时双查。

本轮不指定布局、设计令牌或组件状态，不创建实现合同。

## 2026-11-17 · 用户明确的本轮范围优先级

主要目的仍是梳理**主子品牌关系及其计算、展示方案**。基于两轮调研比较候选，暂不定最终方案。定制视图只作为保存品牌关系/范围、统计条件和总分阅读方式的手段，不将通用看板、任意图表画布、团队治理或舆情功能升为主任务。

本轮候选与演算假设见[主子品牌关系与计算展示比较](decision/主子品牌关系与计算展示_候选形式比较_v1.md)；其中计算示例、层级规则、成员解析及保存政策均不是用户已确认的生产合同。

## 2026-11-19 · 已确认自顶向下的需求口径

主品牌作为监控范围内的全量品牌家族数据池。子品牌以在该池内定义、保存的查询视图呈现。主品牌范围内未命中任何子品牌视图的内容仍计入总体。包含性直接按目标数据范围定义，现有独立报告之间的包含关系只作为现状参考。见[已确认的需求口径](decision/自顶向下与自底向上_竞品对应.md#已确认的自顶向下需求口径)。

## 2026-11-19 · 纳入组合视图与同层使用

用户确认可任意选取多个主视图或子视图，跨主品牌组合并保存为新视图。主视图、子视图、组合视图作为同层的可复用报告使用。按当前理解，三类视图同层展示和管理，数据来源照各自定义保留。见[组合范围与示例](decision/自顶向下与自底向上_竞品对应.md#已确认的组合视图与同层使用)。

主视图只能直接对应主品牌全量数据池，不能由子视图组合定义。全部子视图组合后的结果仍属于组合视图。

## 2026-11-20 · 兼容没有主品牌数据池的独立报告

同一业务对象可以在聚星有多个独立报告，例如 NIKKE 按不同运营范围划分。现有独立报告可直接作为组合视图来源，保留独立取数方式。组合视图的统计范围由所选来源和组合定义决定。见 [NIKKE 线上样本](decision/自顶向下与自底向上_竞品对应.md#线上样本-nikke-按运营范围独立报告)。

## 2026-11-23 · 本期范围收口

v7.5.4 以主品牌全量池为物理来源，向下通过池内查询形成子品牌报告。主品牌总量及子品牌分项在同一池内计算。跨主品牌或混合聚合、以及 NIKKE 这类独立报告的聚合留到后续版本。前述聚合讨论保留历史口径，以 [Input v2](../../02-project-documents/brand_monitor_portfolio/input_v2.md) 为本期范围。

同一主品牌下的多个子品牌可对比，另存聚合留待后续。子品牌视图使用快照。主品牌沿用线上标准报告并补充子品牌对比，子品牌视图以标准报告内容为基础。查询条件、快照语义、指标及视图生命周期继续在 Input 阶段讨论。[查询与快照讨论](../../02-project-documents/brand_monitor_portfolio/子品牌查询与快照讨论_v0.md)
