# 未解决问题与追加取证

## 影响实现选择的缺口

| 缺口 | 为什么会改变选择 | 下一步证据 |
|---|---|---|
| 客户怎样定义主/子品牌、产品线、事业群 | 可能是固定组织、可交叉归属或临时分析组合 | 2–3个真实品牌组合及管理者/品牌经理任务；不是统计代表样本 |
| 原生业务树与多维集合的实际维护 | 决定关系维护成本、能否横切地区、权限是否解耦 | Lefty/CreatorIQ/Sprinklr同场景演示 |
| 公开品牌提及和owned账号数据差异 | 决定哪些竞品机制可迁移 | 同一品牌的两种数据范围对照 |
| 跨品牌内容/达人重复 | 影响总体及分项解释 | 含交叉命中内容的真实结果与计数合同 |
| 金额、比率、受众口径 | 可能需重算/分摊，不能统一累加 | 各指标定义、单位、数据源、公开/私有差异 |
| 可见范围与聚合泄漏 | 是否能给高管和单品牌用户共享同一视图 | 仅有部分品牌权限的账号访问演示 |
| 关系/集合变更后的历史 | 影响复盘可比性与审计 | 改成员/改关键词/移品牌前后，同期历史数对比 |
| 旧资料、套餐与版本 | 不能按2021–2024说明承诺当前功能 | 现行付费租户或厂商演示补证，尤其Rival IQ |
| 聚星现有数据与页面能力 | 影响复用成本和方案边界 | 先读kol-next及服务端本地约束，再结合真实页面核验 |

## 当前不做的扩展

没有新增市场规模、采购价格或中国市场优劣排序。没有把未知标为不支持，没有据资料缺失宣布行业空白；没有联系销售或写入外部应用。
