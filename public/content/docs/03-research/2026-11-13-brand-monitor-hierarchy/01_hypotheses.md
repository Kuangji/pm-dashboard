# 研究假设与验证口径

这些是假设检验用的命题，不是聚星的产品决策。创建：2026-11-13。

| ID | 待检验命题 | 影响 / 不确定性 | 需要的证据 |
|---|---|---|---|
| H1 | 主子品牌总分视图必须依赖一种固定品牌父子树 | 高 / 高 | 不同产品实际对象、集合/层级/多归属配置 |
| H2 | 多品牌同屏、比较与集团汇总是同一种能力 | 高 / 高 | overview、comparison、combined、drilldown的分别定义 |
| H3 | 子项的指标可以直接相加/平均成为总体 | 高 / 高 | 内容/达人/受众去重，指标权重，集合范围、付费和公开指标口径 |
| H4 | 保存一个定制看板就足以保证范围、权限、筛选与历史一致 | 高 / 高 | 保存对象、范围继承、共享边界、成员/查询变更行为 |

本轮不研究市场规模、商业化、分发或监管假设，避免偏离功能问题。用户痛点强度和使用频率仅来自本次需求陈述，后续需客户样例补证。
