# 来源计划与采集边界

创建 / 执行：2026-11-13。

- 第一轮：官方帮助文档、API对象定义、产品页面，按红人营销 / 社媒分析 / 企业级组织分支采集。
- 第二轮：针对“品牌树是不是查询组”“Compare是否等于Combine”“全局筛选是否真的全局”“总量是否去重”做反证检索。
- 补充用户声音：搜索Emplifi、CreatorIQ、Sprout的分组/报告摩擦；采用一条可直接阅读的TrustRadius原始评论，不用平台自动摘要代替用户证据。
- 优先新文档；旧但仍公开的帮助页记录时间风险。能交叉检查对象存在性，不代表旧入口、套餐和界面已获当前验证。
- 不登录/注册竞品，不申请Demo，不联系销售，不假设能使用付费API；失败/403/重定向不凭搜索片段补全。

## 检索主题

`sub-brand / parent brand / brand hierarchy / portfolio / workspaces / brand groups / profile labels / query groups / combined searches / custom dashboard / cross-group analytics / Company Set summary / deduplication`。

## 来源偏差

官方资料适合证明功能声明和对象定义，不证明使用效果。营销页降为中置信度；同厂商多个文档不是独立市场验证。单条评论存在匿名、激励、自选择、版本与业务场景差异，只作为摩擦线索。所有产品均未登录实测。

## 定量边界

证据卡数量是本轮采集量，不是功能覆盖率、客户普及率或用户痛点发生率。没有做全市场穷举；未检出不能写成不支持或行业空白。
