# Sprout Influencer Marketing：文档重建流程

日期：2026-11-13｜公开资料，未登录实测。

用户任务：围绕品牌提及或产品关键词，把分析范围合并或分项比较。

## 前置与入口

数据对象：workspace；keyword groups；report datasets。功能/数据/共享权限按对应来源；本轮未作付费租户验证。

## 核心操作

1. 当前workspace → Add a workspace；填写名称并关联Profile。
2. Reports → New Report，选择Single Topic/Industry Topic/Product Line等模板。
3. Settings → Workspace → Keyword Groups，建关键词/hashtag/handle组合后保存。
4. 在报告中引用并过滤；跨workspace可复制组，未确认组织级自动汇总。

## 完成态与边界

Single Topic合并多关键词dataset；Industry Topic分组比较；品牌/产品词过滤。workspace内复用Keyword Group，可复制到其他workspace。

取消、空数据、异常和无权限界面的具体反馈未观察，不补写为确定事实。复制不等于共享；删除组可影响历史报告；去重未知。

## 设计意图假设

推测：把检索语义与报告呈现解耦，复用查询素材。
