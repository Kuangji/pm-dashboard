# Rival IQ：文档重建流程

日期：2026-11-13｜公开资料，未登录实测。

用户任务：把事业部或地区作为可比较、可汇总的分析集合。

## 前置与入口

数据对象：Landscape；Company Sets；Custom Dashboard。功能/数据/共享权限按对应来源；本轮未作付费租户验证。

## 核心操作

1. 新建Landscape并加入companies。
2. Company Set dropdown → Manage Company Sets；维护具名子集。
3. Custom Dashboard → Create New Chart → Table → Dimension=Company Set。
4. 选metrics与Summary Calculation，Save to Dashboard。
5. 公司链接或受支持可点行进入公司/帖子；未证实集合行一键下钻。

## 完成态与边界

集合汇总行按指标total/average；旧文档；Company Profile/部分行到关联帖子；集合行下钻未知。Custom Dashboard；集合自动保存；报表导出/定期发送。

取消、空数据、异常和无权限界面的具体反馈未观察，不补写为确定事实。Focus Company范围例外；指标权重不同；旧功能需现行确认。

## 设计意图假设

推测：让同一批companies通过集合复用于不同比较和聚合任务。
