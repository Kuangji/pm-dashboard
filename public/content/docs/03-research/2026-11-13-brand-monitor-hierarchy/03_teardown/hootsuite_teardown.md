# Hootsuite Analytics：六维拆解

2026-11-13｜研究记录，不是聚星方案。

| 维度 | 记录 |
|---|---|
| 功能定义 | 汇集团队账号数据，为管理者配置所需报表。 |
| 交互实现 | organization/teams/accounts；report/tile；tile可展示aggregated数据；comparative图型与内容指标；非品牌层级下钻证据。模板/自定义report，Read/Edit共享 |
| 边界处理 | 团队账号集合＋报表配置；品牌树未知；自定义tile脱离report filters/sources；橙点提示。未观察空态/错误/取消态 |
| 业务信号 | 推测：把多种分析需求放入report与tile配置，允许不同组件使用不同范围。这属于研究解释，不是厂商内部策略事实 |
| 设计令牌 | 本轮未采集色值、间距、圆角或动效；无登录态视觉验收，不从营销插图推导产品组件规范。后续聚星Design遵循kol2.0-design-specification |
| 学习与避坑 | 灵活组件会带来范围例外；选定来源/筛选后是否持续继承必须可检查。 |
