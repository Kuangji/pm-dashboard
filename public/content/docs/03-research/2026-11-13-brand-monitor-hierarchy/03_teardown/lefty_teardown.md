# Lefty：六维拆解

2026-11-13｜研究记录，不是聚星方案。

| 维度 | 记录 |
|---|---|
| 功能定义 | 分别管理业务单元，并给管理者统一查看各品牌表现。 |
| 交互实现 | 品牌/地区/部门workspaces；跨团队monitoring dashboard；官方宣称group/division/brand/market统一报告；品牌/市场表现与合作内容；逐节点下钻控件未知。报告导出、live link；自定义范围保存细则未知 |
| 边界处理 | 组织级多业务维度；原生品牌树未知；营销页证据；跨品牌内容/creator去重未知。未观察空态/错误/取消态 |
| 业务信号 | 推测：让分散团队保留运营边界，同时满足组织管理者的整体阅读。这属于研究解释，不是厂商内部策略事实 |
| 设计令牌 | 本轮未采集色值、间距、圆角或动效；无登录态视觉验收，不从营销插图推导产品组件规范。后续聚星Design遵循kol2.0-design-specification |
| 学习与避坑 | 业务单元独立与组织报告可以共存；先验证报告维度能否支持真实总分任务。 |
