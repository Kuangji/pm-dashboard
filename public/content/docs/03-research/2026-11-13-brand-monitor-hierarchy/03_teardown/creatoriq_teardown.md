# CreatorIQ：六维拆解

2026-11-13｜研究记录，不是聚星方案。

| 维度 | 记录 |
|---|---|
| 功能定义 | 在子品牌独立治理下统一查看creator项目结果。 |
| 交互实现 | 团队/sub-brand治理；portfolio报告；MeasureIQ；portfolio跨品牌可见性；计算合同未知；按campaign/creator/region等维度切分。模板/空白报告，保存与division/组织共享 |
| 边界处理 | 明确子品牌组织结构；品牌实体树配置未知；产品页证据；各品牌衡量标准可能不同。未观察空态/错误/取消态 |
| 业务信号 | 推测：面向多品牌企业提供治理和统一衡量，不强制所有品牌相同运营流程。这属于研究解释，不是厂商内部策略事实 |
| 设计令牌 | 本轮未采集色值、间距、圆角或动效；无登录态视觉验收，不从营销插图推导产品组件规范。后续聚星Design遵循kol2.0-design-specification |
| 学习与避坑 | 组织分工、报告维度和数据口径要分别核实，不能由sub-brand术语补造实体关系。 |
