# Rival IQ：六维拆解

2026-11-13｜研究记录，不是聚星方案。

| 维度 | 记录 |
|---|---|
| 功能定义 | 把事业部或地区作为可比较、可汇总的分析集合。 |
| 交互实现 | Landscape；Company Sets；Custom Dashboard；集合汇总行按指标total/average；旧文档；Company Profile/部分行到关联帖子；集合行下钻未知。Custom Dashboard；集合自动保存；报表导出/定期发送 |
| 边界处理 | 平面集合＋可复用子集；company可多标签；Focus Company范围例外；指标权重不同；旧功能需现行确认。未观察空态/错误/取消态 |
| 业务信号 | 推测：让同一批companies通过集合复用于不同比较和聚合任务。这属于研究解释，不是厂商内部策略事实 |
| 设计令牌 | 本轮未采集色值、间距、圆角或动效；无登录态视觉验收，不从营销插图推导产品组件规范。后续聚星Design遵循kol2.0-design-specification |
| 学习与避坑 | 集合汇总与默认对比须分开检查；同名集合在不同报表位置的范围可能不同。 |
