# Meltwater Explore / Explore+：六维拆解

2026-11-13｜研究记录，不是聚星方案。

| 维度 | 记录 |
|---|---|
| 功能定义 | 保留各品牌搜索，再做统一结果范围或横向比较。 |
| 交互实现 | Saved Search；Combined Search；Filter Set；Explore+文件夹；any/all/not组合已保存搜索；Compare独立于Combine；全链路下钻未验。复用查询/filters及分享Dashboard；Explore+有workspace范围 |
| 边界处理 | 逻辑查询组合；嵌套folder为独立导航组织；并集不等于已验证全部指标去重；Explore/Explore+不混写。未观察空态/错误/取消态 |
| 业务信号 | 推测：将资产导航、逻辑范围和分析结果分别管理，适配多种用户问题。这属于研究解释，不是厂商内部策略事实 |
| 设计令牌 | 本轮未采集色值、间距、圆角或动效；无登录态视觉验收，不从营销插图推导产品组件规范。后续聚星Design遵循kol2.0-design-specification |
| 学习与避坑 | 导航树不等于汇总树；已有搜索的复用可构建分析范围但仍需核实去重和历史。 |
